# 티스토리 발행용 HTML 변환

## 전제

티스토리 Open API는 2024년 2월 완전 종료됐다. **자동 발행은 불가능하다.**
이 스킬은 붙여넣기 직전까지만 처리한다. 마지막 단계는 사용자가 직접 한다.

## 절차

### 1. 변환

```bash
python3 scripts/md2tistory.py drafts/2026-07-25-slug.md
```

`dist/slug.html`이 생성되고, 표준에러로 제목·카테고리·태그·글자 수가 출력된다.

옵션:
- `-o <경로>` 출력 위치 지정
- `--stdout` 파일 대신 표준출력

스크립트가 처리하는 것: 제목(H1은 H2로 강등), 문단, **굵게**, *기울임*,
`인라인 코드`, 코드블록, 표(정렬 포함), 인용, 중첩 목록, 수평선, 링크, 이미지.
HTML 주석은 제거된다.

### 2. 변환 결과를 직접 점검한다

스크립트가 잡지 못하는 것을 사람 대신 확인한다.

- [ ] 표의 열이 4개를 넘지 않는가 (모바일에서 깨짐)
- [ ] 코드블록 안에 줄바꿈이 필요한 긴 줄이 없는가
- [ ] 이미지 자리표시(`<!-- 이미지: ... -->`)가 있었다면 사용자에게 알린다
- [ ] TODO 주석이 남아 있었는지 (스크립트가 개수를 보고한다)

### 3. 발행 체크리스트

`references/seo.md`를 읽고 항목을 점검한 뒤, **미충족 항목만** 사용자에게 보고한다.
전부 통과했으면 "체크리스트 통과"로 짧게 알린다.

특히 다음은 자동으로 확인한다:
- 프론트매터 `category`가 `references/categories.md`에 있는 값인가
- 태그가 3~6개인가
- Health 카테고리면 면책 문구가 본문에 있는가
- 글자 수가 카테고리별 목표 범위(`references/voice.md` §4) 안에 있는가

### 4. 붙여넣기 안내

사용자에게 알린다:

1. 티스토리 글쓰기 → 우측 상단 **기본모드 → HTML** 전환
2. `dist/slug.html` 전체 복사 후 붙여넣기
3. 다시 **기본모드**로 전환
4. 이미지는 HTML로 넣지 말고 기본모드에서 직접 업로드
5. 주소(slug)를 영문으로 지정 — 한글 URL은 공유할 때 깨진다

### 5. 발행 후 정리

사용자가 발행을 마쳤다고 알리면:
- `drafts/*.md` → `published/`로 이동
- 프론트매터 `status: published`로 변경
- 발행 URL을 프론트매터에 `url:`로 추가

사용자 확인 없이 미리 옮기지 않는다.

## 지킬 것

- 변환된 HTML 전문을 채팅에 출력하지 않는다. 파일 경로와 점검 결과만 보고한다
- 스크립트에 외부 라이브러리를 추가하지 않는다 (표준 라이브러리만)
- 변환이 이상하면 스크립트를 고치지 말고 먼저 원본 마크다운을 단순화해 본다.
  스크립트 수정이 필요하면 사용자에게 무엇이 왜 안 되는지 먼저 설명한다
- 스크립트를 고쳤으면 반드시 회귀 테스트를 돌린다:
  `python3 scripts/md2tistory.py tests/sample.md --stdout`
