# Reflections 카테고리 구조

말씀 묵상, 신앙 질문, 성경 읽기. 1,500~3,000자.

**다른 카테고리와 성격이 완전히 다르다.** 정보 전달이 아니라 개인 기록이다.
기술글 문체를 그대로 가져오면 안 된다. `references/voice.md` §7을 먼저 읽는다.

## 유형 A — 설교 묵상 (가장 많은 형태)

실제 발행글에서 관찰된 골격 그대로:

```markdown
본문은 {성경 책} {장}장 {절}절, {목사님 성함} 목사님이 전하셨습니다.

## 설교 핵심 요약
(3~5줄. 설교의 중심 메시지)

## 본문 | {성경 책} {장:절} (쉬운성경)

> {절 번호} {구절 원문}
> {절 번호} {구절 원문}

## 설교 요약 - {목사님 성함} 목사님
(설교 흐름을 따라 정리. 들은 내용이지 내 해석이 아님을 유지)

## Thoughts
(내 생각. 여기서 겸손 장치가 들어간다)

(마무리 — 개인 기도 또는 바람)
```

### 첫 문장 형식

전한 사람을 밝히는 것으로 시작한다.

> 본문은 로마서 8장 28-30절, 신동민 목사님이 전하셨습니다.

### 겸손 장치

`Thoughts` 시작 부분이나 글 앞쪽에 한 번 들어간다. 실제 예:

> 제 믿음과 성경 지식은 얕아서, 뒤에 적을 제 생각은 높은 확률로 틀렸을 것입니다.

매번 같은 문장을 복사하지 말고 같은 태도로 다르게 쓴다.

### 마무리

교훈 요약이 아니라 개인 기도/바람으로 닫는다. 실제 예:

> 요즘 저의 바람은 하나입니다. ... 제 인생을 조금씩 바꾸어 가고 계신 주님께 감사드립니다.

## 유형 B — 신앙 질문

스스로 던진 질문을 정리하는 글. 제목에 `[질문]`을 붙인다.

```markdown
(질문이 생긴 계기 — 구체적인 상황에서 시작한다)

## 질문
(질문을 한 문장으로 정확히)

## 이렇게 생각해 봤습니다
(자기 생각의 흐름. 결론을 미리 정해두고 끼워 맞추지 않는다)

## 찾아본 것
(성경 구절, 읽은 글. 출처를 밝힌다)

## 지금의 정리
(답이 아니라 '지금까지의 정리'로 쓴다. 열어 둔다)
```

답을 단정하지 않는다. "아직 모르겠습니다"로 끝나도 된다.

## 유형 C — 성경 읽기 (통독 기록)

```markdown
(읽은 범위와 성경 역본)

## 흐름
(장별 또는 단락별 요약)

## 남은 구절
> 인용

## Thoughts
```

---

## 절대 규칙

- **성경 구절 원문을 지어내지 않는다.** 쉬운성경 본문을 확인할 수 없으면
  초안에 `<!-- TODO: 쉬운성경 본문 확인 필요 -->`를 남기고 사용자에게 요청한다
- **설교자 성함과 설교 내용을 추측하지 않는다.** 사용자가 준 메모에 없으면 비워 둔다
- 독자를 가르치지 않는다. "우리는 ~해야 합니다" 대신 "저는 ~하고 싶습니다"
- 신학적 단정을 하지 않는다. 교리 논쟁으로 들어가지 않는다
- 다른 사람·교회를 평가하지 않는다
- 표를 쓰지 않는다. 불릿도 최소한으로. 산문으로 쓴다
- 태그에 `묵상`을 포함한다
