# Trends 카테고리 구조

AI·테크 업계 소식, 경제·금융, 사회·문화 트렌드. 3,000~5,000자.

Log보다 짧고 빠르다. 시의성이 생명이라 **언제 일어난 일인지**가 첫 문단에 있어야 한다.

## 골격

```markdown
(도입 — 무슨 일이 언제 있었는지 2~3문장. 날짜를 명시한다)

## 무슨 일이 있었나
(사실만. 해석을 섞지 않는다. 1차 출처 링크를 본문 안에 건다)

## 숫자로 보면
(표. 가격/점유율/증감 등. 출처와 기준 시점 필수)

## 왜 지금인가
(배경. 이 일이 갑자기 나온 게 아니라는 맥락)

## 실제로 달라지는 것
(독자 입장에서 무엇이 바뀌는지. 여기가 이 글의 존재 이유)

## 제 생각에는
(해석. 반드시 사실 섹션과 분리하고, 주관임을 명시한다)

## 지켜볼 지점
(앞으로 확인할 것 2~3가지)

(마무리 — 짧게. 단정하지 않는다)
```

## 이 카테고리의 규칙

- **사실과 해석을 문단 단위로 분리한다.** 섞으면 신뢰를 잃는다
  - 해석 섹션은 "제 생각에는"으로 시작
- 1차 출처(공식 발표, 보도자료, 공시)를 링크한다. 남의 요약 기사를 재요약하지 않는다
- 시세·가격은 **조회 시점**을 명시: "2026년 7월 25일 기준"
- 예측을 단정하지 않는다
  - ✗ "내년에는 반드시 오릅니다"
  - ✓ "이 흐름이 이어진다면 ~할 가능성이 있습니다"
- 경제·금융 글에서 **개별 종목 매수/매도를 권하지 않는다.**
  투자 판단은 독자 몫이라는 점을 명시한다
- 사회·문화 트렌드는 국내 데이터(네이버 데이터랩 등)를 쓰면 설득력이 올라간다
