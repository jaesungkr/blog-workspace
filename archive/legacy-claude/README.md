# Legacy Claude material

이 디렉터리는 저장소 개편 전에 Claude 기반 워크플로로 만든 자료의 본문을
보존합니다. 현행 글과 혼동하지 않도록 프론트매터의 `status`만 `legacy-*`로
바꿨습니다.

- 현행 `standards/`를 통과한 원고가 아닙니다.
- 고위험·시의성 주장은 새 글에 사용하기 전에 다시 조사해야 합니다.
- 과거 프론트매터, H2 소제목, 고정 면책 문구를 새 템플릿으로 복사하지 않습니다.
- 이 디렉터리의 파일은 `scripts/blog.py check --all` 대상에서 제외합니다.

새 글로 되살릴 때는 `scripts/blog.py new`로 작업 묶음을 만들고, 필요한 원자료만
출처와 확인 시점을 다시 검증해 옮깁니다.
