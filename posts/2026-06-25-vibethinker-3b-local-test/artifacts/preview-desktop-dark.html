VibeThinker-3B 사용 후기 - 맥북 실험과 한국어 한계

안녕하세요. dev.log입니다.

노트북에서 실행하는 작은 AI도 수학이나 코딩 문제를 풀 수 있을까요? VibeThinker-3B는 이런 기대를 갖게 하는 공개형 언어 모델입니다. 제작사가 발표한 점수만으로 판단하기 어려워 맥북 에어에서 수학, 코딩, 한국어 질문을 각각 넣어 봤습니다.

수학에서는 계산 실수를 스스로 고쳤고, 코딩에서는 효율적인 풀이를 제시했지만, 한국어 속담의 뜻은 제대로 설명하지 못했습니다.

VibeThinker-3B는 어떤 모델인가요?

VibeThinker-3B는 WeiboAI가 공개한 30억 파라미터의 추론 모델입니다. 파라미터는 모델이 학습 과정에서 조정하는 수치이며, ‘3B’는 그 수가 약 30억 개라는 뜻입니다. 모델 파일을 내려받아 자신의 컴퓨터에서 실행할 수 있습니다. 공식 저장소

기반은 기존의 Qwen2.5-Coder-3B입니다. 여기에 여러 풀이 과정을 학습시키고, 답을 검증할 수 있는 문제에서 올바른 풀이를 강화하는 후처리를 적용했습니다. 작은 모델의 수학·코딩 추론을 개선하는 데 집중한 접근입니다. 공식 모델 카드

아래는 제작사가 보고한 평가 결과입니다. AIME와 IMO-AnswerBench는 수학 문제 평가이고, LiveCodeBench는 코드를 작성해 테스트를 통과하는지 확인하는 평가입니다. 모두 점수가 높을수록 좋지만, 서로 다른 시험이므로 점수를 직접 비교하거나 평균 내서는 안 됩니다.

출처는 VibeThinker-3B 기술 보고서입니다. 이 수치는 제작사 평가이며, 아래 맥북 실험으로 같은 성능을 재현했다는 뜻은 아닙니다.

제작사의 공식 평가 화면입니다. 빗금 부분은 추가 추론 기법인 CLR을 적용한 결과이며, 이 글의 맥북 실험에는 CLR을 적용하지 않았습니다.

맥북에서 확인한 세 가지 질문

기존 실행 환경은 Apple Silicon 맥북 에어, 메모리 16GB입니다. Apple Silicon에서 모델을 실행하는 도구인 mlx-lm으로 MLX Community의 8bit 변환 모델을 사용했습니다. 8bit는 모델의 수치를 더 적은 비트로 저장하는 방식으로, 제작사의 원본 모델과 실행 조건이 다릅니다.

수학은 정답과 계산 과정, 코딩은 요구한 조건을 만족하는 알고리즘, 한국어는 속담의 뜻과 실제 유사 속담을 답하는지 살폈습니다. 첨부 로그에는 질문별 실행이 한 번씩 남아 있습니다. 다음 표의 토큰은 생성한 텍스트의 양이고, 메모리는 실행 도구가 출력한 최고 사용량입니다.

계산 오류를 고친 수학 답변과 코딩 풀이

첫 질문은 1부터 100까지의 정수 중 3 또는 5의 배수인 수를 모두 더하는 문제였습니다. 정답은 1,683 + 1,050 - 315 = 2,418입니다. 3의 배수 합과 5의 배수 합을 더한 뒤, 중복되는 15의 배수 합을 한 번 빼면 됩니다.

모델은 처음에 3의 배수 합을 구하면서 첫 항을 1로 잘못 넣어 1,650을 계산했습니다. 이후 첫 항은 3이어야 한다는 점을 알아내 1,683으로 고쳤습니다. 최종 답을 낸 뒤에는 해당 숫자들을 나열해 합을 다시 확인했습니다. 이 한 번의 실행에서는 최종 정답뿐 아니라 오류를 찾아 수정하는 과정도 확인할 수 있었습니다.

코딩 질문은 배열에서 ‘최댓값과 최솟값의 차이가 k 이하인 가장 긴 연속 구간’을 찾는 문제였습니다. 예를 들어 [8, 2, 4, 7]에서 k=4라면 조건을 만족하는 최대 길이는 2입니다.

모델은 구간의 양 끝을 옮기는 슬라이딩 윈도우와, 최댓값·최솟값을 관리하는 두 개의 덱을 사용했습니다. 덱은 양쪽 끝에서 값을 넣고 뺄 수 있는 자료구조입니다. 각 원소를 제한된 횟수만 다루므로 입력 길이에 비례해 처리하는 O(n) 접근입니다. 로그에는 Python 함수와 정당성 설명이 함께 남아 있습니다.

다만 로그에 별도의 테스트 실행 결과까지 있는 것은 아닙니다. 이 결과로 복잡한 개발 업무나 다른 모델과의 우열을 판단하기는 어렵습니다. 생성된 함수와 전체 답변은 글 아래의 실행 로그에서 확인할 수 있습니다.

한국어 속담에서 드러난 한계

같은 모델에 ‘서당 개 삼 년이면 풍월을 읊는다’의 뜻과 비슷한 속담 두 개를 물었습니다. 이 속담은 배우지 못한 사람도 오랫동안 보고 들으면 자연스럽게 지식과 능력을 갖추게 된다는 뜻입니다.

모델은 ‘서당’을 남쪽의 학교나 전통처럼 해석했고, 속담의 뜻을 수확과 연결해 잘못 설명했습니다. 비슷한 실제 속담을 묻는 요청에는 ‘서대·3-path’, ‘서대·시-경’처럼 새로 만든 표현을 내놓았습니다. 답변에서도 기존 속담이 아닌 새로운 표현이라고 밝혔지만, 요청한 결과를 제공하지 못한 것은 같습니다.

이 답변에는 7,166토큰이 쓰였습니다. 수학과 코딩 질문보다 길게 답했지만 정확하지 않았습니다. 설명이 길거나 표로 정리되어 있다는 이유만으로 내용을 신뢰하기 어려운 사례입니다. 다만 한국어 질문 한 건의 결과이므로, 한국어 능력 전체를 평가한 결과로 확대해서는 안 됩니다.

써 본다면 정답을 확인할 수 있는 문제부터

VibeThinker-3B는 로컬 환경에서 수학 풀이와 알고리즘 문제를 시험해 보고 싶은 경우에 검토할 만합니다. 제작사도 정답을 검증할 수 있는 문제를 주요 용도로 안내하며, 도구 호출이나 자율 코딩 에이전트 작업에는 권장하지 않습니다. 제작사의 사용 안내

기존 로그에 남은 코딩·한국어 실행 명령은 temperature=1.0, top_p=0.95, 최대 생성량 8,000토큰을 사용했습니다. 아래는 당시 한국어 질문의 실행 명령입니다. 먼저 MLX 배포 페이지에서 설치 방법을 확인한 뒤 사용할 수 있습니다.

mlx_lm.generate \
  --model mlx-community/VibeThinker-3B-8bit \
  --max-tokens 8000 \
  --temp 1.0 \
  --top-p 0.95 \
  --prompt "한국 속담 '서당 개 삼 년이면 풍월을 읊는다'의 뜻을 설명하고, 비슷한 의미의 다른 속담을 두 개 들어라."

샘플링을 사용하는 설정이므로 다시 실행하면 답변이 달라질 수 있습니다. 기존 기록에는 정확한 칩 세대, 도구 버전, 시드가 없어 완전히 같은 출력을 재현할 조건까지 갖추지는 못했습니다.
