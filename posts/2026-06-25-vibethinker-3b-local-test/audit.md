## 문장과 독자 점검

- 독자 상황 → 모델 설명 → 시험 의미 → 환경·판정 → 관찰 → 적용 범위 순으로 정리했습니다.
- 숫자, 모델 식별자, 기존 사용자 실험 주체, 실패와 불확실성을 보존했습니다.
- 존대어, 제목·소제목, 문단 연결, 중복, 표 설명을 다시 읽었습니다.
- 제목·구조 참고: 2026-09-30-gpt-6-1-sol-vs-opus-5-5 (ready), 2026-09-29-opus-5-5-vs-gpt-6-astra (ready), 2026-09-06-gpt-6-astra-vs-fable-5-1 (ready). 최신 Sonnet 번들은 reviewing이므로 완성 표본에서 제외합니다.
- 이 글은 모델 간 순위보다 기존 실행 기록의 질문별 차이를 중심으로 구성했습니다.
- 원문의 수치와 코드 결과를 새로 실행한 것처럼 표현하지 않았습니다.
