# Nate Herk 공개 집계 재계산

계산일: 2026-07-25  
계산 주체: Codex

## 입력

- Opus 5: 출력 약 2,000,000토큰, 10회, 평균 활성 시간 약 63분
- Fable 5: 출력 약 832,000토큰, 8회, 평균 활성 시간 약 25분
- 표준 출력 가격: Opus 5 $25/M, Fable 5 $50/M

## 계산

```text
Opus 실행당 출력 토큰 = 2,000,000 / 10 = 200,000
Fable 실행당 출력 토큰 = 832,000 / 8 = 104,000

Opus 실행당 출력 비용 = 200,000 / 1,000,000 × 25 = $5.00
Fable 실행당 출력 비용 = 104,000 / 1,000,000 × 50 = $5.20

Opus 출력 비용 절감률 = 1 - 5.00 / 5.20
                         = 0.0384615...
                         ≈ 3.85%

출력 토큰 사용량 배수 = 200,000 / 104,000
                       ≈ 1.923

평균 실행 시간 배수 = 63 / 25
                     = 2.52
```

## 손익분기식

두 모델의 입력·출력 비율과 캐시·도구 비용이 같다고 단순화합니다. Opus의
토큰 단가는 Fable의 절반이므로 Opus가 Fable보다 `T`배 토큰을 사용할 때
작업비 비율은 다음과 같습니다.

```text
Opus 작업비 / Fable 작업비 = T / 2
```

- `T = 1.5`: Opus 작업비는 Fable의 약 75%
- `T = 2.0`: 두 모델의 작업비가 같음
- `T > 2.0`: Opus가 더 비싸질 수 있음

## 해석 제한

- 입력 토큰, 프롬프트 캐시, 도구 호출 비용을 포함하지 않았습니다.
- 각 모델의 실행 수와 과제 구성이 완전히 같지 않습니다.
- 평균은 과제별 분산과 실패 비용을 보여 주지 않습니다.
- 이 결과는 전체 청구액이 아니라 출력 토큰 비용의 경계선을 보여 줍니다.
