# PER·PBR·EPS 선택 지도 문구 근거

## 독자 질문

`이익의 지속성`과 `장부가치 설명력`을 확인했을 때 PER·PBR·EPS 가운데
무엇을 먼저 봐야 하나요?

## 문구 지도

| 인포그래픽 문구 | 본문 근거 | 범위 |
|---|---|---|
| EPS 추세 + PER / PBR은 보조 | `업종보다 먼저 볼 두 가지 질문` 표의 이익 높음·장부 낮음 | 이익이 반복되는 기업 |
| PER + PBR / ROE로 교차 확인 | 같은 표의 이익 높음·장부 높음 | 세 배수의 동일 기간·자본 기준 필요 |
| PBR 먼저 / 자산의 질·정상 이익 | 같은 표의 이익 낮음·장부 높음 | PBR 단독 판정이 아님 |
| 세 지표만으로 부족 / 현금·사업 지표부터 | 같은 표의 이익 낮음·장부 낮음 | 적자 성장기업 등에서 억지 선택 금지 |
| 업종은 출발점일 뿐 | `업종별로 달라지는 출발 지표` 도입부 | 적정 배수나 절대 업종 규칙이 아님 |
| 같은 업종도 사업 모델과 성장 단계에 따라 위치가 달라짐 | 선택 지도 직후 문단 | 핵심 예외 |

## 제작 정보

- 유형: 선택
- 크기: 1080x1350, 4:5
- 제작 방식: HTML 안의 결정론적 SVG 조판 후 Playwright 래스터 렌더
- 최종 후보 소스: `per-pbr-eps-choice-map-infographic-v4.html`
- 렌더 스크립트: `render-per-pbr-eps-infographic-v4.cjs`
- 한글 글꼴: Apple SD Gothic Neo, AppleGothic 대체
- 권장 위치: `업종보다 먼저 볼 두 가지 질문` 절의 2축 표와 설명 바로 뒤
- 숫자: 없음
- 화살표: 축의 높아지는 방향과 `세 지표만으로 부족` 영역에서 다른 지표로
  이동하는 방향만 표시
