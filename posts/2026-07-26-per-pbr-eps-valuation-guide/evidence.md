## 직접 검증 설계

- 질문: 영업가치나 주가를 새로 추정하지 않고 회계 입력 하나만 바꿔도
  PER·PBR·EPS의 인상이 얼마나 달라지는가?
- 실행 주체: Codex
- 환경과 확인 시점: Python 3 표준 라이브러리, 2026-07-26
- 입력: 주가 10, 순이익 100, 자기자본 500, 유통주식 수 100인 가상 기준
  기업과 세 가지 변형 시나리오
- 전처리 또는 표현: 통화 단위는 임의 단위로 통일하고 주당 값은 소수 둘째
  자리, 배수는 소수 둘째 자리까지 반올림
- 비교·판정 규칙:
  1. EPS = 순이익 / 유통주식 수
  2. BPS = 자기자본 / 유통주식 수
  3. PER = 주가 / EPS, EPS가 0 이하면 N/A
  4. PBR = 주가 / BPS, BPS가 0 이하면 N/A
  5. 주가는 10으로 고정해 회계 입력의 민감도만 관찰
- 성공 기준: 일회성 손실, 자사주 매입, 순환적 이익 급증 가운데 적어도
  하나가 영업의 장기 성장과 다른 방향으로 지표를 움직임
- 반복 횟수와 표본 크기: 결정론적 계산 4개 시나리오, 각 1회
- 보존할 원자료:
  - `artifacts/metric_sensitivity.py`
  - `artifacts/metric-sensitivity-results.csv`

## 실패와 반례

- 실패한 입력: 순이익이 0이거나 음수인 시나리오는 PER을 유한한 양의 배수로
  계산할 수 없어 `N/A`로 처리합니다.
- 예상과 달랐던 결과: 자사주 매입 시나리오에서 EPS와 PER은 좋아 보이지만,
  현금 유출로 자기자본이 줄어 PBR은 2.00배에서 2.67배로 높아졌습니다.
- 일반화하면 안 되는 범위:
  - 네 시나리오는 특정 상장사의 실제 가치나 향후 주가를 재현하지 않습니다.
  - 손상·자사주·호황이 항상 같은 폭으로 지표를 바꾸는다는 뜻이 아닙니다.
  - 주가를 고정했으므로 시장 반응과 자본비용은 측정하지 않습니다.
  - 단순화한 기말 자본을 사용해 평균자본 기준 ROE와 정확히 연결하지 않습니다.

## 출처 메모

- 한국거래소 투자지표 가이드:
  `https://kind.krx.co.kr/external/dst/guidebook/investment_indicators.pdf`
  - PER은 최근 분기말 주가와 직전 4개 분기 EPS, PBR은 최근 분기말 주가와
    최근 분기 BPS를 사용하는 산식 예시를 제시합니다.
- IFRS IAS 33:
  `https://www.ifrs.org/issued-standards/list-of-standards/ias-33-earnings-per-share.html/`
  - 기본·희석 EPS의 분자와 가중평균 주식 수 원칙을 설명합니다.
- IFRS IAS 36:
  `https://www.ifrs.org/issued-standards/list-of-standards/ias-36-impairment-of-assets/`
  - 장부금액이 회수가능액을 넘으면 손상차손을 인식하고 장부금액을 낮추는
    원칙을 설명합니다.
- IFRS IAS 38:
  `https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2021/issued/part-a/ias-38-intangible-assets.pdf`
  - 연구 단계 지출은 발생 시 비용 처리하며, 개발 단계는 인식 요건을
    충족해야 무형자산으로 잡힙니다.
- Investor.gov P/E:
  `https://www.investor.gov/introduction-investing/investing-basics/glossary/price-earnings-pe-ratio`
  - 현재 주가를 EPS로 나눈 비율이며 과거·다른 회사와 비교하는 출발점으로
    설명합니다.
- Investor.gov Stocks FAQ:
  `https://www.investor.gov/introduction-investing/investing-basics/investment-products/stocks`
  - 낮은 P/E가 시장에서 외면받은 이유를 반영할 수도 있음을 설명합니다.
- Federal Reserve 공개 신청 자료:
  `https://www.federalreserve.gov/foia/files/mt-bank-application-20210322.pdf`
  - 은행 거래가격 비교에서 예상 이익 배수와 tangible book value 배수를 함께
    사용한 실제 사례입니다. 이를 은행 전체의 적정 배수로 일반화하지 않습니다.
