# 병행수입 두 축 인포그래픽 문구 근거

## 독자 질문

`병행수입`이라는 말은 정품·가품과 어떤 관계인가요?

## 문구 지도

| 인포그래픽 문구 | 본문·근거 | 범위 |
|---|---|---|
| 정품 여부와 수입 경로는 서로 다른 축 | 본문 `병행수입과 짭은 서로 다른 질문`, evidence C01-C04 | 두 축을 분리한 Codex 결정 프레임워크 |
| 정품 + 공식 유통망 → 공식수입품 | 본문 첫 번째 판정표 1행 | 브랜드의 국내 공식 수입·판매망 |
| 정품 + 공식망 밖 → 병행수입품 | 본문 첫 번째 판정표 2행, 관세청 정의 | 진정상품이라는 전제 |
| 가품 + 어떤 경로 주장 → 위조상품 | 본문 첫 번째 판정표 3행, 공정거래위원회 고시 | 병행수입이라는 판매 문구로 달라지지 않음 |
| 병행수입 문구만 있고 정품 근거가 없을 때 → 판정 보류 | 본문 첫 번째 판정표 4행, evidence C08 | 실제 상품의 정품 감정 결과가 아님 |
| 모델·판매자·정품 근거·A/S 주체를 따로 확인 | 본문 `병행수입 구매 전 30초 체크 네 칸` | 체크 완료가 정품을 100% 보증하지 않음 |

## 제작 정보

- 유형: 비교·판단
- 크기: 1080×1350, 4:5
- 제작 방식: 결정론적 HTML·SVG 조판 후 Playwright 래스터 렌더
- 소스: `parallel-import-two-axes-infographic.html`
- 렌더 스크립트: `render-parallel-import-infographic.cjs`
- 한글 글꼴: Apple SD Gothic Neo, AppleGothic, Noto Sans KR 대체
- 권장 위치: `병행수입과 짭은 서로 다른 질문` 절의 판정표 바로 뒤
- 숫자: 없음
- 화살표: 수입 경로가 공식 유통망과 공식망 밖 수입자로 갈라지는 선택만 표시
- 360px CSS 표시 환산:
  - 제목: 20px
  - 주요 판정: 16px
  - 보조 설명·축: 13px
