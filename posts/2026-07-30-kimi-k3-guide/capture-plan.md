# 캡처 계획: Kimi K3란? 중국 AI 모델의 특징·성능과 현실적인 사용법

## 독자 과업

- 글을 읽은 뒤 완료할 작업: Kimi K3가 어떤 AI인지 이해하고, 비개발자는
  웹에서 `K3`를 선택하며 개발자는 Kimi Code의 `k3` 또는 API의
  `kimi-k3`로 시작합니다.
- 시작 상태와 전제 조건: Kimi K3라는 이름은 낯설지만 ChatGPT·Claude처럼
  질문에 답하는 AI 서비스는 알고 있는 상태입니다.
- 가장 짧은 성공 경로: Kimi K3의 정체 확인 -> 특징과 성능 근거 이해 ->
  공개 가중치의 실제 규모 확인 -> 목적별 시작 경로 선택
- 이 글이 시험하지 않는 범위: 로그인 뒤 Kimi 세션, API 호출, Kimi Code
  실행, 가중치 다운로드·추론
