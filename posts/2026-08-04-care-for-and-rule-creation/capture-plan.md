# 캡처 계획: 창조세계를 돌보고 다스리라

## 독자 과업

- 주요 독자와 이 독자가 모른다고 가정할 내용: 창세기의 `다스리라`는 명령을
  자연 이용의 권리와 청지기의 책임 중 어떻게 읽어야 하는지 정리하고 싶은 독자
- 낯선 주제를 설명할 익숙한 기준: 자연을 쓸모 있는 자원으로만 볼 때와
  없어서는 안 될 생명의 터전이자 선물로 볼 때의 차이
- 글을 읽은 뒤 완료할 작업: 설교의 성경 해석과 실천 흐름을 이해한 뒤 자기
  `Thoughts`를 작성함
- 시작 상태와 전제 조건: 창세기 1장의 창조 이야기를 알고 있으나 설교 전체
  녹취는 읽지 않은 상태
- 비개발자가 시작할 가장 쉬운 경로: 제품 사용기가 아니므로 해당 없음
- 개발자·API·자체 배포로 확장할 경로: 해당 없음
- 가장 짧은 성공 경로: 사람과 자연의 관계 -> 다스림의 뜻 -> 죄와 복음 ->
  자연을 기뻐함 -> 작은 실천
- 이 글이 시험하지 않는 범위: 과학적 기후 데이터, 환경 정책 효과, 모든
  생태신학 입장

## 비교와 사용법

- 비교 대상과 개수: 해당 없음. 한 편의 설교를 정리함
- 점수·순위 판정 규칙: 해당 없음
- 벤더 자료와 독립 검증의 경계: 해당 없음. 사용자 제공 설교와 Codex의
  시간대별 대조를 구분함
- 실제 시작 URL·앱·메뉴·명령: 해당 없음
- 멤버십·결제·API Key·운영체제 조건: 없음
- 정확한 모델명·모델 ID·명령: 해당 없음
- 대표 첫 과제 또는 프롬프트: 해당 없음
- 공식 문서 링크: 중심 성경 본문 비교 URL을 `article.md`에 기록
- 가장 흔한 실패와 조건별 복구 방법: 자동 전사 오류를 원문처럼 확정하는
  문제를 피하기 위해 불명확한 고유명사와 원어를 공개 글에서 제외
