# 캡처 계획: Qwen3.8-Max 성능 비교, 중국 AI의 추격은 어디까지 왔나

## 독자 과업

- 주요 독자와 이 독자가 모른다고 가정할 내용: Qwen3.8-Max를 처음 보고,
  Qwen3.7-Max·Kimi K3와의 차이와 지금 쓸 수 있는 경로를 모르는 일반 AI 사용자
- 낯선 주제를 설명할 익숙한 기준: 제조사 성능표와 공개 사용자 선호도 평가를
  따로 확인한 뒤 제품을 고르는 과정
- 글을 읽은 뒤 완료할 작업: 벤더 표·Arena·가중치 공개 상태를 구분해 보고,
  웹·API·자체 배포 중 자신의 시작 경로를 선택합니다.
- 시작 상태와 전제 조건: ChatGPT·Claude 같은 대화형 AI는 알고 있지만 Qwen
  계정, Alibaba Cloud 계정, API Key는 없을 수 있습니다.
- 비개발자가 시작할 가장 쉬운 경로: 공식 Qwen Studio 링크에서
  `Qwen3.8-Max`가 선택됐는지 확인하고 대표 질문을 새 대화에서 시험합니다.
- 개발자·API·자체 배포로 확장할 경로: QwenCloud·Model Studio API Key와
  지역별 Base URL을 준비해 `qwen3.8-max`를 호출합니다. 자체 배포는 실제
  가중치와 라이선스가 공개된 뒤 검토합니다.
- 가장 짧은 성공 경로: 모델 정체 확인 -> 세 모델 사양·공개 상태 비교 ->
  공식표와 Arena 분리 해석 -> 웹 또는 API 선택
- 이 글이 시험하지 않는 범위: 모델 응답 생성, 결제, API 호출, 가중치 추론

## 비교와 사용법

- 비교 대상과 개수:
  - 사양·선택 비교 3개: Qwen3.8-Max, Qwen3.7-Max, Kimi K3
  - Qwen 공식 점수표 5개: Opus4.8, Fable5, GPT5.6 Sol (max),
    Qwen3.7-Max, Qwen3.8-Max
- 점수·순위 판정 규칙: 공식 표의 단일 점수 30행만 사용하고 높은 값 순으로
  행별 순위를 계산합니다. 단위가 다른 행을 합산·평균하지 않습니다.
- 벤더 자료와 독립 검증의 경계: 30행은 Qwen 벤더 표의 재계산이며, Arena는
  별도 운영되는 공개 선호도 리더보드의 2026-08-06 관찰값입니다.
- 실제 시작 URL·앱·메뉴·명령:
  - 웹: `https://chat.qwen.ai/?models=qwen3.8-max`
  - API: QwenCloud 또는 Alibaba Cloud Model Studio에서 API Key 생성 후
    OpenAI 호환 요청의 `model`에 `qwen3.8-max`
- 멤버십·결제·API Key·운영체제 조건:
  - 웹 첫 화면은 비로그인 상태에서 모델 선택을 확인했지만 실제 프롬프트 제출은
    시험하지 않았습니다. 로그인이나 이용 한도가 필요할 수 있습니다.
  - API는 계정·API Key·사용 지역에 맞는 Base URL과 사용료가 필요합니다.
  - 자체 배포는 8월 6일 현재 공개 파일이 없어 실행 조건을 확정할 수 없습니다.
- 정확한 모델명·모델 ID·명령: 표시명 `Qwen3.8-Max`, API ID `qwen3.8-max`
- 대표 첫 과제 또는 프롬프트: 기존에 정답과 완료 기준을 아는 작은 코딩 수정이나
  문서 비교를 맡기고, 근거·diff·실패 복구를 함께 확인합니다.
- 공식 문서 링크: Qwen 출시 글, QwenCloud 모델 문서, Alibaba Cloud 가격 문서
- 가장 흔한 실패와 조건별 복구 방법:
  - 웹에서 모델이 보이지 않으면 새로고침을 만능 해결책으로 제시하지 않고,
    공식 직링크의 선택 표시와 계정·지역·이용 자격을 먼저 확인합니다.
  - API `model not found`는 API Key와 Base URL이 같은 서비스·지역에서 발급된
    조합인지 확인합니다.
  - 로컬 설치 파일이 없으면 비공식 저장소를 대신 쓰지 말고 공식 Qwen 조직의
    모델 카드·라이선스가 공개될 때까지 기다립니다.
