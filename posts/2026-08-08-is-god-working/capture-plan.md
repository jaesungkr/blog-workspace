# 캡처 계획: 하나님은 정말 일하고 계신가 - 자유의지 앞에서 멈춘 질문

## 독자 과업

- 주요 독자와 이 독자가 모른다고 가정할 내용: 교회의 설명을 믿고 싶지만 자유의지와 하나님의 개입이 어떻게 함께 성립하는지 정리하지 못한 독자
- 낯선 주제를 설명할 익숙한 기준: 좋은 결과와 나쁜 결과에 같은 설명 기준이 적용되는지 비교
- 글을 읽은 뒤 완료할 작업: 자신의 의심을 불신으로 몰아붙이지 않고 질문의 정확한 위치를 확인
- 시작 상태와 전제 조건: 기독교가 하나님을 사랑하고 전능하며 일하시는 분으로 말한다는 정도만 알고 있음
- 비개발자가 시작할 가장 쉬운 경로: 해당 없음 - 묵상형 읽기 글
- 개발자·API·자체 배포로 확장할 경로: 해당 없음
- 가장 짧은 성공 경로: 도입 -> 설명의 비대칭 -> 개입과 강제의 구분 -> 미결 결론
- 이 글이 시험하지 않는 범위: 하나님의 존재 증명과 모든 신정론의 비교

## 비교와 사용법

- 비교 대상과 개수: 좋은 결과에 적용되는 설명과 나쁜 결과에 적용되는 설명, 2개 흐름
- 점수·순위 판정 규칙: 해당 없음
- 벤더 자료와 독립 검증의 경계: 해당 없음
- 실제 시작 URL·앱·메뉴·명령: 해당 없음
- 멤버십·결제·API Key·운영체제 조건: 해당 없음
- 정확한 모델명·모델 ID·명령: 해당 없음
- 대표 첫 과제 또는 프롬프트: 해당 없음
- 공식 문서 링크: 해당 없음
- 가장 흔한 실패와 조건별 복구 방법: 질문을 교리의 정답이나 무신론의 결론으로 성급히 봉합하지 않음
