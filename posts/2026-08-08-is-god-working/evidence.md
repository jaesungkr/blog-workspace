## 직접 검증 설계

- 질문: 사용자가 제기한 여러 문장을 하나의 일관된 논증으로 배열했을 때 어디에서 설명이 멈추는가?
- 실행 주체: 공동 - 사용자가 질문과 판단을 제공하고 Codex가 논리 순서를 정리함
- 환경과 확인 시점: 2026-08-08 대화
- 입력: 사용자의 질문 6개와 후속 설명 요청
- 전처리 또는 표현: 비꼼과 감정의 강도는 지우지 않되 공개 글에서는 논점 중심의 존대어로 정리
- 비교·판정 규칙: 사용자에게 없는 신앙 결론을 추가하지 않고, `가능한 설명`과 `해결된 설명`을 분리
- 성공 기준: 제목과 소제목만 읽어도 `일하심 -> 결과 -> 자유의지 -> 개입 -> 미결`의 흐름이 보이며 결론을 억지로 닫지 않음
- 반복 횟수와 표본 크기: 한 대화 흐름, 핵심 질문 6개
- 보존할 원자료: `artifacts/user-conversation-summary.md`

## 실패와 반례

- 실패한 입력: `교회가 항상 이렇게 말한다`거나 사용자가 특정 설명을 자주 들었다는 빈도는 원자료로 확인할 수 없어 본문을 `제가 문제 삼는 설명`으로 제한함
- 예상과 달랐던 결과: 논점의 중심은 자유의지 자체보다 좋은 결과와 나쁜 결과에 설명 기준이 달라지는 비대칭이었음
- 일반화하면 안 되는 범위: 이 글만으로 하나님의 존재 여부, 모든 교단의 섭리론, 악의 문제 전체를 판정할 수 없음
