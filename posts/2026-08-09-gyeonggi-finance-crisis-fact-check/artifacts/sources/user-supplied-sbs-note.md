# 사용자 제공 SBS 기사 메모

- 수신일: 2026-08-09 KST
- 원문 URL: https://news.sbs.co.kr/news/endPage.do?news_id=N1008695099
- 제공 형태: 사용자가 기사 본문을 대화에 붙여 넣음
- 직접 접근 결과: 웹 도구에서 원문 페이지를 열지 못해 사용자 제공 본문을 근거로 사용

## 기사에서 확인한 핵심

- 추미애 경기도지사는 과도한 복지정책 때문에 재정난이 생겼다는 주장을 반박했습니다.
- 지사는 아이와 고령인구가 함께 늘어 보육·교육·돌봄·의료·교통·주거 지출이 증가한다고 설명했습니다.
- 지사는 경기도 본청이 법인지방소득세를 직접 걷지 못하고 취득세 의존도가 높다는 세입 구조를 지적했습니다.
- 정치권에서는 전임 도정의 재정 운용과 복지정책 책임론이 이어지고 있습니다.

## 사용 경계

- SNS 원문을 직접 확인했다고 쓰지 않습니다.
- 기사에 담긴 지사의 인과 해석은 `정치권 주장`으로 표시합니다.
- 인구·세목·재정 수치는 별도 공식 자료로 검증한 범위에서만 본문에 사용합니다.
