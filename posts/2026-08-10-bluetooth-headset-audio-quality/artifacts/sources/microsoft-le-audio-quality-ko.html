    Windows 11 Bluetooth LE 오디오 품질 설정 구성

    Bluetooth LE Audio는 저전력 Bluetooth LE 라디오를 통해 오디오 스트리밍을 지원하며 Bluetooth 클래식 오디오에 비해 향상된 오디오 품질과 대기 시간을 제공합니다. Bluetooth LE 오디오 장치를 Bluetooth LE 오디오를 지원하는 Windows 11 PC와 함께 사용하면 마이크를 사용하는 동안 재생 오디오 품질이 슈퍼 와이드밴드 충실도로 향상됩니다.

    Windows 11(빌드 26100.4484 이상)에 대한 최신 업데이트와 PC 제조업체의 Bluetooth 드라이버 업데이트로 일부 Windows PC는 마이크를 사용하는 동안 스테레오 재생을 지원하여 오디오 품질을 더욱 향상시킬 수 있습니다.

    마이크를 사용하는 동안 Windows 11 PC 및 Bluetooth 오디오 디바이스가 스테레오 재생을 지원하는 경우 Windows는 기본적으로 스테레오 모드로 스트리밍됩니다. 마이크를 사용하는 동안 오디오에 문제가 있는 드문 경우 모드를 다시 모노로 변경할 수 있습니다.

    하드웨어 및 소프트웨어 호환성

    마이크를 사용하는 동안 스테레오 오디오를 사용하려면 PC가 Windows 11, 버전 24H2 이상을 실행하고 공장에서 Bluetooth LE를 통합 지원해야 합니다. 또한 스테레오 기능을 갖춘 Bluetooth LE Audio를 지원하기 위해 제조업체의 필수 드라이버가 있어야 합니다.

    Windows PC에서 LE 오디오를 지원하는 경우 검사 방법에 대해 자세히 알아보기

    Bluetooth LE 오디오를 지원하는 Bluetooth 헤드폰, 이어버드 또는 스피커도 필요합니다. Bluetooth를 통해 스테레오 오디오는 Bluetooth LE 오디오 보조 청각 장치에서도 지원됩니다.

    Windows 11 PC에서 청각 장치를 사용하는 방법에 대해 자세히 알아보기

    참고

    PC 또는 주변 장치가 LE 오디오를 지원하지 않거나 필요한 드라이버 지원이 없는 경우 마이크를 사용할 때 모노 오디오가 들립니다.

    스테레오 재생 구성

    Bluetooth LE 오디오 디바이스 페어링 및 연결

    오디오 품질 설정을 조정하려면 Bluetooth LE 오디오 디바이스를 페어링하고 Windows PC에 연결해야 합니다.

    Windows에서 Bluetooth 디바이스를 페어링하는 방법에 대해 자세히 알아보기

    오디오 설정 조정

    1. 설정>시스템>사운드로 이동한 다음 출력 섹션 아래의 Bluetooth LE 오디오 디바이스 오른쪽에 있는 을 클릭합니다>.

    2. 출력 설정>형식 요소 확장

    3. 마이크가 활성 상태일 때 형식 드롭다운에서 원하는 오디오 형식을 선택합니다.

      • Mono(1개 채널)
      • 스테레오(채널 2개)

    참고

    마이크가 활성 상태일 때 형식 요소가 표시되지 않으면 마이크가 활성화된 동안 시스템에서 스테레오 오디오를 지원하지 않습니다. 최신 OS 및 드라이버 업데이트가 있는지 확인하세요. 그렇지 않으면 PC 제조업체에 문의하여 자세한 내용을 확인하세요.

    오디오 문제 해결

    마이크가 활성 상태인 경우 형식 드롭다운은 기본적으로 스테레오(2개 채널)로 설정됩니다. 일부 Bluetooth 액세서리는 마이크가 활성 상태인 동안 스테레오 오디오를 렌더링하는 데 문제가 발생할 수 있습니다. 오디오 손실 또는 중단 결함과 같은 Bluetooth 오디오 액세서리에 문제가 발생하는 경우 설정을 모노(1 채널)로 변경하여 호환성을 개선해 보세요.

    모노 오디오 접근성 설정 상호 작용

    설정>접근성>오디오에서 시스템 차원의 모노 오디오 토글을 사용하도록 설정하면 스테레오 오디오가 제대로 작동하지 않을 수 있음을 나타내는 경고 배너가 표시됩니다. 스테레오 오디오가 필요한 경우 시스템 차원의 모노 오디오 토글을 사용하지 않도록 설정합니다.
