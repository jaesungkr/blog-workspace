# 기획: 게임·디스코드에서 블루투스 이어폰 음질이 나빠질 때 해결법

## 분류와 독자

- 상위 카테고리: `Log`
- 하위 카테고리: `개발 · 디지털`
- 한 명의 독자: Windows 11에서 게임이나 Discord 음성 채팅을 시작하면 블루투스 이어폰 소리가 갑자기 먹먹해지는 사용자
- 검색 의도: 고장 여부를 판단하고, 지금 가진 장비에서 가장 간단한 해결 방법을 찾고 싶음
- 독자가 이미 아는 것: Windows와 Discord에서 출력·입력 장치를 바꿀 수 있다는 정도

## 글의 중심

- 독자가 기억할 한 문장: Discord 입력 장치를 별도 마이크로 바꾸는 것이 가장 먼저 할 일이며, 그대로라면 출력 장치와 LE Audio 지원만 추가로 확인합니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 평소 음악은 선명한데 Discord 통화에 들어가는 순간 소리가 전화 통화처럼 얇고 답답해지는 장면
- 이 글이 답하지 않는 범위: 특정 이어폰 펌웨어 결함, 무선 간섭, 게임별 음향 버그, 드라이버 재설치 전반, macOS·모바일 해결법
- 가장 정직한 한계 또는 반론: Bluetooth LE Audio와 스테레오 마이크 동시 사용을 지원하는 최신 PC·이어폰 조합은 같은 현상이 나타나지 않을 수 있으며, 메뉴는 하드웨어와 드라이버에 따라 다릅니다.

## dev.log만의 근거

- first-party contribution: 증상 발생 시 `블루투스 마이크인가 통신용 출력인가 -> Classic인가 LE Audio인가 -> 별도 입출력으로 분리할 수 있는가` 순서로 판단하는 3단계 진단표
- 실제 실행 주체: `Codex`
- 보존할 원자료: `artifacts/sources/`에 저장할 Microsoft·Discord 공식 문서 스냅숏과 미디어 원본
- 기존 글 또는 시리즈 연결: `Log > 개발 · 디지털`의 Windows 문제 해결 글
- 다른 블로그 이름으로 바꿔도 성립하는 부분: A2DP·HFP의 일반 설명. dev.log에서는 공식 문서의 예외 조건을 반영한 진단 순서와 해결 선택 기준에 무게를 둡니다.

## 설명 순서

| 순서 | 독자가 먼저 알아야 할 것 | 다음 내용과의 연결 |
|---|---|---|
| 1 | Discord 입력 장치를 별도 마이크로 바꿈 | 한 번의 설정으로 해결되는지 확인 |
| 2 | 그대로라면 Discord 출력을 다른 장치로 바꿈 | 통신용 출력 조건을 분리 |
| 3 | 이어폰 하나로 말하고 들으려면 LE Audio 지원을 확인 | 지원되지 않으면 별도 마이크와 모노 품질 중 선택 |

## 중앙 방법의 계산 또는 판단 사슬

`음질 저하가 시작된 순간 확인 -> 블루투스 마이크와 통신용 출력 분리 -> Classic/LE Audio 지원 확인 -> 별도 입출력 또는 지원되는 품질 옵션 선택`

## 보조 인포그래픽 판단

- 결정: `없음`
- 한눈에 보여 줄 관계: A2DP 출력과 HFP 마이크·출력의 차이는 본문 내 2열 비교 카드로 표현합니다.
- 글이나 표만으로 충분하지 않은 이유: 해당 없음. 별도 인포그래픽을 추가하면 Tistory 업로드 부담에 비해 정보 이득이 작습니다.
- 유형: `비교 | 문제 해결`
- 핵심 설명 뒤 권장 위치: 본문 내 HTML 비교 카드로 대체
- 추가 이미지가 있다면 각 이미지가 답할 서로 다른 질문: 생성형 리드는 증상을 시각적으로 붙잡고, 공식 스크린샷 1은 Discord 입력 장치 위치, 공식 스크린샷 2는 지원되는 PC에서 LE Audio 품질 선택 위치를 보여 줍니다.

## 독자 마찰 스크린샷 판단

- 진입점: Discord의 `사용자 설정 > 음성 및 비디오` 위치는 공식 UI 스크린샷 후보로 남깁니다.
- 선택: 헤드셋 마이크 대신 사용할 `입력 장치`를 고르는 화면은 선택 실수를 줄이므로 포함합니다.
- 확인: LE Audio 지원 PC에서만 보이는 `마이크가 활성 상태일 때 형식` 항목은 기능 지원 여부 자체를 확인하는 표식이므로 포함합니다.
- 배제한 화면: Windows의 기본 출력·입력 장치 목록은 `설정 > 시스템 > 소리` 경로만으로 찾기 쉬워 제외합니다. 장치 관리자와 레거시 제어판 화면은 첫 해결에 필요하지 않고 환경별 차이가 커서 제외합니다.
