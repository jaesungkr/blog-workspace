안녕하세요. dev.log입니다.

제목의 ‘일론 머스크의 애착 에이전트’는 공식 명칭이 아닙니다. Grok Bot은 xAI가 사내 프로토타입으로 만들었다가 여러 팀으로 사용 범위가 넓어진 별도 제품입니다. 공식 출시 글에는 일론 머스크 개인의 사용기도 나오지 않습니다.

Grok Bot은 **한 번 질문하고 답을 받는 챗봇이 아니라, 전용 컴퓨터에서 앱과 웹사이트를 열어 여러 단계를 처리하는 AI 작업자**에 가깝습니다. 같은 자료를 매일 확인하거나 여러 서비스 사이에서 반복되는 일을 통째로 맡기고 싶을 때 차이가 드러납니다.

처음에는 메일 발송이나 결제보다 `자료 읽기 -> 분류 -> 초안 만들기`처럼 되돌리기 쉬운 일 하나를 맡겨 보세요. 결과를 사람이 확인한 뒤 다음 행동을 승인하는 방식이 가장 안전한 출발점입니다.

이 글은 공식 공개 페이지와 데모 화면에서 확인한 범위만 다룹니다. Grok Bot 앱을 설치하거나 실제 계정으로 외부 서비스를 조작하지는 않았습니다.

{{media:grok-bot-landing}}

### Grok Bot은 답변이 아니라 앱 안의 결과를 만드는 도구

일반 Grok 대화는 질문에 답하거나 글·이미지를 만드는 데 초점이 있습니다. [Grok Automations](https://x.ai/news/grok-automations)는 같은 지시를 정해진 시각이나 이메일 수신 조건에 맞춰 다시 실행합니다. Grok Bot은 여기서 한 단계 더 나아갑니다. 전용 클라우드 컴퓨터에 로그인된 실제 도구를 사람처럼 조작합니다.

| 선택지 | 잘 맞는 일 | 실행 방식 |
|---|---|---|
| Grok 대화 | 한 번의 조사, 요약, 글쓰기 | 현재 대화에서 답을 만듭니다. |
| Grok Automations | 아침 뉴스, 이메일 감시처럼 반복되는 정보 작업 | 일정이나 이메일을 조건으로 새 요청을 실행합니다. |
| Grok Bot | CRM 정리, 버그 재현처럼 여러 앱을 오가는 작업 | 클라우드 컴퓨터에서 웹과 앱을 직접 사용합니다. |

[공식 출시 글](https://x.ai/news/introducing-grok-bot)은 CRM에 통화 메모를 옮기고 후속 메일을 작성하거나, 제품 화면에서 버그를 재현해 티켓과 증거를 남기는 사례를 소개합니다. 정식 연동 기능이 없는 웹사이트도 화면을 따라 조작할 수 있다는 점이 Bot의 가장 큰 차이입니다. 이는 2026년 8월 11일 공개된 초기 베타의 공식 설명이며, 독립적인 정확도나 성공률 검증은 아직 없습니다.

### 처음 맡길 일은 수집·정리·초안 만들기

2026년 8월 13일에 [공식 활용 사례 페이지](https://x.ai/bot/use-cases)를 확인했을 때 56개 예시가 공개돼 있었습니다. 영업, 마케팅, 고객 지원, 채용, 재무, 제품, 엔지니어링뿐 아니라 일정·여행 같은 개인 업무도 포함됩니다.

{{media:grok-bot-use-cases}}

목록이 길어도 첫 Bot은 아래 세 종류 중 하나로 좁히는 편이 좋습니다.

- **읽기와 요약**: Slack·이메일·캘린더를 훑고 오늘 볼 내용만 출처와 함께 정리합니다.
- **점검과 증거 수집**: 스테이징에서 버그를 재현하거나 관측 도구를 열어 스크린샷과 재현 단계를 모읍니다.
- **검토할 초안**: 후속 메일, 게시물, 보고서, 광고 예산 조정안을 만들되 전송이나 적용은 보류합니다.

첫 작업부터 메일을 보내거나 광고비를 바꾸고, 여행을 예약하거나 결제를 처리하게 두면 잘못된 판단의 비용이 커집니다. 공식 예시도 메일 전송, 캠페인 조정, 예약 같은 행동은 사람이 검토하거나 승인하는 흐름을 반복해서 보여 줍니다.

### 7일 체험 제공 여부 확인과 데스크톱 앱 설치

시작 위치는 X의 Grok 채팅 메뉴가 아니라 [Grok Bot 공식 페이지](https://x.ai/bot)입니다. 유료 이용 대상은 Cursor Ultra, SuperGrok Heavy, Cursor Premium Teams 구독자입니다. 2026년 8월 14일 [AI Freaks가 Instagram에 공개한 가입 화면 캡처](https://www.instagram.com/p/Db-PtJSGjiu/?img_index=6)에는 **7일 무료 체험** 선택지가 표시돼 있습니다.

무료 체험 안내 화면에는 `One Week Trial`과 함께 다음 조건이 표시됩니다.

- 결제 카드를 등록해야 합니다.
- 모든 기능에 접근할 수 있지만 사용량은 제한됩니다.
- 사용자가 별도로 구독하지 않으면 카드에 요금이 청구되지 않습니다.

[Grok Bot 가입 화면](https://cursor.com/bot/onboarding?product=grok-bot)으로 들어가면 Cursor 계정 로그인이 먼저 열립니다. 이메일·Google·GitHub·Apple로 로그인할 수 있고, SuperGrok Heavy를 이용 중이라면 Grok 계정을 연결하는 선택지도 보입니다. 로그인 이후의 체험 선택 화면은 독립적으로 재현하지 못했습니다. 계정·지역에 따라 제공 여부가 다를 수 있으므로, 카드 등록 직전 화면에서 7일 종료일과 청구 문구를 한 번 더 확인하세요.

1. 공식 페이지에서 macOS 또는 Windows 앱을 내려받습니다.
2. Cursor 계정으로 로그인하고, 계정에 7일 체험이 표시되면 조건을 확인해 선택합니다.
3. 첫 Bot을 만들고 한 가지 역할을 붙입니다. `Chief`처럼 넓은 이름보다 `아침 브리핑`, `버그 재현`, `메일 초안`처럼 결과가 보이는 역할이 좋습니다.
4. 대화창에 첫 작업을 보냅니다. 앱 내부 버튼과 배치는 초기 베타에서 바뀔 수 있으므로, 이 글은 공개 화면에서 확인되는 메시지 중심 흐름까지만 안내합니다.

지원 기기는 macOS의 Apple Silicon·Intel, Windows 10·11 x64, iPhone·iPad입니다. Android 앱은 공식 페이지에서 `Coming soon`으로 표시돼 있었습니다. 데스크톱에서 시작한 대화는 iOS에서 이어갈 수 있지만, Bot의 작업은 사용자의 휴대폰이나 노트북이 아니라 클라우드 컴퓨터에서 계속됩니다.

7일을 기능 구경으로만 보내지 않으려면 시험할 업무를 먼저 정해 두는 편이 좋습니다.

| 체험 구간 | 확인할 것 | 성공 기준 |
|---|---|---|
| 1~2일 | 테스트용 도구 로그인과 단발 작업 | 자료를 읽고 초안에서 멈춥니다. |
| 3~4일 | 실제 반복 업무 한 가지 | 수정 지시를 반영해 같은 형식으로 다시 만듭니다. |
| 5~7일 | Routine 또는 Bot 역할 분리 | 시간을 줄일 만큼 재사용 가능하고 승인 지점이 분명합니다. |

업무 한 번이 일반 Grok 대화보다 크게 낫지 않거나, 로그인·수정에 드는 시간이 더 길다면 월 200달러 요금제로 넘어갈 이유가 약합니다. 무료 기간에는 기능 수보다 **매주 반복할 한 가지 일을 끝까지 넘길 수 있는지**를 확인하세요.

### 첫 지시는 목표·자료·완료 조건·금지 행동까지

Bot에게 동료처럼 메시지를 보내되, 첫 요청은 아래 네 가지를 넣어 구체적으로 작성합니다.

```text
목표: 오늘 오전에 들어온 고객 문의를 주제별로 분류해 줘.
자료: Zendesk의 미처리 티켓만 확인해.
완료 조건: 긴급도, 한 줄 요약, 답변 초안을 표로 정리해.
금지 행동: 답변을 전송하지 말고 초안에서 멈춰. 애매하면 나에게 물어봐.
```

작업에 필요한 웹사이트가 로그인돼 있지 않으면 Bot이 자신의 `Computer` 화면을 열고 로그인을 요청합니다. 이때 비밀번호를 대화에 적지 말고, 사용자가 화면에서 직접 로그인하는 편이 안전합니다. 로그인 뒤에는 Bot이 같은 사이트를 다시 열어 작업을 이어갑니다.

{{media:grok-bot-workflow}}

Bot이 결과를 가져오면 자료 범위가 맞는지, 누락은 없는지, 외부에 영향을 주는 행동이 남아 있는지 먼저 확인하세요. 수정할 점은 다음 메시지에서 구체적으로 알려 주면 됩니다.

### 반복 작업은 Routine으로 저장하고 큰 일은 Bot별로 분리

반복 업무라면 사용자가 작업하는 과정을 한 번 따라오게 할 수 있습니다. 공식 설명에 따르면 Bot은 그 순서를 `Routine`으로 저장하고, 다음부터 같은 다단계 작업을 다시 실행합니다. 예약 실행도 지원 요금제 기능에 포함됩니다.

업무가 커졌다고 모든 조건을 한 Bot에 계속 붙일 필요는 없습니다. 예를 들어 `Research`가 자료를 모으고, `Comms`가 초안을 쓰고, `Chief`가 우선순위를 정하도록 역할을 나눌 수 있습니다. 여러 Bot은 같은 대화방에서 서로 메시지를 보내고 작업을 넘길 수 있습니다.

공식 FAQ에 따르면 **한 사용자의 여러 Bot은 하나의 지속형 클라우드 컴퓨터와 그 안의 파일·브라우저 로그인 정보를 공유**합니다. Bot마다 격리된 컴퓨터가 따로 생기지 않습니다. 서로 다른 고객사나 보안 등급의 작업을 같은 계정에서 섞기 전에 이 공유 범위를 먼저 검토해야 합니다.

### 전송·결제·변경은 승인 뒤로 남기기

공식 영업 사례는 Bot이 계정을 조사하고 메일 초안을 만든 뒤, `Send email` 단계에서 사용자의 판단을 기다리는 장면을 보여 줍니다. 첫 Bot의 성공 기준도 “알아서 전부 실행”보다 “검토 가능한 결과를 남기고 멈춤”으로 잡는 편이 좋습니다.

{{media:grok-bot-approval}}

Grok Bot 페이지는 전송 중·저장 데이터 암호화, 학습 제외 선택, 민감 작업의 Auto Review를 보안 수단으로 안내합니다. 로그인한 도구와 파일을 Bot들이 공유하는 만큼, 다음 원칙은 작업 지시에도 직접 적어 두는 편이 좋습니다.

- 메일·DM·게시물은 초안까지만 만들고 전송 전 확인을 받습니다.
- 결제, 예약, 광고비 조정, 삭제, 제출은 실행 직전에 다시 승인받습니다.
- 비밀번호, 인증 코드, 주민번호, 금융·의료 정보는 메시지나 첨부 파일에 넣지 않습니다.
- 처음 보는 업무는 예약 실행보다 단발 작업으로 결과와 실패 지점을 먼저 확인합니다.

### 체험이 보였다면 월 200달러를 낼지 판단

2026년 8월 13일 공식 가격 표에는 개인용 Cursor Ultra가 월 200달러, Cursor Premium Teams가 좌석당 월 120달러로 표시돼 있습니다. SuperGrok Heavy 또는 Cursor Ultra 구독에는 Grok Bot이 포함되며, 주간 사용량을 넘으면 토큰 비용에 따라 추가 사용료가 붙을 수 있습니다. 가격과 포함 범위는 바뀔 수 있으므로 결제 전 [공식 페이지](https://x.ai/bot)를 다시 확인해야 합니다.

Grok Bot이 특히 잘 맞는 일은 **여러 웹 도구를 오가고, 매번 비슷한 판단 기준을 쓰며, 마지막 행동 전에 사람이 확인할 수 있는 업무**입니다. 단순한 아침 뉴스 요약만 필요하다면 Grok Automations가 더 가볍고, 한 번의 조사라면 일반 Grok 대화로 충분합니다. 반대로 매주 몇 시간씩 반복되는 브라우저 작업이 있고 7일 체험에서 Routine 재현까지 확인했다면 유료 전환을 검토할 근거가 생깁니다.

이 글은 Codex가 공개된 공식 페이지와 출시 글을 직접 탐색하고 화면을 캡처해 작성했습니다. Grok Bot 앱을 설치하거나 실제 계정을 연결해 외부 서비스에서 작업을 실행하지는 않았습니다. 따라서 앱 내부의 세부 조작, 장기 실행 안정성, 실제 비용과 성공률은 확인 범위에 포함하지 않습니다.
