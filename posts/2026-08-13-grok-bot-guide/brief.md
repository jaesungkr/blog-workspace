# 기획: Grok Bot 사용법, 일론 머스크의 애착 에이전트

## 분류와 독자

- 상위 카테고리: `Log`
- 하위 카테고리: `AI 개념 · 실전`
- 한 명의 독자: X에서 Grok을 질문·답변용으로만 써 봤고, Grok Bot으로 반복 작업을 맡겨 보고 싶은 입문자
- 검색 의도: Grok Bot의 정체, 7일 무료 체험, 실제 용도, 시작 위치, 설정 순서와 현재 한계를 한 번에 확인
- 독자가 이미 아는 것: X 계정과 일반적인 AI 챗봇의 질문 입력 방식

## 글의 중심

- 독자가 기억할 한 문장: Grok Bot은 계정에 표시되는 7일 무료 체험으로 반복 업무를 검증한 뒤 유료 전환을 판단할 수 있는, 전용 클라우드 컴퓨터 기반 AI 작업자입니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 매일 같은 시간에 X의 주요 반응을 찾아 요약하고 다음 행동을 정리해 달라고 맡기는 상황
- 이 글이 답하지 않는 범위: Grok 일반 채팅 사용법, API 개발, 요금제 전체 비교, 위험하거나 되돌리기 어려운 자동 실행
- 가장 정직한 한계 또는 반론: 로그인 없이 볼 수 있는 공식 공개 페이지와 데모 화면을 기준으로 확인하며, 앱 설치·계정 연결·결제·게시·메시지 전송처럼 외부에 영향을 주는 작업은 실제 실행하지 않습니다. 사용자 지정 제목의 ‘애착 에이전트’는 공식 명칭이나 일론 머스크 개인 사용을 입증하는 표현이 아닙니다.

- 실제 실행 주체: `Codex`
- 보존할 원자료: `artifacts/sources/web/`의 화면 캡처와 접근 시각, 공식 설명 원문
- 기존 글 또는 시리즈 연결:
- 다른 블로그 이름으로 바꿔도 성립하는 부분: 공식 기능 요약만으로는 성립하므로, 실제 화면에서 확인한 진입점·선택지·제약을 글의 중심 근거로 남깁니다.
