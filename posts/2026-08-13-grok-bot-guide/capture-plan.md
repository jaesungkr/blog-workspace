# 조건부 캡처 계획

## 독자 행동과 증거

| ID | 시작 상태 | 행동 | 기대 결과 | 필요한 캡처 |
|---|---|---|---|---|
| T01 | Grok Bot을 처음 들은 상태 | 공식 제품 페이지를 연다 | 별도 제품과 다운로드 위치를 알아본다 | 제품 첫 화면 |
| T02 | 무엇을 맡길지 모르는 상태 | 활용 사례를 분류별로 살핀다 | 첫 작업을 읽기·정리·초안 중 하나로 고른다 | 대표 활용 사례 카드 |
| T03 | 작업 방식이 추상적인 상태 | 로그인 요청과 Teach a task 카드를 본다 | 직접 로그인, 한 번 시연, Routine 저장 흐름을 이해한다 | 작동 방식 카드 |
| T04 | 자동 실행이 불안한 상태 | Sales Outbound 예시를 연다 | 초안과 전송 승인 사이의 경계를 알아본다 | 승인 대기 모달 |

## 실행 경계

- 실행자: Codex
- 제품·앱 버전: 공식 페이지가 연결한 Grok Bot 0.18.0 다운로드, 앱 자체는 설치하지 않음
- 운영체제·브라우저: macOS, Codex 인앱 브라우저, 1280×720
- 실행 날짜: 2026-08-13
- 직접 확인하지 못한 범위: 앱 설치, 계정 로그인, 타사 도구 로그인, 실제 작업 실행, Routine 생성, 비용·성공률 측정

## 개인정보 준비

- 공개 페이지와 공식 데모 데이터만 사용했습니다.
- 계정·비밀번호·토큰·개인 경로를 입력하지 않았습니다.
- 원본은 `artifacts/sources/web/`에 보존했습니다.
