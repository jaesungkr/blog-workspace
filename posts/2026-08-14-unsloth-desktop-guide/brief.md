# 기획: Unsloth Desktop이란? 코딩 없이 내 PC에서 AI를 학습하는 앱

## 분류와 독자

- 상위 카테고리: `Log`
- 하위 카테고리: `AI 개념 · 실전`
- 한 명의 독자: ChatGPT 같은 AI 채팅은 써 봤지만 로컬 AI, 파인튜닝, GPU 같은 말은 낯선 비개발자
- 검색 의도: Unsloth Desktop이 무엇이고 일반 AI 채팅과 어떻게 다른지, 자신의 컴퓨터에서도 쓸 수 있는지, 처음 무엇부터 해야 하는지 알고 싶음
- 독자가 이미 아는 것: AI에게 질문하면 답을 받을 수 있다는 정도. 공개 모델, GGUF, 양자화, LoRA, 학습 파라미터는 모름

## 글의 중심

- 독자가 기억할 한 문장: Unsloth Desktop은 공개 AI 모델을 내 컴퓨터에 내려받아 대화하고, 질문·답변 예시로 원하는 응답 방식을 학습할 수 있게 만든 화면형 앱입니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 웹 AI 채팅에서 같은 말투와 출력 형식을 매번 다시 요청하던 사람이 정답 예시를 모아 모델에 가르치는 장면
- 가장 쉬운 시작: `Train`보다 먼저 작은 GGUF 모델을 내려받아 채팅이 되는지 확인함
- 공개 본문에서 답하지 않는 범위: 특정 GPU별 속도·메모리 벤치마크와 학습 전후 품질 순위
- 근거 경계 처리: 미실행 사실을 독자에게 알리는 방어 문장은 쓰지 않음. 대신 직접 측정하지 않은 수치나 체험을 주장하지 않고, 공식 주장에는 출처를 붙이며 모델·백엔드별 차이를 행동에 필요한 범위에서만 설명함

## dev.log만의 근거

- first-party contribution: 공식 문서와 공개 UI를 비개발자의 질문 순서인 `무엇인가 -> 내 컴퓨터에서 가능한가 -> 무엇을 내려받나 -> 자료를 어떻게 준비하나 -> 어디서 시작을 확인하나`로 다시 분류함
- 실제 조사 주체: `Codex`가 공개 문서와 공식 화면의 정보 구조를 분석함. 이 역할은 내부 근거에 기록하되 공개 본문을 제작 과정 고지로 시작하지 않음
- 보존할 원자료: 공식 문서·릴리스·저장소 URL, 원본 스크린샷 파일과 해시, 화면별 독자 질문
- 기존 글 또는 시리즈 연결: 초보자가 이해할 만한 직접 연결 글이 확인되지 않아 억지 내부 링크를 넣지 않음
- 다른 블로그 이름으로 바꿔도 성립하는 부분: 제품 기능 요약만으로 끝내지 않고, 작은 채팅부터 시작하는 분리 진단과 99% 다운로드·첫 스텝의 차이를 실제 화면에 연결함
