## 3축 판정 설계

- 질문: 중국 AI는 한 번의 화제성 돌풍인가, 지속해서 비교해야 할 경쟁자 집단인가?
- 실행 주체: Codex
- 환경과 확인 시점: 공개 웹 자료, 2026-08-21 KST
- 입력: 같은 버전의 모델별 독립 지수와 API 가격, Stanford의 국가·오픈웨이트 생태계 지표, NIST의 반대 평가
- 처리: 성능, 경제성, 확산력으로 근거를 분리합니다.
- 판정 규칙:
  1. 성능 - 서로 다른 중국 개발사의 모델이 동일 독립 지수 버전에서 미국 선두 모델 점수의 85% 이상에 반복 진입하는가? 단, 추론 설정 차이는 따로 표시합니다.
  2. 경제성 - 중국 모델 중 둘 이상이 Fable 5뿐 아니라 GPT-5.6 Sol medium 출력 가격의 20% 이하인가?
  3. 확산력 - 다운로드뿐 아니라 새 파생 모델 비중에서도 중국 기반 모델의 증가가 확인되는가?
- 성공 기준: 세 축이 모두 충족되면 ‘단발성 돌풍’보다 ‘지속적 경쟁자 집단’으로 분류합니다. 다만 ‘미국을 전면 역전했다’고 쓰려면 투자·인프라·업무별 독립 평가까지 우위가 확인되어야 합니다.
- 보존할 원자료: `artifacts/china-ai-signal-snapshot.csv`

## 실패와 반례

- ‘AI 톱10에 중국 모델 4개’만으로 전체 산업 역전을 주장하면 평가 버전과 추론 설정을 숨기게 됩니다.
- 출력 토큰 가격만으로 ‘10분의 1 비용’을 일반화하면 입력 토큰, 캐시, 생성 길이, 실패 후 재시도 비용이 빠집니다.
- DeepSeek 한 모델의 NIST 결과를 중국 전체로 확대하면 Kimi·Qwen·GLM의 현재 성능을 놓칩니다.
- 반대로 Stanford의 2.7% 격차를 모든 업무의 체감 차이로 읽으면 코딩·보안·장문·한국어 등 작업별 편차를 지웁니다.
- 오픈웨이트는 배포와 수정 자유도를 높이지만 학습 데이터와 전 과정을 공개한다는 뜻은 아닙니다.
