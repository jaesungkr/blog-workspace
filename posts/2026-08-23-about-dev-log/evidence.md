## 직접 검증 설계

- 질문: 공개 블로그의 현재 카테고리와 기존 소개문 사이에 빠진 내용이 있는가?
- 실행 주체: Codex
- 환경과 확인 시점: 웹 공개 페이지, 2026-08-23 Asia/Seoul
- 입력: 기존 공지, 블로그 홈, Off.log 카테고리 페이지
- 비교·판정 규칙: 공개 내비게이션의 상위 카테고리 이름과 기존 소개문의 절 이름을 대조
- 성공 기준: 모든 현재 상위 카테고리가 새 소개문에 한 번씩 명시됨
- 반복 횟수와 표본 크기: 공개 페이지 3개를 각 1회 확인
- 보존할 원자료: `artifacts/public-site-review.md`
