# 기획: 세관에서 부름받은 마태

## 분류와 독자

- 상위 카테고리: `Reflections`
- 하위 카테고리: `성경 인물 시리즈`
- 시리즈: `성경 인물 알아가기` (7탄)
- 한 명의 독자: 마태라는 이름은 복음서 제목으로 알지만, 세관에서 부름받은
  인물 마태와 어떻게 연결되는지 모르는 성경 입문 독자
- 검색 의도: `마태`, `성경 마태`, `마태는 어떤 사람`, `세리 마태` - 복음서
  제목으로 익숙한 이름과 성경에 기록된 대표 장면을 쉽게 연결하고 싶음
- 독자가 이미 아는 것: 신약성경에 마태복음이 있다는 정도. 당시 세금 징수원,
  열두 제자, 레위라는 이름에는 설명이 필요함

## 글의 중심

- 독자가 기억할 한 문장: 마태는 세관에 앉아 있다가 예수님의 `나를 따라오라`는
  부름을 받고 일어나 따랐으며, 뒤이어 여러 세금 징수원과 사람들이 예수님과
  함께 식사한 장면에 등장하는 열두 제자입니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 삭개오 편에서 만난 세금 징수라는 일을
  떠올리되, 이전 글을 읽지 않은 독자도 `여리고의 세무서장 삭개오 / 세관의
  세무원 마태`라는 짧은 설명만으로 두 사람의 공통점과 차이를 이해하게 함
- 문을 여는 성경 본문: 마태복음 9:9의 세관과 부르심을 풀어 쓰고, 예수님의
  짧은 말씀 `나를 따라오너라`만 직접 인용함
- 본문 전체를 끌 질문: 한 문장뿐인 부르심 뒤에 마태에 관해 무엇이 직접
  기록되어 있으며, 복음서 제목으로 아는 마태와 어디까지 연결할 수 있을까?
- 이 글이 답하지 않는 범위: 마태의 어린 시절과 성격, 레위와 동일 인물이라는
  단정, 마태복음 집필 과정과 연대, 성경 밖 선교지와 죽음
- 가장 정직한 한계 또는 반론: 교회 전통은 세 평행 장면의 대응을 근거로
  마태와 레위를 같은 인물로 이해하지만, 복음서 본문은 두 이름의 관계나 이름이
  달라진 이유를 직접 설명하지 않음

## 설명 순서

| 순서 | 독자가 먼저 알아야 할 것 | 다음 내용과의 연결 |
|---|---|---|
| 1 | 삭개오와 마태는 모두 세금 징수와 연결되지만 직책과 직접 기록은 다름 | 세관에 앉아 있다가 부름받은 마태의 첫 장면으로 이동 |
| 2 | 식탁에 여러 세금 징수원과 사람들이 함께 있었음 | 왜 사람들이 예수님을 비판했고 예수님이 무엇이라고 답했는지 확인 |
| 3 | 마태는 열두 제자 명단에 포함됨 | 개인 기록이 많지 않다는 한계와 마지막 명명 장면으로 연결 |
| 4 | 평행 본문은 서로 다른 복음서에서 사건 흐름이 대응하는 장면이며, 마가·누가복음은 세관의 인물을 레위라고 기록함 | `마태 / 레위 / 열두 제자 명단`을 순서대로 정리한 뒤 본문이 이름 관계를 직접 설명하지 않는 범위를 구분 |
| 5 | 마태복음 저자라는 이름은 오랜 교회 전승에 속함 | 성경 본문에서 확인되는 마태와 후대 전승을 나눠 기억하며 마무리 |

## 중앙 방법의 계산 또는 판단 사슬

`마태·레위가 나오는 정경 본문 수집 -> 사건·인물·직접 발화 단위 분류 ->
평행 장면과 명단 대조 -> 직접 기록과 전승의 경계가 표시된 passage map`

## 보조 인포그래픽 판단

- 결정: `없음`
- 한눈에 보여 줄 관계: 마태복음의 마태와 마가·누가복음의 레위가 같은
  부르심 장면에 놓이는 관계
- 글이나 표만으로 충분하지 않은 이유: 세 본문의 이름 차이는 짧은 문단과
  본문 참조만으로 이해할 수 있으며, 별도 도식은 따뜻한 인물 소개의 흐름을
  끊고 업로드 부담만 늘림
- 유형: `비교`
- 핵심 설명 뒤 권장 위치: 해당 없음
- 추가 이미지가 있다면 각 이미지가 답할 서로 다른 질문: 해당 없음

## 독자가 이어서 물을 질문

- 마태는 어떤 일을 하던 사람이었나요? -> 마태복음은 그가 세관에 앉아
  있었다고 기록하고, 열두 제자 명단에서는 `세금 징수원 마태`라고 부름
- 예수님의 부름을 받은 뒤 무엇을 했나요? -> 마태는 일어나 따랐고, 이어진
  식사 자리에는 여러 세금 징수원과 사람들이 함께 있었음
- 마가복음과 누가복음에서 왜 갑자기 레위가 나오나요? -> 세관, 부르심, 일어나
  따름, 식사, 질문과 대답이 대응하는 평행 본문이기 때문임. 마태복음은 마태,
  마가·누가복음은 레위라고 적고 제자 명단에는 마태만 나옴. 교회 전통에서는
  같은 인물로 이해하지만, 본문은 두 이름의 관계나 이름이 달라진 이유를 직접
  설명하지 않음
- 마태가 마태복음을 직접 썼나요? -> 마태 저자 전승은 오래되었지만 복음서
  본문 자체에는 저자 이름이 적혀 있지 않으므로 전승으로 소개함
- 마태는 이후 어디에서 무엇을 했나요? -> 열두 제자 명단과 사도행전 1장의
  기도 모임에 이름이 나오지만, 성경 밖 선교와 죽음 이야기는 이번 글에서 제외함

## 제목 후보

1. 세관에서 부름받은 마태 (최종 선택)
2. 식탁으로 예수님을 맞은 마태
3. 세금 징수 자리에서 일어난 마태

최종 선택 이유: 마태복음 9장의 장소와 부르심을 짧게 담고 인물명 `마태`를
제목 끝에 두는 시리즈 규칙을 지킵니다. `식탁으로 예수님을 맞은`은 누가복음의
레위 장면을 마태에게 곧바로 옮길 위험이 있고, 세 번째 후보는 정확하지만
첫 번째보다 길고 리듬이 무겁습니다.
