## 직접 검증 설계

- 질문: 신약성경에서 마태라고 이름 붙은 사람의 직접 장면은 어디까지이며,
  공관복음의 레위 부르심과 어떤 요소가 같고 다른가?
- 실행 주체: Codex
- 환경과 확인 시점: YouVersion 웹의 읽기 쉬운 성경(KOERV), 2026-08-28
- 입력: 마 9:9-13, 마 10:2-4, 막 2:13-17, 눅 5:27-32, 막 3:16-19,
  눅 6:13-16, 행 1:12-14와 마태복음 저자 전승 참고 자료
- 전처리 또는 표현: 본문을 `인물명 / 장소 / 부르심 / 반응 / 식사 / 논쟁 /
  명단 / 전승` 단위로 분리
- 비교·판정 규칙: 본문이 직접 적은 이름과 행동만 `직접 기록`으로 표시하고,
  평행 장면의 대응과 후대 저자 귀속은 별도 열로 분리
- 성공 기준: 공개 원고의 모든 마태·레위 진술이 passage map의 같은 사건과
  근거 수준에 일치하고, 누가복음의 세부를 마태복음 직접 기록으로 옮기지 않음
- 반복 횟수와 표본 크기: 대표 본문 8개 단위, 수동 대조 1회
- 보존할 원자료: `artifacts/matthew-passage-map.csv`,
  `artifacts/source-notes.md`

## 실패와 반례

- 실패한 입력: 누가복음 5:28-29의 `모든 것을 그대로 두고`와 `큰 잔치`를
  마태 개인의 직접 기록으로 합치려던 초안 메모
- 예상과 달랐던 결과: 마태복음은 집을 마태의 집이라고 기록하지만, 모든 것을
  두고 감과 큰 잔치는 레위라고 이름 붙인 누가복음에만 나타남
- 일반화하면 안 되는 범위: 평행 장면의 높은 유사성만으로 복음서가 설명하지
  않은 이름 변경 이유를 확정하거나, 마태의 성격·회심 과정·저술 경력을
  복원하지 않음

## 출처 메모

- 마태복음 9:9 KOERV는 마태가 세관에 앉아 있다가 부름받고 일어나 따랐다고
  기록합니다.
- 마태복음 9:10-13 KOERV는 마태의 집 식사, 바리새파 사람들의 질문,
  예수님의 의사 비유와 부르심의 대상을 이어 적습니다.
- 마태복음 10:2-4 KOERV는 열두 제자 가운데 `세무원 마태`라고 직업을
  덧붙입니다.
- 마가복음 2:13-17 KOERV는 같은 구조의 장면에서 `알패오의 아들 레위`를,
  누가복음 5:27-32 KOERV는 `레위`를 이름으로 씁니다.
- 사도행전 1:12-14 KOERV는 마태가 다른 사도들과 이층 방에 모여 기도한
  사람들의 명단에 포함되었다고 기록합니다.
- USCCB의 마태복음 서론은 고대 교회의 마태 저자 전승을 소개하면서도 현존
  복음서의 저자를 미상으로 설명합니다. 공개 글은 논쟁을 해결하지 않고
  `전승이 있음 / 본문 안에 자기 이름을 밝히지 않음`까지만 씁니다.
