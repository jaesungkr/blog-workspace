# GPT-6 Astra vs. Fable 5.1 - AI 모델 비교

## 전면 개정의 목적

사용자가 도입부의 일반적인 업무 질문, 부족한 성능표, 대표 이미지 한 장뿐인 구성을 지적했습니다. 질문형 첫 문장을 출시 사건으로 바꾸고 공식 성능표와 외부 평가를 본문 앞쪽에 배치합니다.

- 독자: 코딩과 문서 작업에 쓸 최신 유료 AI 모델을 비교하는 한국어 사용자입니다.
- 독자가 아는 것: ChatGPT와 Claude로 글과 코드를 만들 수 있다는 정도입니다. 세부 벤치마크, API, 캐시, 추론 설정의 뜻은 설명합니다.
- 첫 화면: Fable 5.1 출시 이틀 뒤 Astra가 공개된 사건, 개별 공식 평가와 외부 종합 평가의 엇갈림, 코딩·분석에서 Astra를 먼저 시험할 제안입니다.
- 남길 판단: 공식 수치만으로 완승을 선언하지 않고 실제 작업에 가까운 평가와 과제 비용으로 시작 모델을 정합니다.
- 독자가 얻을 것: 모델 이름이나 종합 점수 하나로 고르지 않고 코딩·문서·반복 입력 조건에 맞는 후보를 정할 수 있습니다.
- 제목과 구조: 시리즈 제목은 유지합니다. 모델 소개 → 공식 벤치마크 9종 → 외부 평가의 다른 순위 → 긴 작업 기능 → 비용 → 작업별 선택 순서입니다.
- 검증 기여: Codex가 공식 사이트를 브라우저에서 직접 열어 캡처하고 원문 조건을 대조했습니다. 고정 토큰 비용 3개 시나리오는 기존 Decimal 계산을 유지합니다. 모델 직접 실행 또는 저자의 체험으로 표현하지 않습니다.
- 비교표: 공식 9종에는 두 모델 수치가 있는 주요 공개 지표를 선별합니다. 내부 전용 평가, BenchCAD 수정 조건, OSWorld 서로 다른 구성, ARC-AGI-3의 Fable 공란은 섞지 않습니다. 외부 지수·GDP.pdf·코딩 에이전트·비용은 별도 표이며 날짜와 척도를 구분합니다.
- 미디어: 기존 검증 대표 이미지를 유지하고 OpenAI 발표 상단, 과학 벤치마크 그래프, Anthropic 발표 상단을 추가합니다. 모델 정체, 평가의 비용과 성능 관계, Fable와 Mythos 구분을 각각 돕습니다. 같은 그래프를 재작성한 인포그래픽과 과도한 전체 페이지 캡처는 제외합니다.
- 가독성: 공식 그래프는 560px 개별 가로 스크롤과 한국어 설명을 제공합니다. 다른 이미지는 일반 반응형입니다. 표는 세 열을 동시에 읽을 수 있게 합니다.
- 주장 한계: 제조사와 독립 평가를 구분합니다. 최고 effort와 max의 비동등성, Fable fallback, 종합 지수 버전, GDP.pdf의 all-pass 기준, 장문 전체 할증, 실제 과금과 가상 계산, 한국어 글쓰기 미평가를 유지합니다.
- 제외: 내부 구조 추정, 한국어 품질 승자, 전 지표 합산 승수, 의료·보안 역량 권고, 모델 직접 사용 후기, 미확인 앱 한도입니다.
- 공개 질문 담당: 무엇이 나왔는가(소개), 어떤 과제를 잘 푸는가(공식 표), 왜 순위가 다른가(외부 평가), 길게 작업할 수 있는가(기능), 비용은 얼마인가(요금), 무엇부터 쓸까(선택)입니다.
- 상태: 전면 개정 후 reviewing입니다. 신규 이미지의 사용자 CDN URL을 받아 최종 페이지 검증을 다시 수행해야 합니다.
