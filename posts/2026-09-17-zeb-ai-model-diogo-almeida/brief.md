# 기획: 제브(Jev), InstructGPT 연구자가 만든 판단 전용 AI

## 분류와 독자

- 상위 카테고리: `Trends`
- 하위 카테고리: `AI 뉴스 · 테크 · 산업`
- 한 명의 독자: 챗GPT는 알지만 제브(Jev)는 처음 접한 비전문가
- 검색 의도: 디오고 알메이다가 공개한 제브가 무엇이며 기존 챗봇형 AI와 무엇이 다른지 알고 싶음
- 독자가 이미 아는 것: 챗GPT 같은 AI는 질문을 받으면 문장으로 답한다는 점
- 독자가 아직 모르는 것: 제브는 자유로운 문장을 생성하지 않고, 미리 정한 선택지·점수·참일 확률을 소프트웨어에 돌려주는 판단 전용 모델이라는 점

## 글의 중심

- 독자가 기억할 한 문장: 제브는 챗GPT를 대체하는 챗봇이 아니라, 챗GPT를 부를지와 결과를 통과시킬지 같은 반복 판단을 빠르고 저렴하게 맡기는 모델입니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 고객 문의가 스팸인지, 어느 상담팀으로 보내야 하는지, 사람이 다시 봐야 하는지를 애플리케이션이 매번 판단하는 상황
- 가장 쉬운 시작: 제브를 `문장을 쓰는 AI`가 아니라 `선택지마다 확률을 매기는 AI`로 이해하기
- 첫 화면 답: TypeSafe AI가 2026년 9월 15일 공개한 제브는 상태와 정형 질문을 입력받아 선택·점수·참일 확률을 반환함. TypeSafe 콘솔은 초기 접근 단계이고 Vercel AI Gateway에는 별도 제공 경로가 있음
- 이 글이 답하지 않는 범위: 제브 API 전체 사용법, 미공개 모델 구조와 학습 데이터 추정, 제브를 직접 호출한 독립 성능 비교, 범용 AGI 전망
- 가장 정직한 한계 또는 반론: 홈페이지의 속도·비용·지능 수치는 TypeSafe가 설계하고 수행한 워크플로 평가에서 나온 벤더 주장이고, 공개 표준 벤치마크나 독립 재현 결과로 확인된 보편적 성능이 아님
- 테스트 경계: 계정과 초기 접근 권한이 없어 제브를 직접 호출하지 않음. 공식 홈페이지·발표문·문서·평가 페이지를 서로 대조해 주장별 보장 범위와 미검증 범위를 나눔
