# 기획: Drifty, 고양이 AI 시간 관리 앱

## 분류와 독자

- 상위 카테고리: `Log`
- 하위 카테고리: `개발 · 디지털`
- 한 명의 독자: 타이머를 켜는 일을 자주 잊고, 퇴근 무렵에는 하루가 어디에 쓰였는지 기억하기 어려운 Mac·Windows 지식 노동자입니다.
- 검색 의도: Drifty가 무엇을 기록하는지, 기존 사용 시간 통계와 무엇이 다른지, 무료로 시작할 수 있는지, Windows에서도 쓸 수 있는지 확인하고 싶습니다.
- 독자가 이미 아는 것: 화면 사용 시간이나 타이머 앱은 알지만, 활동 맥락을 AI로 분류하는 방식과 로컬·Cloud·BYOK 선택지는 모릅니다.

## 글의 중심

- 독자가 기억할 한 문장: Drifty는 AI로 일과 딴짓을 구분하고 데스크톱 고양이가 집중 복귀를 돕는 시간 관리 앱입니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: 업무 자료를 찾으려고 연 YouTube에서 어느새 쇼츠를 넘기고 있는 상황입니다.
- 가장 쉬운 시작: 무료 기록 기능과 `기록만 하기`에 가까운 보수적 설정으로 하루를 먼저 쌓고, 분류가 맞는지 정정한 뒤 알림이나 자동 종료를 켭니다.
- 첫 화면의 답: Drifty의 고양이가 집중 복귀를 돕는다는 정체, 자동 기록의 쓰임, 고양이·자동 종료의 선택 기능 여부와 기록부터 확인하는 첫 행동을 제시합니다.
- 이 글이 답하지 않는 범위: 앱을 직접 설치한 장기 정확도 실험, Rize·RescueTime·Timely와의 독립 벤치마크, 팀 감시 용도, 모든 설정 화면의 사용법은 다루지 않습니다.
- 가장 정직한 한계 또는 반론: 공식 자료는 맥락 기반 분류를 장점으로 제시하지만, 실제 분류 정확도는 업무 프로필과 최근 맥락에 따라 달라집니다. 이 글은 제품을 직접 설치하지 않았으므로 정확도나 안정성을 보증하지 않습니다.

| 5 | Windows판은 공개됐으며 다운로드 안내와 첫 설정의 알려진 문제를 확인합니다. | 분류를 먼저 확인하고 고양이의 개입 강도를 높이는 첫 사용으로 마칩니다. |

## 중앙 방법의 계산 또는 판단 사슬

`활성 앱·사이트·창 제목·지속 시간 -> 업무 프로필과 최근 맥락을 함께 본 AI 분류 -> Focus·Neutral·Drift 라벨과 일간·주간 타임라인 -> 사용자가 정정하고 필요할 때 복귀 알림 또는 자동 종료`

## 보조 인포그래픽 판단

- 결정: `없음`
- 한눈에 보여 줄 관계: 자동 기록에서 분류와 복귀로 이어지는 흐름은 본문 4단계와 표만으로 충분합니다.
- 글이나 표만으로 충분하지 않은 이유: 해당 없음입니다. 숫자와 플랫폼 상태를 이미지에 고정하면 업데이트 시점이 다른 독자를 오도할 수 있습니다.
- 유형: `과정`
- 핵심 설명 뒤 권장 위치: 별도 인포그래픽을 두지 않습니다.
- 추가 이미지가 있다면 각 이미지가 답할 서로 다른 질문: 대표 이미지에는 제품 정체를 담고, 사용자가 제공한 공식 홈페이지 스크린샷은 활동 타임라인과 분류 비중의 위치를 보여 줍니다. 기존 `drifty-cat`은 발행 대상에서 제외합니다.

## reader-friction 화면 판단

- 진입점: 설치 절차를 재현하는 글이 아니므로 메뉴 위치 캡처가 필요하지 않습니다.
- 선택: AI 실행 위치와 비용은 표가 화면 캡처보다 정확하고 접근성이 좋습니다.
- 확인 상태: Windows 공개 여부는 공식 릴리스 링크와 버전·운영체제 문구로 확인하며, 빠르게 낡는 다운로드 화면 캡처는 싣지 않습니다.
- 채택한 화면: 사용자 요청에 따라 홈페이지의 대시보드 스크린샷을 `drifty-dashboard`로 채택합니다. 공식 예시 데이터이며 사용자의 실제 기록이 아님을 캡션에 밝힙니다. 모바일에서는 이미지 안에서만 가로로 스크롤합니다.
