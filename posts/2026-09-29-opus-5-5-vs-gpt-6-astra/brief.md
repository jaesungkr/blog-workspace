# 기획: Opus 5.5 vs GPT-6 Astra - AI 모델 비교

## 분류와 독자

- 상위 카테고리: `Log`
- 하위 카테고리: `AI 모델 · 비교`
- 한 명의 독자: Opus 5.5, GPT-6 Astra, Fable 5.1 가운데 복잡한 코딩·리서치·업무 자동화에 쓸 모델을 고르는 개발자 또는 실무자
- 검색 의도: Opus 5.5가 Astra를 대신할 수 있는지, Fable 5.1까지 포함하면 어느 모델을 먼저 시험해야 하는지 확인하려는 비교 검색
- 독자가 이미 아는 것: GPT-6 Astra가 OpenAI의 상위 모델이라는 점은 알지만, 모델별 API 단가·문맥·공개 평가 조건은 모를 수 있습니다.

## 글의 중심

- 독자가 기억할 한 문장: 새 API의 기본 시험 모델은 Opus 5.5이며, OpenAI 도구 흐름이 중요하면 Astra를, Opus의 높은 추론 강도에서도 부족한 장기 작업만 Fable 5.1을 검토합니다.
- 낯선 주제를 붙잡아 줄 익숙한 장면: Opus 5.5 출시 소식을 보고 현재 쓰는 Astra나 Fable을 바꿀 이유가 있는지 판단하는 순간입니다.
- 첫 화면의 답: API로 새 작업을 시작한다면 Opus 5.5부터 써 보도록 권합니다. 공개 성능이 경쟁력 있고 Astra·Fable보다 입력과 출력 단가가 60% 낮기 때문입니다. 다만 실제 과제 비용은 모델별 토큰 사용량에 따라 뒤집힐 수 있습니다.
- 가장 쉬운 시작: 대표 업무 20개 안팎을 정하고 동일한 입력·도구·완료 조건으로 Opus 5.5와 현재 모델을 비교합니다.
- 이 글이 답하지 않는 범위: 소비자용 Claude·ChatGPT 구독 한도, 한국어 문체 취향, 비공개 기업 평가, 특정 IDE의 중개 요금, 모델 안전성 전체를 다루지 않습니다.
- 가장 정직한 한계 또는 반론: 직접 API로 동일 과제를 실행한 글이 아닙니다. 제공사 문서, 제공사 비교표, 독립 평가와 공식 단가 계산으로 선택 기준을 만들며 실제 업무의 승자를 확정하지 않습니다.

## dev.log만의 근거

- first-party contribution: 서로 다른 출처의 평가 조건을 한 표에서 분리하고, 공식 API 단가를 세 가지 동일 토큰 구조에 대입한 재현 가능한 계산과 선택 규칙을 제공합니다.
- 실제 실행 주체: `Codex`
- 보존할 원자료: `artifacts/compare_costs.py`, `artifacts/compare_costs.json`
- 기존 글 또는 시리즈 연결: 기존 Astra·Fable 비교글과 2026-09-23 Grok 4.7·Fable 5.1 비교 묶음을 잇습니다.
- 다른 블로그 이름으로 바꿔도 성립하는 부분: 공식 사양 요약은 성립합니다. dev.log의 차별점은 단가와 실제 평가 비용의 충돌을 드러내고, 전환 전에 재현할 비교 조건까지 제시하는 데 있습니다.

## 제목·첫 화면의 질문별 담당 절

- Opus 5.5·Astra·Fable 5.1의 역할: 세 모델의 용도와 공통 사양을 설명합니다.
- Opus 5.5와 Astra의 공개 성능: 제공사 표에서 업무별로 우위가 달라지는 지점을 설명합니다.
- Arena에서 확인한 사용자 평가: Text·WebDev의 좋은 평가와 Agent의 다른 순서를 구분하고, 사용자가 제공한 언어 표현 차트는 문체 특징으로만 설명합니다.
- 독립 평가의 성능과 과제당 비용: Artificial Analysis에서 점수와 비용의 순서가 달라지는 이유를 설명합니다.
- 기본 입력·출력 단가는 Astra의 40%: 사용량을 같게 맞춘 API 비용을 비교합니다.
- Fable 5.1은 언제 필요한가: 추가 비용을 감수할 조건을 설명합니다.
- 내 업무에는 어떤 모델부터 써 볼까: 업무별 시작 모델과 비교 절차를 제시합니다.
