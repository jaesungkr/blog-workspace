Sonnet 5.5가 맡으려는 일

Anthropic의 발표는 Sonnet 5.5를 빠르고 비용이 낮은 Opus 5.5의 보완 모델로 설명합니다. 범위가 분명한 일상 작업, 버그 수정, 완성도 높은 문서·슬라이드·스프레드시트 제작이 주된 용도입니다. Claude Platform 문서에 따르면 API 모델 ID는 claude-sonnet-5-5이며, 100만 토큰의 문맥과 최대 12만 8천 토큰 출력을 지원합니다.

비교 대상인 GPT-6 Sol은 복잡한 코딩과 에이전트 작업을 겨냥한 OpenAI의 균형형 모델입니다. 105만 토큰 문맥과 최대 12만 8천 토큰 출력을 제공하며, Responses API에서 웹 검색·파일 검색·코드 실행·컴퓨터 사용 같은 내장 도구를 연결할 수 있습니다. Opus 5.5는 같은 Claude 계열에서도 복잡하고 개방적인 작업을 더 오래 판단하는 상위 선택지입니다.

세 모델의 역할을 먼저 나누면 선택이 단순해집니다.

동일 토큰 기준의 짧은 요청 비용

Sonnet 5.5와 GPT-6 Sol의 표준 API 가격은 모두 입력 100만 토큰당 2달러, 출력 10달러입니다. 캐시 읽기는 둘 다 0.20달러입니다. GPT-6 Sol의 캐시 쓰기와 Sonnet 5.5의 5분 캐시 쓰기는 2.50달러이며, Sonnet의 1시간 캐시 쓰기는 4달러입니다. Opus 5.5는 입력 4달러, 출력 20달러이므로 기본 토큰 가격이 두 배입니다.

소비자용 Claude나 ChatGPT 구독료와 API 사용료는 별개입니다. 아래 계산은 API에서 각 모델이 똑같이 입력 10만 토큰과 출력 2만 토큰을 청구했다고 가정합니다.

공개 점수에서 확인할 수 있는 범위

Anthropic이 발표문에 정리한 공개 평가는 Sonnet 5.5가 가격만 낮춘 모델이 아님을 보여줍니다. 다만 평가마다 도구 환경과 노력 수준이 다르며, 일부 숫자는 제조사가 취합해 제시했습니다. 세 평가 모두 점수가 높을수록 좋은 결과입니다. GDPval-AA의 Elo는 결과물을 서로 비교해 얻은 상대 평점이므로 다른 평가의 백분율과 직접 비교할 수 없습니다. 같은 평가 이름이 붙은 값만 나란히 보고 빈칸은 그대로 남겨야 합니다.

Opus 5.5에 비용을 더 낼 조건

Opus 5.5는 Sonnet 5.5와 같은 100만 토큰 문맥과 최대 12만 8천 토큰 출력을 지원하지만 기본 입력·출력 단가는 두 배입니다. 공개 점수 차이가 작은 작업이라면 Sonnet으로 먼저 처리하고, 실패 비용이 높은 작업만 Opus로 올리는 방식이 비용을 통제하기 쉽습니다.

Opus가 필요한지는 프롬프트의 난도보다 작업 범위를 미리 닫을 수 있는지로 판단하는 편이 낫습니다. 여러 저장소를 아우르는 마이그레이션과 요구사항이 계속 바뀌는 설계 검토가 대표적입니다. 자료를 모은 뒤 판단 기준까지 세워야 하는 조사처럼 중간 결정이 다음 단계에 누적되는 일도 해당합니다. 입력과 기대 결과를 명확히 적을 수 있는 버그 수정이나 문서 제작이라면 Sonnet이 먼저입니다.

Sonnet이 결과를 끝내지 못한 원인이 범위를 미리 닫기 어려운 판단에 있었다면 그 작업만 Opus 5.5로 다시 실행합니다. 이 순서라면 공개 벤치마크의 순위를 그대로 믿지 않고도 전환 이득과 Opus의 추가 비용이 실제 업무에서 정당한지 확인할 수 있습니다.
