# 창세기 4:1-14, 분노와의 싸움

## 범위와 상태

사용자는 요약을 먼저 읽은 뒤 Thoughts를 제공하겠다고 명시했습니다. 이번 산출물은 설교 요약과 본문 미삽입 썸네일입니다. lifecycle은 reviewing, workflow scope는 draft입니다. 전체 source freeze와 최종 페이지·Git 단계는 후속 자료 수신 뒤 진행합니다. 기존 작업트리에 여러 변경이 있어 이 번들 밖의 파일은 건드리지 않았습니다. origin은 https://github.com/jaesungkr/blog-workspace.git이며 시작 전 origin/master를 fetch했습니다.

## v2 문장·밀도 점검

- 독자 계약: 요약으로 설교를 복습하고 개인 묵상을 작성하는 독자입니다. 생활정보 추천·효능 글이 아니므로 별도 추천 계약은 해당하지 않습니다.
- 도입: 가까운 사람에게 다른 일에서 쌓인 분노가 향하는 상황은 전사문 6:32-8:42에 근거합니다. 저자의 실제 경험으로 바꾸지 않았습니다.
- 제목 질문: 분노가 위험한 이유와 대응 방법을 각각 하나의 section에서 설명합니다. 심리학·사회학·역사 해설은 제외했습니다.
- 제목·소제목: ‘분노의 위험성 및 대응 방안’ 같은 추상 명사열 대신 ‘가인·요나·모세에게서 드러난 분노의 위험’과 ‘분노와 싸우는 세 가지 권면’을 사용했습니다. 번호는 설교자 자신의 세 논점과 세 권면에만 사용했습니다.
- 문장 틀: ‘단순한 감정 문제가 아니라 영적 전쟁’이라는 대조 구문은 ‘감정을 절제하는 문제와 함께, 누가 내 삶을 다스리는지를 묻는 영적 싸움’으로 정리했습니다. 주장을 약화하지 않고 범위를 드러냈습니다.
- 삭제·압축: 알고리즘 설명과 역사 연대, 가인 장면의 반복적 짐승 비유, 다윗의 내면을 추측하는 구절은 본문 요약에서 제외했습니다. ‘멈춰라·가져가라·채워라’ 전체 설명을 결말에 다시 반복하지 않았습니다.
- 의미 보존: 가인의 제물 거절 이유를 추측하지 않았습니다. 분노가 일어나는 것과 품는 것을 구별했습니다. 물이 나와도 모세의 순종과 하나님의 거룩함은 별개라는 설명을 보존했습니다.
- 단락 소유권: 도입=분노가 이웃에게 향하는 문제, 위험1=지배, 위험2=심판자 위치, 위험3=결과와 순종 구별, 권면1=멈춤, 권면2=기도로 쏟음, 권면3=내면 채움, 결말=영적 싸움 관점입니다.
- 단락 연결: 가인·요나·모세의 사례는 각각 다른 위험을 설명하므로 인물 전환은 의도적입니다. 권면에서는 위험 설명을 반복하지 않고 대응 행동을 맡겼습니다.
- 본문과 설교자 구별: 각 적용을 ‘목사님은’ 또는 ‘설교는’으로 귀속했습니다. 사용자 Thoughts는 생성하지 않았습니다.
- 이미지 역할: thumbnail_only. 기사 본문에 이미지 directive가 없습니다. 빈 본문 media manifest는 사용자 지정에 따른 것이며 엄격한 완성 gate를 통과했다고 주장하지 않습니다.

## 산문 정리

- 비교한 완성 글: under-construction(ready), how-much-is-enough(ready), care-for-and-rule-creation(ready), ephesians-4-spiritual-maturity(ready). 같은 말씀 묵상 하위 분류에 4개가 있어 추가 분류를 사용하지 않았습니다. 최근 reviewing 초안은 비교 개수에 포함하지 않았습니다.
- 앞선 글의 ‘설교 핵심 요약’과 상세 요약을 반복하는 형식을 복사하지 않았습니다. 기사 도입 뒤에 중복되는 설교 소개 단락을 삭제하고 곧바로 인물 사례를 이어 배치했습니다. 별도 요약 파일의 소개는 독립해서 읽는 데 필요하므로 보존했습니다.
- analyzer 전후 결과는 prose-before.json과 prose-after.json에 저장합니다. 신호 개수가 아니라 실제 제목·소제목·단락 연결과 전사문 의미 보존을 판정 기준으로 삼았습니다.

## Thoughts 수신과 완성 초안

- 사용자 원문을 보존한 뒤, 시대 관찰 -> 여유 비유 -> 남에 대한 판단 -> 방문 사건 -> 자기 돌아봄 -> 설교와 기도 -> 구체적 적용의 순서로 작성했습니다. 본문은 ~습니다 존대어를 유지합니다.
- ‘분노조절장애=10’, 도파민과 호르몬 설명, 복권 가정은 요약 주장에 필요한 사실이 아니므로 삭제했습니다. 인기도는 개인 관찰로, 수치는 비유로 바꿨습니다. 방문자의 마음을 아는 것처럼 쓰지 않았습니다.
- 원문을 다듬을 권한은 사용자가 명시적으로 부여했습니다. 원문 밖의 새 경험·대화·실행 결과를 추가하지 않았습니다.
- 이전 단계의 reviewing 초안·검수 기록은 요약 범위의 역사입니다. 현재 완성 글은 신규 검수를 거칩니다.
- 사용자 명시 예외: 썸네일은 별도, 본문 이미지 없음. 기존 v2 checker의 lead/CDN 조건과 충돌하므로 해당 미디어 조건을 사용자 요청으로 제외합니다. 스킬·CSS·checker 원본은 변경하지 않습니다. source·hero 검수, 실제 브라우저 양 테마/양 폭, 바이트 동일성, focused Git은 유지합니다.

## 추가 검수 후 최종 polish

- 독립 source_review의 초안 권고를 반영했습니다. ‘교회에 다니기 전’을 사용자 원문의 신앙 상태에 맞게 ‘기독교인이 되기 전’으로 고쳤습니다.
- 숫자 단락은 ‘제 참을성을 숫자에 비유하면’으로 시작해 비유임을 바로 밝히고, 뒤의 측정 부정·비유 재설명을 삭제했습니다.
- ‘이 경험은 … 이어 줍니다’라는 편집자식 연결을 삭제하고, ‘화가 나는 이유’에서 ‘화가 난 뒤 대응’으로 생각이 바뀐 과정을 직접 썼습니다.
- 방문자가 수고 인정을 원했다는 의도는 ‘제게는’과 ‘제가 느낀 대로 …이었더라도’로 한정했습니다.
- 결말의 기도 시작 반복을 덜고 사용자가 원한 안쓰럽게 바라보기·문제 해결·작은 말을 너그럽게 듣기를 남겼습니다. 숫자·경험·대화·조건·기독교 이전 생각이라는 사실은 보존했습니다.
- v2 여섯 표면: 도입=상태에 따라 달라지는 반응, 제목·목차=본문/설교/Thoughts, 문장 틀=진행 설명 삭제, 새 정보=콘텐츠/비유/판단/사건/돌아봄/설교/기도/미디어선택/적용, 주장 소유=분노 위험은 설교/반응 경험은 Thoughts, 독자 계약=분노를 돌아보는 묵상 독자입니다. 효능·추천 계약은 해당하지 않습니다.

- 최종 읽기에서 ‘크게 화를 낸 것은 아니었습니다’라는 앞선 조건 반복, 다음 문장과 중복되는 감정 소멸 질문, ‘마음을 채우는 문제’라는 추상적 연결을 추가로 삭제했습니다. 내용과 결말을 바꾸지 않았습니다.
