# 작성 감사 기록

## 현재 판정

2026-10-24 작성자 피드백을 반영한 두 번째 원고가 prose-polish와 독립 article/source 검증을 통과했습니다. 현재 상태는 `reviewing`입니다. 기존 실험의 일반 요약 1개와 같은 대화의 후속 답변 3개를 사용했으며 새 실험은 하지 않았습니다. 현재 문구로 로컬 밝은/어두운 미리보기를 다시 생성하고 반응형 배치를 확인했습니다. 이 기록은 ready, 독립 최종 페이지 또는 게시 승인을 뜻하지 않습니다.

아래에는 첫 원고의 편집·검증 이력을 보존했습니다. 현재 원고의 소제목, 문단 연결과 재확인 결과는 마지막의 `두 번째 원고의 독해·문장 편집 결과`를 기준으로 읽어야 합니다.

이전 기록의 `researching / authentication_required`는 Claude Code 인증 오류로 실제 답변을 확보하지 못했던 당시 상태입니다. 그 실패는 성능 판정에서 제외했습니다. 이후 Claude 웹 실험을 완료했으므로 현재 차단 사유로 남기지 않습니다.

## 보존한 사실과 편집 범위

- 제목 `AI에게 PDF 요약을 맡겨도 될까?`와 게시 분류 `AI·개발 > AI 이해·활용`은 사용자 지정으로 유지했습니다. 도구 호환용 `Log > AI 개념 · 실전`도 유지했습니다.
- 실험 수행자는 Codex이며, Claude 웹의 새 대화에 원본 PDF 한 개를 첨부했습니다. 2026-10-24 화면 표시 모델은 `Sonnet 5.5 · 중간`이고 웹 검색은 껐습니다. 이를 사용자의 직접 체험으로 바꾸지 않았습니다.
- 183쪽짜리 2016년 공개 영문 설명서 한 개와, 요청 전에 작성한 정답 기준을 사용했습니다. 일반 요약 한 번 뒤에 같은 대화에서 질문 세 개를 순서대로 보냈으며 독립 시행 세 번으로 표현하지 않았습니다.
- q1의 숫자 8개는 모두 일치하지만 해상도까지 EB-1795F/1785W/1781W의 공통값으로 묶은 설명은 틀렸습니다. 부분 성공을 전면 성공이나 숫자 추출 실패로 바꾸지 않았습니다.
- q2는 다른 파일 제한을 충족하는 1920×1080 비인터레이스 PNG를 가정했습니다. PNG 각주를 사양표에 연결한 문서 해석이며 실제 기기 투사 실험은 아닙니다.
- q3는 정확한 dB(A) 수치를 추정하지 않은 답변입니다. PDF에서 확인하지 못했다는 판단과 제품 자료 어디에도 값이 없다는 주장을 구분했습니다.
- 숫자, 단위, 전압·동작 조건, 근삿값 표시, 원문 링크, 표의 값과 실제 답변 인용을 유지했습니다. `artifacts/experiment/*-web-answer.txt`를 읽었으며 원시 답변은 편집하지 않았습니다.
- 도구 기록의 텍스트 추출·검색을 PDF 전체 정독, OCR 정확도 또는 그림의 시각적 이해 성능으로 확대하지 않았습니다.
- 편집 파일은 `article.md`와 `audit.md`뿐입니다. Git 작업, source-pass 기록, 이미지 제작은 수행하지 않았습니다.

## 독자에게 약속한 내용과 범위

독자는 AI로 제품 설명서를 요약한 뒤 구매나 기능 사용 여부를 판단하려는 비전문 독자입니다. 표가 깔끔하다는 이유만으로 모델별 적용 조건까지 맞았다고 받아들이는 상황을 다룹니다. 먼저 요약을 받고 실제 선택에 필요한 숫자와 조건을 페이지 근거와 함께 다시 묻도록 권합니다. 마지막에는 원문 페이지에서 자신의 모델과 사용 조건을 직접 확인하도록 안내합니다.

독자가 PDF 내부 처리나 API를 안다고 가정하지 않았습니다. PC Free는 USB 이미지를 컴퓨터 없이 투사하는 기능으로, dB(A)는 소음 수준을 나타내는 단위로 설명했습니다. 비인터레이스 조건은 이번 질문에서 제외한 저장 방식을 명시하는 문장으로 풀었습니다. 모델 순위, 다른 제품 추천, OCR 제품 비교, API 구현과 가격 비교는 다루지 않습니다.

제목이 만든 질문과 본문의 담당 절은 다음과 같습니다.

| 독자 질문 | 담당 절 |
|---|---|
| 어떤 PDF를 어떻게 확인했는가? | 183쪽 설명서, 요약 한 번과 후속 질문 세 번 |
| 숫자를 맞혔으면 설명도 믿어도 되는가? | 숫자 표 아래에서 발견한 모델 혼동 |
| 작은 각주까지 적용할 수 있는가? | PNG 파일의 허용 크기를 바꾸는 각주 |
| 없는 수치를 만들어 내지는 않는가? | 팬 소음이 줄어든다는 설명에 없는 수치 |
| 내 PDF에는 어떻게 물어보면 되는가? | PDF 답변을 검증하는 후속 질문 |

글의 중심 문장은 다음과 같습니다. 제품 설명서 요약을 실제 선택에 쓰려는 상황에서 모델별 표기와 각주가 문제가 되었으므로, Codex가 같은 PDF의 답변을 원문과 대조했고 숫자 일치와 설명의 정확성이 서로 다를 수 있음을 관찰했습니다. 기존 절 순서는 이 경로에 맞아 유지했습니다.

다음 다섯 글은 모두 같은 하위 분류 `AI 개념 · 실전`이며 `ready` 상태입니다. 대상 글은 제외했고 다른 분류로 대체할 필요는 없었습니다.

## 두 번째 원고의 독해·문장 편집 결과

### 독자가 알아야 할 내용과 설명 순서

독자는 AI에게 PDF를 요약하게 한 뒤 제품 선택이나 기능 사용 여부를 판단하려는 사람입니다. 프로젝터 사양이나 PDF 처리 방식을 알고 있다고 가정하지 않았습니다. 이 글이 답하는 질문은 ‘요약 뒤에 무엇을 더 확인해야 하는가’이며, 제품 구매 추천이나 AI 모델 순위는 다루지 않습니다.

설명의 중심은 다음과 같습니다. 요약을 실제 결정에 쓰려면 숫자의 적용 대상과 예외 조건이 맞아야 하므로, Codex가 Claude에 제품 설명서를 첨부하고 답변을 원문과 대조했습니다. 숫자 여덟 개는 맞았지만 모델별 해상도를 설명한 문장은 틀렸고, 별도로 물은 PNG 각주는 올바르게 적용했으며, 확인할 수 없는 소음 수치는 추정하지 않았습니다. 각 결과를 해당 질문의 범위에서만 서술했습니다.

오케스트레이터가 재구성한 절 순서는 유지했습니다. 제품 설명서를 고른 이유를 Epson 문서보다 먼저 설명하고, 비교할 두 제품과 줄인 모델명을 정한 뒤 실험 절차를 소개합니다. Claude가 PDF를 읽고 답했으며 Codex가 질문 입력과 대조를 맡았다는 구분은 절차를 설명하기 전에 배치했습니다. 제품 모델과 Claude 모델을 혼동하지 않도록 첫 비교 소개, 화면 모델 표시, 마지막 프롬프트와 맺음에서 대상을 밝혔습니다.

### 대표 수정과 보호한 조건

| PNG 판정 뒤에 같은 결론과 일반적인 권고가 반복됐습니다. | 각주 적용 성공, 최초 요약의 누락과 미채점 이유만 남겼습니다. | 실제 투사를 하지 않았다는 경계는 바로 뒤에 유지했습니다. |
| ‘답변을 멈췄다’는 표현은 부연 설명까지 없었던 것처럼 읽혔습니다. | Claude가 소음 감소 설명으로 정확한 숫자를 추정하지 않았다고 적었습니다. | 실제 q3 답변은 관련 페이지와 정성 설명을 함께 제시했습니다. |

ECO 모드는 밝기와 팬 소음을 줄이는 모드라고 먼저 설명하고 dB(A)는 소음 수준에 쓰는 단위 표기로 소개했습니다. 정확한 수치가 없는 설명과 수치 근거를 구분하는 데 필요한 만큼만 설명했습니다. q3 대조의 수행자는 Codex라고 밝혔으며, 관련 화면과 사양표 대조 및 전체 추출 텍스트 검색을 전 페이지 정독으로 확대하지 않았습니다.

표·인용·미디어는 바로 앞 문단에서 소개한 근거로 보았습니다. 각 문단이 새로 알려 주는 내용과 다음 문단을 읽어야 할 이유를 확인했습니다.

### 소제목과 미디어 placement 인계

prose-polish에 들어오기 직전의 다섯 소제목과 순서를 그대로 유지했습니다. 첫 원고의 manifest가 이전 소제목을 가리키고 있다면 다음 현재 소제목에 맞춰야 합니다. 이 단계에서는 `media.json`을 수정하지 않았습니다.

1. `왜 프로젝터 설명서를 골랐을까?`: 자료 선정과 실험 절차를 소개합니다. 미디어 지시문은 없습니다.
2. `숫자 표 아래에서 발견한 모델 혼동`: `model-specifications` 다음 `claude-model-group`입니다.
3. `같은 PNG 파일을 두 모델에서 쓸 수 있을까?`: 기본 상한과 각주를 설명한 뒤 `png-footnote`입니다.
4. `정확한 소음 수치가 문서에 없다면?`: ECO와 질문의 요구 조건을 설명한 뒤 `eco-noise`입니다.
5. `내 PDF에 써 볼 후속 질문`: 제안 프롬프트를 제공합니다. 미디어 지시문은 없습니다.
