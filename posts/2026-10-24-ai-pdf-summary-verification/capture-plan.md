# 실험 증거 수집 및 공개 범위

## 실제 입력과 수행자

- Codex가 Claude 웹의 새 대화에 원본 Epson PDF 하나를 첨부했습니다. UI 표시 모델은 Sonnet 5.5 · 중간입니다.
- 일반 요약 1개 후 같은 대화에서 숫자·각주·부재 정보 질문을 차례로 보냈습니다. 독립 시행으로 표현하지 않습니다.
- 입력과 실제 답변은 artifacts/experiment/의 baseline-web-prompt.txt, verification-web-prompts.json, *-web-answer.txt에 보존했습니다. 전체 선택 문서, 사전 정답표, 실제 결과 기록도 함께 보존합니다.

## 원문 화면

- 65·131·173쪽은 공식 PDF에서 Poppler로 렌더링했습니다. 원본 페이지와 발췌 이미지를 모두 남겼습니다.
- 65쪽 PNG 행과 별표 각주를 연결해서 보존합니다. 173쪽은 해상도·램프·전압별 동작 전력·무게 행을 원문 그대로 세로로 모았습니다. 131쪽은 ECO 행과 Normal 행의 전체 문구를 보존합니다.
- 정확한 crop 위치와 크기, 해시는 media.json의 processing에 기록했습니다.

## 실제 AI 화면

- 숫자 질문의 설명 오류 화면을 Codex in-app browser 1280×720 뷰포트에서 캡처했습니다. 사이드바를 접어 다른 대화 제목과 계정 정보가 없는 상태로 캡처했습니다.
- 공개용 이미지의 원본은 artifacts/captures/raw/claude-q1-explanation.png입니다. 해당 응답 영역만 발췌하고 2배 확대했습니다. 텍스트는 수정하거나 가리지 않았습니다.
- 일반 요약과 각 검증 질문의 원본 화면은 artifacts/experiment/에 있습니다. 원문 정답을 AI 답변처럼 재구성한 이미지는 만들지 않았습니다.
- 공개 본문에는 숫자 오류 화면 한 개만 싣습니다. 나머지 답변은 원문 화면과 함께 발췌·대조표로 보여 주어 중복 화면과 업로드 부담을 줄입니다.

## 공개·검증 규칙

- 계정과 다른 대화 내용이 보이는 화면은 공개 증거에 포함하지 않습니다. 최초 넓은 DOM 추출은 현재 작업의 private-capture 폴더로 분리했고 Git에 추가하지 않습니다.
- 인증 오류는 문서 읽기 결과가 아니며, 완료된 본 실험과 구분합니다.
- 비교용 화면을 360px에서 무리하게 축소하지 않고 개별 가로 스크롤로 읽게 합니다. 원문 표의 숫자와 각주, AI 설명 문장이 각각 읽혀야 합니다.
