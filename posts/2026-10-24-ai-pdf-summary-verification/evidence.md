# AI에게 PDF 요약을 맡겨도 될까?

## 실험 상태

Claude Code의 인증 오류로 실패한 요청은 성능 평가에서 제외했습니다. 사용자가 2026-10-24에 Claude 웹 로그인을 완료하고 GPT도 대안으로 허용했습니다. 본 실험은 Claude 웹의 새 대화에 원본 PDF 하나를 첨부하고 화면 표시 모델 Sonnet 5.5 · 중간으로 완료했습니다. CLI의 추출 텍스트 파일은 웹 대화에 제공하지 않았습니다. 웹 검색은 해당 대화 메뉴에서 껐으며 UI에서 Value: 0을 확인했습니다.

일반 요약 1개와 같은 대화에서 순서대로 질문한 후속 답변 3개를 보존했습니다. 입력 문서는 ground-truth.json의 SHA-256과 같습니다. 대화 URL, 모델 표시명, 결과는 artifacts/experiment/results.json에 있습니다. 실제 모델 내부 ID는 웹에서 노출되지 않아 추정하지 않았습니다.

## 출처와 원본

- S01: https://platform.claude.com/docs/en/build-with-claude/pdf-support
  - 2026-10-24 열람. PDF의 텍스트·그림·차트·표를 질문할 수 있다는 공식 지원 범위를 확인했습니다. 이 기능 설명은 정확도 보증이 아닙니다. API의 지원 범위를 웹 실험에서 내부적으로 어떤 처리까지 수행했는지에 관한 증거로 취급하지 않습니다.
- S02: https://download.epson.com.sg/manuals/EB-1785W_1795F_User%20Guide.pdf
  - Seiko Epson Corporation의 EB-1795F/EB-1785W/EB-1781W/EB-1780W User’s Guide입니다. 183쪽, 5,785,314바이트입니다. PDF 메타데이터는 2016년 문서이므로 최신 제품·구매 추천 자료로 사용하지 않습니다. 텍스트를 선택할 수 있는 영문 설명서이며 스캔 문서의 OCR 성능을 검증하지 않습니다.
  - 원본: artifacts/sources/epson-eb17-user-guide.pdf. SHA-256은 artifacts/experiment/ground-truth.json에 기록했습니다. PDF 페이지와 인쇄된 페이지 번호가 이번 인용 범위에서는 같습니다.
  - PDF는 비밀번호 없이 열리고 복사·인쇄가 허용되지만 편집 제한 암호화가 있습니다. 최종 웹 실험에는 변환하지 않은 이 원본을 첨부했으며, 실제 응답과 도구 기록에서 페이지별 내용을 추출한 결과를 확인했습니다.

## 판정 규칙과 실행 경계

- 정답표는 모델 요청 전에 ground-truth.json에 기록했습니다.
- 최종 실험은 원본 PDF 하나를 새 웹 대화에 첨부하고 일반 요약 뒤 같은 대화에서 검증 질문을 순서대로 보냈습니다. 이는 독립 시행 3회의 모델 비교가 아닙니다. 초기 CLI 계획의 페이지 표시 텍스트는 웹에 제공하지 않았습니다.
- 웹 검색을 끄고 PDF만 근거로 답하도록 요청했습니다. 웹의 가시 도구 기록에는 pdftotext를 사용한 전체 텍스트 검색이 있습니다. PDF 전 페이지의 그림을 읽었다는 주장은 하지 않습니다. CLI 계획의 Read/Grep 도구 제한은 웹 실험에 적용한 제한이 아닙니다.
- q1: 모델 두 개의 4개 항목을 각각 확인하므로 숫자 값 8개를 대조합니다. 램프 W와 본체 W 및 전압 조건을 혼동하면 실패입니다.
- q2: PNG 표의 별표와 1080p 모델 예외를 연결해야 통과합니다. 단순히 PNG 지원 여부만 답하면 불충분합니다.
- q3: 정확한 수치를 추정하지 않고 문서에서 확인 불가라고 답해야 통과합니다. 관련 정성 설명과 수치 근거를 구분합니다.
- 결과 한계: 질문을 명시적으로 잘게 나눈 검증 실험입니다. ‘요약해 줘’ 한 문장으로 얻은 일반 요약의 정확도 또는 183쪽 전체를 정독했는지를 증명하지 않습니다. 단일 문서와 회당 관찰을 전체 모델 성능으로 일반화하지 않습니다.

## 실제 결과와 대조

- q1: 숫자 8/8과 173쪽 인용은 맞았습니다. 그러나 답변의 모델 귀속 설명은 해상도까지 EB-1795F/1785W/1781W의 공통값으로 묶어 원문 및 답변 자체 숫자 표와 충돌했습니다. 부분 성공으로 기록합니다. 실제 문장과 화면은 q1-web-answer.txt, q1-web-explanation.png에 있습니다.
- q2: 65쪽 PNG 각주와 173쪽 모델별 해상도를 연결해 EB-1795F 가능, EB-1780W 불가로 답했습니다. 질문에서 명시한 다른 파일 조건 충족 가정 안에서 통과입니다.
- q3: 131쪽의 정성 설명과 정확한 dB(A) 수치 부재를 구분했고 숫자를 추정하지 않았습니다. 해당 질문에서 통과입니다. Codex는 별도 noise-text-scan.json 검색과 131·173쪽 원문 화면을 대조했습니다.
- 첫 요약에는 PNG 각주가 없었지만, 특정 사용 조건을 요청하지 않은 단계이므로 이 누락 자체를 오답으로 채점하지 않습니다.
- 본문에 인용한 응답은 실제 웹 응답의 일부입니다. 원문 숫자를 요약한 표는 발췌임을 본문에 명시했습니다. q1의 보충 오류 문장은 중간 수정을 하지 않고 그대로 인용합니다.
- 원문에 없는 정보의 부재는 정성 설명과 사양표 확인 및 전체 추출 텍스트 검색으로 판단했습니다. 검색만으로 PDF 전체의 의미적 부재를 수학적으로 증명했다는 주장은 하지 않습니다.
