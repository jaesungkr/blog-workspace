Claude Duet은 어디에서 무엇을 하나요?

Anthropic은 10월 21일 Duet의 연구 프리뷰를 발표했습니다. iOS·Android에서는 기존 Claude 앱과 분리된 앱을 쓰고, 컴퓨터에서는 claude.ai에서 이용합니다. 기존 Claude 계정의 메모리, 스킬, 연결된 앱을 가져옵니다. 메모리는 이전에 공유한 정보를 기억해두는 기능이며, 스킬은 특정 업무를 수행하는 지침입니다. 공식 발표

시작하려면 제품 페이지의 대기 명단에 Claude 계정 이메일로 신청하고 초대를 받아야 합니다. 이후 메일·캘린더처럼 필요한 앱을 연결하고, 텍스트를 입력하거나 음성으로 일을 요청합니다. 예를 들어 회의 상대 회사의 사전 자료를 부탁하면, Duet이 사용할 앱과 작업 단계를 정하고 클라우드 컴퓨터에서 자료를 준비합니다. 앱을 닫아도 작업은 이어집니다. 진행 상황은 Tasks, 완성된 파일은 Make 탭에서 확인하며, 완료되거나 판단이 필요하면 주 대화에 메시지를 보냅니다. 시작 안내

Anthropic이 공개한 Tasks 화면에서는 ‘Ready for review’와 ‘Needs input’으로 검토할 작업과 사용자 입력을 기다리는 작업을 구분합니다. 작업 목록 예시

Duet은 아침에 주요 업무를 요약하고, 낮에도 연결된 계정을 확인합니다. 사용자가 화면을 열어 기다리지 않아도 서버에서 처리하는 일을 백그라운드 작업이라고 합니다. Duet은 계정을 몇 시간 간격으로 확인하므로, 확인 사이에 들어온 긴급한 소식은 다음 확인까지 놓칠 수 있습니다. 공식 발표

Claude Code는 코드 수정·테스트 등 개발 작업을 맡기는 제품입니다. Duet은 메일과 일정 등 여러 업무를 살피는 용도이며, 공개 문서에는 기존 Claude Code 작업을 이어받는 기능이 명시돼 있지 않습니다.

ChatGPT Dots는 ChatGPT 안에서 만드는 개인 에이전트

OpenAI의 Dots는 9월 28일~10월 2일 업데이트와 9월 29일자 DevDay 자료에서 소개됐습니다. 사용자는 자신의 dot에 이름을 붙이고, “프로젝트 일정과 미응답 사항을 관리해줘”처럼 지속적인 책임을 맡깁니다. dot은 연결된 앱에서 자료를 찾고, 파일을 만들거나 일을 나눠 수행한 뒤 결과와 결정 요청을 가져옵니다. DevDay 발표

OpenAI가 공개한 아래 대화 예시는 사용자가 자리를 비운 동안 무엇을 확인하고, 어떤 경우에 결정을 요청할지 정하는 과정을 보여줍니다. 대화 예시

Dots는 ChatGPT 안의 기능입니다. 모바일 앱·데스크톱 앱·데스크톱 웹에서 dots를 열고 이름과 외형을 정한 뒤 필요한 플러그인을 연결합니다. 플러그인은 외부 서비스의 자료와 기능을 쓰게 해주는 연결 수단입니다. 대화할 Slack 채널, 자료를 읽을 앱, 개인 컴퓨터는 각각 따로 연결합니다. 설정 안내

ChatGPT Work는 조사·분석·파일 제작 같은 작업을, Codex는 소프트웨어 개발을 맡기는 제품입니다. dot은 필요할 때 이들에 작업을 맡기고 후속 지시를 내릴 수 있습니다. 클라우드 작업은 사용자의 컴퓨터가 꺼져 있어도 진행됩니다. 로컬 파일이나 기존 로컬 Codex 작업을 사용하려면 개인 컴퓨터를 연결하고 ChatGPT 앱을 켜둬야 합니다. 클라우드 개발에는 저장소와 설정을 갖춘 Codex 환경이 필요합니다. 작업과 메모리, 컴퓨터 연결

10월 9일에는 모바일 앱에서 dot을 만들고 플러그인을 연결하는 기능이 소개됐고, 최신 업데이트 목록의 10월 12~16일 항목에는 iOS 위젯·Shortcuts 진입 기능이 실렸습니다. 10월 9일 업데이트, 최신 업데이트

“내일 회의 준비를 도와줘”를 맡기는 세 가지 방식

다음은 차이를 설명하기 위한 가상 상황입니다. 일반 대화에서는 회의록과 메일을 주고 쟁점을 정리해 달라고 요청할 수 있습니다. 이후의 변경 사항을 계속 확인하려면 별도의 후속 요청이나 자동화 설정이 필요합니다. 기존 Claude에도 예약 작업이 있고 ChatGPT Work도 일정에 따른 실행을 지원합니다. Claude 릴리스 노트, ChatGPT 기능 구분

예약 작업에는 “내일 오전 8시에 회의 자료를 정리해줘”처럼 실행 시간을 지정합니다. 지속적인 업무 위임에는 “회의까지 안건과 미응답 사항을 관리하고, 내 결정이 필요한 변화만 알려줘”처럼 관리할 대상과 판단 조건을 줍니다. AI가 먼저 필요한 소식을 전하는 선제적 알림도 이 조건에 맞춰 이해하면 됩니다.

Duet에는 캘린더와 관련 메일을 연결하고 회의 전 자료를 요청할 수 있습니다. Anthropic은 Duet이 고객 통화를 앞두고 자료를 준비하고, 비행 일정과 가깝다는 점을 발견해 시간 변경을 제안한 사례를 소개했습니다. 이는 회사가 제시한 초기 사용자 사례입니다. 발표 속 활용 사례

Dots에는 “내일 회의까지 안건과 미응답 사항을 관리하고, 한국 시간 오전 8시에 자료를 정리해줘. 결정이 필요하면 ChatGPT에서 알려줘”라고 맡길 수 있습니다. 연결된 서비스가 지원하면 “지정한 Slack 채널에 새 버그 보고가 올라올 때 조사해줘”처럼 사건을 계기로 실행하도록 요청할 수도 있습니다. 채널을 연결한 다음에는 무엇을 감시하도록 설정했는지 확인해야 합니다. 시작 안내

공식 문서의 ‘상시 실행’은 대화 사이에도 업무를 이어가는 방식입니다. Duet은 주기적으로 계정을 확인하고, Dots는 필요할 때 멈췄다가 다시 작업할 시점을 정합니다. Dots의 정확한 확인 간격은 해당 문서에 공개돼 있지 않습니다. 두 문서는 중단 없는 추론을 약속하지 않습니다. Duet 실행 방식, Dots 실행 방식

맡긴 일을 확인하고 멈추는 방법

Duet은 전송·결제·서명·삭제 전에 내용을 보여주고 승인을 기다리도록 설계됐습니다. Tasks에서 진행 방향을 바꿀 수 있고, 연결된 앱을 해제하면 이후 접근이 중단됩니다. 이미 기억한 정보는 별도 메모리 초기화가 필요합니다. 전체 작업을 한 번에 멈추는 구체적인 조작법은 확인한 문서에 없습니다. 안전·개인정보 후속 설명

Dots는 외부 계정이나 정보 공유에 영향을 주는 행동을 자동 심사합니다. 기존 지시와 권한에 따라 바로 수행하거나, 승인을 요청하거나, 사용자에게 단계를 넘깁니다. 특정 범위의 향후 행동도 지시로 허용할 수 있습니다. 고객 메시지는 항상 확인받도록 하는 등의 Custom rules를 추가할 수 있지만, 이 규칙도 실수 가능성이 있으며 기본 안전 요건을 해제하지 못합니다. 통제 문서

Dots의 진행 상황은 데스크톱 프로필의 Activity, 예약 작업은 Scheduled에서 봅니다. Pause는 현재 주 작업을 멈춥니다. 따로 맡긴 작업은 Activity에서, 향후 예약 실행은 Scheduled에서 각각 중단해야 합니다. 중단해도 이미 보낸 메시지나 완료된 변경은 되돌아오지 않습니다. 클라우드 브라우저는 Take over로 직접 조작할 수 있지만, Duet 프리뷰는 브라우저 보기와 제어권 인수를 지원하지 않습니다. Dots 통제, Dots 브라우저, Duet 제한

Anthropic은 10월 23일 별도 안전 설명에서 행동 심사, 민감정보 검사, 인증정보 분리와 외부 침투 테스트를 설명했습니다. 같은 문서는 보호 장치의 누락과 오탐 가능성도 인정합니다. 이 설명은 회사가 공개한 설계와 평가입니다. 이번 조사에서는 두 제품의 안전성을 비교한 독립 검증 자료를 확보하지 못했습니다. Duet 안전 설명

한국에서의 이용 조건과 사용량

Duet은 현재 미국 Claude 계정의 Pro·Max 가입자가 초대를 받아야 이용할 수 있습니다. 한국 계정은 대상에 포함되지 않고 Team·Enterprise도 아직 지원하지 않습니다. 프리뷰에는 추가 요금이 없으며, 아침 요약과 계정 확인도 기존 5시간·주간 사용량에 반영됩니다. 최신 도움말

Dots는 18세 초과 Pro 100·200·500 사용자 중 유럽경제지역·영국·스위스 밖의 사용자를 대상으로 합니다. 한국은 이 지역 제한상 대상에 들어가지만, 실제 계정 활성화는 점진적 배포에 달려 있습니다. Business Premium·Enterprise는 전 세계 배포 대상으로 안내되며 Enterprise는 관리자가 켜야 합니다. Plus는 대상 목록에 없습니다. 모바일 앱·데스크톱 앱·데스크톱 웹을 지원하고 모바일 웹은 지원하지 않습니다. 현재 이용 조건

dot과의 대화는 ChatGPT 사용량 한도에 포함되지 않지만, 위임한 Work·Codex 작업에는 해당 제품 한도가 적용됩니다. 더 깊은 작업의 허용량과 출시 첫 달 확대 한도를 안내하지만, 정확한 수치와 확인 1회당 소모량은 공개하지 않았습니다. 구체적인 비용 계산에는 계정에 적용된 최신 한도가 필요합니다. 사용량 안내

회의 준비부터 개발 후속 점검까지

Duet은 회사 조사 자료와 일정 확인을, Dots는 회의 자료 준비와 후속 관리를 공식 예시로 제시합니다. 관련 메일·캘린더·문서를 연결하고 최종 안건과 공유할 내용을 검토하도록 요청할 수 있습니다. Duet 업무 예시, Dots 소개 업데이트
