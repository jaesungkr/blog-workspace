# 집필 기획

- 독자: Claude나 ChatGPT로 질문한 경험이 있는 개발자·지식 노동자. Duet, Dots, 에이전트 개념은 처음 접합니다.
- 익숙한 상황: 내일 회의 전에 일정, 메일, 문서에 흩어진 변경 사항을 다시 확인해야 합니다.
- 핵심 질문: AI에 매번 새 질문을 하는 방식에서 일정한 업무 책임을 맡겨두면 무엇이 달라지는가?
- 설명 순서: 익숙한 회의 준비 → Duet의 정체와 사용 과정 → Dots의 정체와 사용 과정 → 같은 상황 적용 → 비교 표 → 구체적인 활용·한국 이용 조건.
- 확인 기준일: 2026-10-25(한국 시간).
- 기여: 공식 자료의 발표 시점과 현재 문서를 교차 확인하고, 요청·시간·변화 감지·결과 검토라는 결정 체계로 비교합니다.
- 검증 경계: 실제 계정으로 실행하지 않았습니다. 제품 설명·회사 사례·가상 예시를 구분합니다. 모델 성능 순위, 성공률, 실행 시간은 다루지 않습니다.
- 저자의 제품 이용·전환 의도: 알려지지 않았습니다. 특정 구독 전환을 권하지 않습니다.
- 독자 질문: 무엇인가, 어디서 시작하는가, 무엇이 계기가 되는가, 자리를 비우면 무엇을 하는가, 무엇을 승인하는가, 어떻게 멈추는가, 한국에서 이용할 수 있는가, 한도는 어떻게 드는가?
- 시각 자료 판단: 사용자가 생성 이미지 대신 공식 홈페이지의 화면을 요청했습니다. 생성 대표 이미지는 최종 원고에서 제외하고, Duet의 Tasks 작업 목록과 Dots가 대화 사이에 업무를 이어간다고 설명하는 대화 예시를 각 제품 소개에 넣습니다. Duet은 공식 이미지의 왼쪽 작업 목록만 잘라 사용하고, Dots는 공식 문서의 대화 예시를 브라우저에서 캡처합니다. Dots 이미지는 휴대폰에서 가로로 밀어 원래 글자 크기로 읽도록 합니다. 공식 소개 예시와 실제 계정 사용 경험을 구분하며 두 제품의 우열을 암시하지 않습니다. 별도 설명용 그림은 기존 사례와 비교 표를 반복하므로 추가하지 않습니다.
- 상태: 대표 이미지와 로컬 반응형 미리보기를 포함한 검토용 인계. 게시·배포하지 않습니다.
