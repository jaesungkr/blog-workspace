# 표지 대비 보정 후보의 독립 페이지 기록 갱신

- 검수자: source_review
- 결과: 현재 standalone 후보 pass, 실제 표지 보정 결과는 동일 게시물에 반영한 뒤 라이브 확인이 필요합니다.
- 원고·미디어·CSS·Tistory는 검수자가 수정하지 않았습니다.

수정 전 실제 라이트 표지 캡처와 published-dark.png를 열었습니다. 밝은 금속 이미지 위에 흰 제목과 작은 날짜가 겹쳐 일부 글자의 대비가 약한 문제를 확인했습니다.

변경된 post.css를 이전 기록과 대조했습니다. 이 글이 포함된 body의 hELLO main header > .info에만 검은 반투명 배경과 흰 글자·얕은 그림자를 더합니다. h1과 desc의 글자색도 흰색으로 고정합니다. 기존 모바일 표 규칙은 그대로입니다. 원고의 정규화 해시, source pass 파일 해시, media.json 해시가 이전 최종 페이지 기록과 일치합니다.

final-light와 final-dark를 각각 새 Chrome 세션으로 다시 실행했습니다. 1280·360 네 정규 스크린샷을 직접 열었습니다. 네 이미지의 해시가 이전 최종 캡처와 정확히 같고, 문서 가로 넘침은 0px입니다. 이미지 로드와 유일한 목차 대상, H1 하나도 유지됩니다. 새로운 CSS 선택자의 대상이 없는 standalone 화면은 시각적으로 변하지 않았습니다. 기존 전체 본문·표·목록·원격 이미지 검수를 재사용하며 편집 심사를 다시 열지 않았습니다.

final-measurements.json의 사람 판단을 유지하고 record_final_page_v2.py로 현재 CSS가 포함된 후보 HTML 및 게시 조각의 해시에 맞는 유일한 final-page.json을 다시 기록했습니다. 오래된 후보 해시를 재사용하지 않았습니다.

중요한 범위: standalone 후보에는 hELLO 자동 표지가 없습니다. 따라서 이 pass를 실제 표지 대비가 개선됐다는 관찰로 표시하지 않습니다. 게시 담당자가 같은 게시물 150에 CSS만 반영한 뒤 실제 표지의 제목·날짜를 라이트·다크 및 데스크톱·모바일에서 재확인해야 합니다. 기존 live defect가 해결됐다는 판정은 그 관찰 뒤에 남겨야 합니다.
