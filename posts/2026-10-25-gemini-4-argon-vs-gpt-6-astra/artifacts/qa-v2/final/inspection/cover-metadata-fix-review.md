# 모바일 표지 메타데이터 보정 후보의 독립 기록 갱신

- 검수자: source_review
- 결과: 현재 standalone 후보 pass입니다. 모바일 표지의 실제 줄바꿈은 같은 게시물에 CSS 반영 후 재확인해야 합니다.

공개 모바일 스크린샷을 직접 열었습니다. 제목은 반투명 검정 배경 위에서 잘 보이지만, 날짜·카테고리와 로그인한 저자용 링크가 같은 줄 안에서 문자 중간에 나뉘는 현상이 있습니다.

추가 CSS는 이 글의 hELLO header .info .desc에서 flex-wrap, 중앙 정렬과 행 간격·안쪽 여백을 정하고, time과 category에 nowrap을 지정합니다. 본문을 대상으로 하는 선택자는 바뀌지 않았습니다. 원고의 정규화 해시와 source pass·media.json 해시가 최초 최종 페이지 기록과 같습니다. source 편집 심사는 다시 열지 않았습니다.

최신 후보에서 final-light와 final-dark를 서로 다른 새 Chrome 세션으로 다시 실행했습니다. 1280/360 스크린샷 네 장을 직접 열었고 네 장 모두 이전 캡처와 해시가 같습니다. 문서 가로 넘침 0px, 원격 이미지 로드, H1 하나와 유일한 목차 대상이 유지됩니다. 해당 표지 DOM이 없는 standalone 본문은 바뀌지 않아 기존 전체 본문 검수를 재사용합니다.

final-measurements.json의 사람 판단을 유지하고, record_final_page_v2.py가 최신 CSS를 포함한 HTML·게시 조각에 결합된 final-page.json을 성공적으로 갱신했습니다. 이 기록을 실제 모바일 표지의 날짜·카테고리 줄바꿈까지 확인한 것으로 표시하지 않습니다. 게시 담당자가 동일 게시물에 반영한 뒤 실제 화면으로 그 부분을 재확인해야 합니다.

검수자는 원고·CSS·미디어·Tistory를 수정하거나 Git 작업을 하지 않았습니다.
