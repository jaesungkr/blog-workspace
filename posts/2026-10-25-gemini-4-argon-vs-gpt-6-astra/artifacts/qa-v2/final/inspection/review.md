# 독립 최종 페이지 검수

- 검수자: source_review
- 결과: pass
- 대상: final-rendered와 final-dark-rendered의 정확한 원격 미디어 후보입니다.
- 기존 source 심사를 다시 열지 않았으며 원고·CSS·미디어는 수정하지 않았습니다.

## 실행과 증거

capture_rich_qa_v2.py를 final-light 및 final-dark로 각각 실행했습니다. 두 테마는 서로 다른 새 Chrome 세션을 사용했고 browser-capture.json이 모두 pass입니다. Chrome은 155.0.8059.85입니다. 각 세션에서 1280×900과 360×800을 새로 로드했습니다.

정규 캡처는 첫 뷰포트만 저장하므로, 같은 canonical HTML의 전체 화면을 추가 캡처했습니다. 도구가 긴 전체 이미지를 축소해 보여 주는 문제 때문에 연속된 읽기 구간도 1800px 이하로 새로 캡처해 모든 영역을 실제로 열었습니다. 이 보조 기록은 새로운 원고 승인이나 별도 페이지 승인이 아닙니다. inspection.json에 canonical HTML 해시와 실제 브라우저 측정을 보존했습니다.

## 실제 관찰

- 양쪽 테마의 1280·360 화면 모두 문서 가로 넘침은 0px입니다. 프리뷰 H1은 하나이고 목차 일곱 대상은 유일합니다.
- 원격 이미지 한 장이 실제 픽셀로 그려졌습니다. 1672×941 원본을 데스크톱에서는 916px, 모바일에서는 320px로 표시합니다. 두 모델명과 별·커서가 구분되고 캡션이 바로 아래 붙어 있습니다. 빈 미디어 영역이나 재색칠은 없으며 이미지의 CSS filter는 none입니다.
- 목차부터 마지막 참고 자료까지 전체 페이지를 확인했습니다. 긴 소제목은 모바일에서 정상적으로 줄바꿈하며 잘리지 않습니다. 캡션과 문단·섹션 사이의 여백이 유지됩니다.
- 모바일의 세 비교표는 각 320px 안에 들어가며 모든 모델 열과 수치가 동시에 보입니다. 셀 문자 14px과 줄바꿈이 유지돼 숫자가 겹치거나 숨지 않습니다. 데스크톱의 표는 760px, 셀 문자는 15px입니다. 별도 가로 스크롤이 필요하지 않은 현재 내용입니다.
- 참고 자료의 불릿 세 개와 줄 간격을 실제로 확인했습니다. 목록 표지 CSS는 disc이며 링크가 여러 줄로 바뀌어도 다음 항목과 구분됩니다. 코드 블록은 없습니다.
- 다크 모드에서는 본문·표·소제목·링크의 대비가 유지되고, 밝은 배경이 섹션 내부에 남지 않습니다. 이미지 주변은 중립적인 어두운색이며 래스터 자체는 바뀌지 않습니다. 굵은 저자 입장 문장과 링크 스타일도 보존됩니다.

## 게시 조각 확인

게시 HTML의 H1은 0개이며 unresolved media directive와 로컬 파일 경로는 없습니다. media.json의 native Image 블록 하나가 그대로 들어 있고 alt가 일치합니다. 외부 래퍼는 devlog-rich__native-image div입니다. 관측 URL의 원격 프리뷰와 native 게시 조각을 구분해 확인했습니다.

이 검수는 standalone 후보에 대한 유일한 독립 최종 페이지 승인입니다. 실제 Tistory 편집기에서 native 블록이 변환된 화면과 공개 게시 후의 데스크톱·모바일 검증은 게시 담당 단계에서 이어져야 합니다.

## 기록

final-measurements.json에서는 readable_media, 각 status, dark_theme의 사람 판단 필드만 채웠습니다. 생성된 수치와 viewport는 바꾸지 않았습니다. record_final_page_v2.py가 현재 해시에 결합된 final-page.json을 성공적으로 기록했습니다. 해결하지 않은 시각 결함은 없습니다.
