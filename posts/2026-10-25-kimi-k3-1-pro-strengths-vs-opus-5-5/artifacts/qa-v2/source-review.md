# 독립 소스·원고 검토

## 사전 자료를 읽기 전 독해 기록

이 글은 Kimi를 처음 접하고 문서·코딩 작업에 쓸 AI를 알아보는 독자를 대상으로 한다. 중심 질문은 “Kimi K3.1 Pro는 무엇을 잘하며, 공개 평가에서 Claude Opus 5.5와 어느 정도 차이가 나는가?”이다. 글은 서비스에서 파일을 넣는 방법부터 문서 제작, Kimi Work와 Code, 3D Make, 공개 성능과 API 비용 순서로 설명한다.

독자가 얻는 결론은 종합 지능 평가에서는 Opus가 앞서지만, Kimi도 문서 근거 탐색·계산 및 코딩 과제에서 비슷한 성적을 보이고, 일반형 API 입출력 단가가 낮다는 것이다. 실제 모델을 직접 사용한 결과로 주장하지 않으며, 웹 화면 확인과 제작사가 공개한 기능·평가를 구분하려고 한다.

첫 화면만 읽어도 Kimi가 Moonshot AI의 서비스라는 점과 K3.1 Pro가 그 서비스에서 쓰는 모델이라는 점을 알 수 있다. 다만 “문서와 3D 결과물을 만듭니다”라는 두 번째 문단의 표현은 모델 자체와 서비스·도구가 함께 만드는 결과를 초심자가 구분하기 어려울 수 있다. 첫 화면에서 구체적인 비교 수치는 제시하지 않지만 본문의 질문은 분명하다.

제목과 소제목만 읽으면 웹 사용 시작, 긴 자료와 결과물, 3D 제작, Opus 대비 성능, API 비용이라는 전체 구조를 파악할 수 있다. “긴 자료를 읽고 결과물을 만드는 방식”은 서비스 구성 소개까지 포함하는 넓은 제목이지만 실제 본문과 모순되지는 않는다. 대체 여부를 묻는 방향으로 흐르지 않는다.
