FAQ

The web version is more of a good fit for quick chats and everyday tasks. Kimi Work is designed for work that needs deeper access to your desktop environment and local files, or repetitive tasks. It can use the local folders you allow, work through browser tasks with Kimi Browser Extension, run Python code, and complete scheduled work in the background.
You decide what Kimi can access and what actions it can take. With Ask before acting enabled, Kimi asks for your permission before actions such as changing or overwriting files, or running code in your local folders.
Kimi Browser Extension helps Kimi complete tasks directly in the browser. You can ask it to research across websites, summarize the latest information, collect data, or save results to a local Excel file. Kimi can handle actions such as clicking, scrolling, switching tabs, and extracting information for you.
You can schedule LLM Agent calls, Python or Shell scripts, and other tasks to run automatically. Tasks can run hourly, daily, or when certain conditions are met. For tasks that need to continue overnight, turn on Keep Computer Awake in Settings.
