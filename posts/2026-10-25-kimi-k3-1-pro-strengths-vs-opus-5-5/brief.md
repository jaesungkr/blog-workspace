# Kimi K3.1 Pro란? 문서·코딩 AI의 장점과 Opus 5.5 비교

## Reader and intent

- One reader: ChatGPT/Claude로 문서를 읽히거나 업무 결과물을 만드는 일을 알고 있지만 Kimi는 처음 접하는 한국어 사용자.
- Recognizable situation: PDF를 읽은 뒤 비교표와 발표자료를 만드는 일에 AI를 활용하려고 한다.
- Unknown: Kimi의 개발사와 서비스 정체, K3.1 Pro가 서비스 안의 모델이라는 점, 웹·Work·Code의 역할, Opus 대비 수준.
- One practical proposal: 문서의 근거를 모아 결과물로 만드는 용도로 Kimi의 기능을 이해한다. 구독 추가·제품 전환·대체 권유는 하지 않는다.
- Retained message: Kimi는 긴 자료와 도구를 다루는 업무·코딩·3D 제작에서 강점을 보이고, Opus 대비 종합 평가 격차와 업무별 경쟁력 및 일반형 API 단가를 각각 확인할 수 있다.
- Useful consequence: 생소한 모델 이름을 일상적인 문서/코딩/제작 작업과 연결하고, 어떤 근거로 평가하는지 구분한다.
- Search intent/title: Kimi K3.1 Pro 정체·장점·Opus 비교. Search review is qualitative; no query-volume or traffic forecast.

## Opening movement and boundary

PDF 읽기에서 발표자료 제작으로 이어지는 작업 -> Kimi는 무엇인가 -> 모델/서비스 구분과 결과물 제작 -> 항목별 성적은 다르다는 질문으로 비교를 연결한다. 출시는 공식 연구 목록의 2026-10-24를 기준으로 표현한다. AA 기사 표기는 10-23이며 같은 날짜라고 합치지 않는다.

Default easiest start: 웹의 가운데 입력창과 +의 파일 첨부. UI 표시를 직접 관찰했으나 로그인·첨부·모델 추론은 실행하지 않았다. 예시 프롬프트는 작성 구조를 보여 주는 예시로 표시한다. 공개 UI 관찰, 공식 기능 설명, 제조사 평가, 독립 평가, Codex 산술 계산을 구분한다.

## Question map and explanation chain

1. Kimi가 무엇이고 어디서 질문/파일을 넣는가? -> opening and first section; home and attachment screenshots.
2. 긴 자료와 결과물 작업을 어떻게 연결하는가? -> context size, Work and Code roles; no architecture detail.
3. Kimi에서 눈에 띄는 제작 기능은 무엇인가? -> actual 3D Make entry/templates and official 3D/CAD examples.
4. Opus 대비 수준은 어느 정도인가? -> explained metrics first, separate independent and vendor tables; settings/source restrictions next to values.
5. 비용은 어떻게 다른가? -> same-unit international API table and reproducible arithmetic; Highspeed/caching and subscription distinction.

Excluded: 대체 판정, 일반적인 구독 구매 조언, 투자 추천, 금융 안전성 보증, 모델 파라미터·RL 구현 설명, 자체 실험을 가장한 프롬프트 결과, 한국어 품질 우열, 다운로드/로컬 설치 가이드.

## First-party contribution

Codex의 2026-10-25 공개 UI 관찰 3종, 국제 API 요금표 관찰, 평가 결과를 같은 열로 정리한 비교, 같은 처리량의 비용 산식, 출처에 따른 수치 차이의 분리. 원문 HTML 및 DOM 스냅샷과 변경하지 않은 캡처를 보존한다. 사용자의 체험담으로 표현하지 않는다.
