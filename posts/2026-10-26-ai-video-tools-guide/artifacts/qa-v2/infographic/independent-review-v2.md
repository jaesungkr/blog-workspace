## 검수 범위와 증거

원고·brief·evidence의 C01/C02/C04/C19, copy map, 최초 프롬프트, edit-prompt-v2.txt, generation-v2.json을 확인했다. 정확한 v2 원본 전체를 `view_image(detail="original")`로 열고, 그 파일을 HTML에서 실제 너비 320 CSS px로 표시한 화면을 열었다. 자료 준비 장면·클립 생성 장면·최종 편집 장면과 세 라벨, 두 화살표/화살촉을 각각 확대 캡처해 검사했다.

`visual-inspection-v2.html`, `capture_independent_inspection_v2.py`, `independent-display-receipt-v2.json`, `actual-320-browser-viewport-v2.png`, `*-enlarged-v2.png`가 동일한 원본 경로와 해시에 묶인다. 원본의 자연 크기는 1448×1086, 실제 작은 표시는 320×240으로 확인했다. 별도 축소 래스터를 만들거나 공개 이미지를 재인코딩하지 않았다. 확대 영역은 원본을 브라우저에서 1.5배 표시한 화면이며, 검사 영역을 글자 전체가 보이도록 조정한 후 다시 캡처·관찰했다.

처음 in-app browser 선택은 하위 검수 환경에서 unavailable이 반환됐다. v1과 동일하게 저장소의 목적별 Chrome/CDP 캡처 도구를 재사용해 로컬 이미지 표시만 검사했다. 티스토리 편집·업로드·게시 작업은 하지 않았다.

최신 `preflight/360-workflow.png`, `preflight-dark/360-workflow.png`를 각각 열었고 local-preflight-measurements.json이 v2 경로를 참조하는 것도 확인했다. 소개 문단 뒤에 이미지가 놓였으며, 개념도라는 캡션은 이미지 밖에 정상적인 본문 크기로 표시된다. 두 테마 모두 이미지 내부의 밝은 바탕과 글자 대비가 유지된다.

## 라벨·연결부·공간 관찰

- `자료 준비 / 클립 생성 / 최종 편집`의 정확한 글자와 한 줄 배치를 읽는 순서대로 확인했고, 라벨만 따로 훑어도 같은 세 단계가 남는다. 추가 제목·설명·번호·가짜 문자는 없다.
- 글자 주변에 그림이나 선이 들어오지 않는다. 확대해서 본 첫 화살촉과 가운데 라벨, 둘째 화살촉과 마지막 라벨도 분리되어 있다.
- 위쪽 라벨과 사진의 의미 있는 상단, 중앙 라벨과 프레임 선 사이에는 각각 대략 12px/17px의 원본 여백이 있다. 마지막 라벨 아래부터 프레임 선까지는 약 8px로 더 좁지만 연결선·문자 획이 닿거나 합쳐지지 않으며 실제 크기에서도 라벨을 그림과 구분할 수 있다. 편집 프롬프트가 요구한 모든 주변 18px 여백이 수치상 충족됐다고 주장하지 않는다. 관측된 작은 여백은 현재 이미지에서 읽기나 관계 이해를 방해하는 결함으로 보이지 않는다.
- 이 그림에는 인위적인 가로 구분선이 없다. 장면과 화살표가 구분선에 닿는 문제도 없다. 넓은 여백으로 세 장면을 연결하고, 의미 없는 바닥 문구나 장식 구획을 채우지 않았다.
- 실제 화면에 보이는 둥근 이미지 외곽은 본문 CSS의 표시이며, 원본 그림 안에 큰 외곽 카드나 포스터 제목이 들어간 것이 아니다.

## 설명 정확성과 전체 품질

- 위 왼쪽 사진/자료가 중앙의 연속 프레임을 거쳐 아래 오른쪽의 자막·썸네일·소리 파형으로 이어진다. 라벨을 가려도 준비 자료, 움직임이 있는 클립, 최종 편집 결과의 차이가 보인다.
- 같은 청록색 운동화와 크림색 밑창이 단계별로 유지된다. 가운데 세 프레임은 시점이 점진적으로 바뀌고 마지막 장면은 클립 조합과 자막·소리 작업을 나타낸다.
- 화살표가 교차하거나 역방향을 암시하지 않는다. 한 장면에서 다음 장면으로 진행한다는 관계가 첫눈에 읽힌다.
- 원본 사진을 바탕으로 하는 설명 삽화이며 실제 제품 화면이나 실험 성공 기록을 모방하지 않는다. 상표·가짜 UI 문구·수치·순위·보장된 성능을 추가하지 않았다. C19와 주변 캡션의 범위를 벗어나지 않는다.
- flat vector보다 제품 사진을 포함한 편집 설명 그림에 가깝지만 사용자 요청과 본문 역할에 적합하다. 현재 수정의 목적이던 가독성은 해소됐고, 그림의 제품 형태와 사진·프레임·파형은 과도하게 변하지 않았다.
- 1초 재관찰에서 읽힌 것은 세 단계의 변환 관계였다. 큰 제목 위주의 포스터, 텍스트 시트, 카드 그리드로 보이지 않는다. 라벨은 설명을 돕고 그림의 관계가 중심에 남는다.

원본/실제 320px/모든 라벨·연결부 확대 검수에서 알려진 출판 차단 결함은 남지 않았다. v2만 통과 대상으로 선정하며 v1은 revision_required 이력을 유지한다. 이 기록은 보조 이미지의 독립 검수이며, 사용자 게시 승인이나 최종 원격 페이지 승인 기록을 대신하지 않는다.
