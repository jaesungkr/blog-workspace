# 담배를 끊고 세 달째

## 작성과 원전 대조
- 저자 제공 현재 경험을 회고의 원전으로 사용했다. 흡연 기간·초기 패치 계획은 이전 공개 글, 저장소 article.md, raw 원고를 함께 읽어 확인했다.
- 조사한 주체는 Codex이고, 3개월차 경험 주체는 저자이다. 연구 확인을 저자의 금연 당시 행동으로 새로 소급하지 않았다.
- 패치 준비 후 오전 사용을 미룬 사실과 '니코틴을 단번에 끊으려 한 선택'을 보존한다. 오후 이후 실제 사용 이력은 공개 글에도 확인되지 않아 창작하지 않았다.
- 기존 dirty worktree와 origin을 확인하고 origin/master를 fetch했다. 시작 당시 HEAD와 origin/master 차이는 0/0. 기존 스킬·CSS·다른 글 수정 및 삭제는 보존한다.

## 이해·목적 확인
독자는 초기 금단 때문에 첫 금연을 망설이는 성인이다. 약17년 흡연한 저자가 첫 시도 후 3개월차에 느낀 강도 변화와 준비에 대한 후회를 설명한다. 개인 회고는 5일차와 현재 두 시점 비교이고 수치측정·원인 진단은 없다. NRT·금연방법 연구는 초기 도움을 준비하는 선택을 뒷받침하고, 수명 연구는 오래 피웠어도 중단할 가치가 있다는 범위를 맡는다. 후기에 임상 연구를 혼합해 전자담배의 회복 속도를 보장하지 않는다.

## 독자 계약·도입·범위
- 첫 화면은 식후·취침 전 강한 욕구 감소를 먼저 밝힌다. 잔존 욕구와 초기의 어려움을 이어 붙인 뒤 도움을 준비하라고 권한다.
- 도입에 목차 안내나 '결론부터'·'이번 글에서는'을 넣지 않았다.
- 제목 질문별 담당 절과 제외 주제는 brief.md에 고정했다. 일반 건강 습관·운동 식단 체크리스트·약물별 처방 순위는 제외했다.
- topic-link: 패치는 초기 무보조 시작 후회에 연결하고, 연구 표는 치료 선택·금연 이익에 연결한다. 팽만의 진료 기준은 실제 겪은 2~3개월차 소화 증상에 붙인다. 환경 조정은 실제 적은 흡연 동료라는 조건을 설명한다. 도구 정리는 실제 기기 폐기 행동을 해석한다. 마지막 상담은 첫 시도 독자가 실행할 시작 방법이다.

## 제목·소제목과 비교 원고
같은 subcategory의 최근 ready 글 다섯 편을 살폈다. published 표시는 해당 원고들에 없어 ready 상태를 그대로 기록한다.
- 2026-08-31-clascoterone-5-percent-hair-loss: ready, 회사 수치·허가 단계별 설명.
- 2026-08-22-dementia-risk-reduction-guide: ready, 원인·예방 질문형 제목.
- 2026-08-20-aim-cat-longevity-drug: ready, 치료제 기대와 근거 구분.
- 2026-08-06-smoking-cessation-day-5: ready, 전편으로서 경험 회고의 연결 대상.
- 2026-07-29-hiccup-causes: ready, 반사 설명과 대처.
같은 분류에 다섯 편이 있어 fallback 없음. 이 글은 회고여서 전편 제목의 5일차만 3개월차로 바꿔 연속성을 유지했다. 정보성 글의 질문형 제목을 반복하지 않았다.

초기 소제목을 그대로 공개 구조로 채택했다. 임시 템플릿 '핵심 메시지'는 제거했다.
1. 한 시간 반도 길었던 17년: 흡연 빈도·조절 어려움과 첫 시도.
2. 다시 시작한다면 니코틴 패치부터: 저자의 바뀐 선택.
3. 금연 방법을 고를 때 참고할 연구: 치료 효과와 건강 이익의 근거·범위.
4. 첫 주의 금단, 그 뒤에 남은 담배 생각: 일반 경과와 개인의 두 시점 비교.
5. 2~3개월차에 겪은 소화불량과 가스: 관찰·원인 미확인·진료 판단.
6. 담배를 권하지 않는 주변 환경: 권유 없는 조건과 조정 방법.
7. 기기와 액상을 모두 버린 이유: 재사용 접근성을 낮춘 실제 결정.
8. 처음 시작하는 분에게: 상담 시작과 15분 대처, 응원.

## 문장·밀도 수정
- '금연 때문에 생겼다고 확정해서 설명하기는 어렵습니다' → '제가 겪은 소화불량과 가스의 원인은 따로 확인하지 않았습니다.' 원인 미확인 상태를 직접 밝혔다.
- 연구 적용 범위 뒤 식후·취침 전 변화의 전면 반복 → 삭제. 해당 비교는 개인 경과 절이 담당한다.
- '제 주변이 흡연을 많이 하는 집단이 아니라는 점' → '제 주변에는 자주 함께 흡연하는 사람이 많지 않았습니다.' 저자와 주변 사람이 한 문장 안에서 명확하게 연결된다.
- 길었던 Smokefree 요청 문장 → 출처와 실제 요청 행동을 두 문장으로 분리했다.
- 도구 정리 절의 '처음부터 두 가지를 준비했으면' 반복 → 삭제하고 금단이 지속될 때 치료 계획 상담을 안내했다.
- 결말에서 세 번째로 반복하던 초기 대비 호전 설명 → 삭제. 금연 지속과 사용자 요청인 준비·응원을 남겼다.
- '커피를 끊는 것과 차원이 다르다' → 저자가 예상한 고통 수준과 실제 체감 차이로 서술한다. 카페인과 니코틴의 의학적 중독성 순위를 만들지 않았다.
- 주변의 권유가 계속되면 '금연 무기한 연기' → 흡연 약속 조정·권유 중단 요청 뒤 금연일 계획으로 구체화했다. 금연을 어렵게 하는 조건이라는 저자의 뜻을 유지했다.
- analyzer는 prose-before.txt/prose-after.txt에 남겼다. generic-heading '이유' 신호는 실제 기기 폐기 행동과 이유를 다루므로 유지했다. 단어 수치를 품질 점수로 사용하지 않았다.

## 새 정보와 반복의 소유
- 도입 두 문단: 현재의 체감, 잔존 욕구와 준비 권고.
- 과거 절 네 문단: 시작·대략 기간 / 빈도·참기 어려움 / 새 지역의 흡연장 / 첫 시도와 타인과의 차이.
- 패치 절 네 문단: 최초 계획 / 실제 오전 고통·후회 / 다시 택할 방법·예상 차이 / 담배중단과 치료용 니코틴감량 구분.
- 연구 절: 전편과 질문 연결 / 치료·장기금연 용어 / 서로 다른 비교 4행 / 상대효과·집단추정 한계 / 연초 연구 범위 / 다른 약물과 상담.
- 경과 절: 공식 시간표 / 첫날·5일차 기억 / 상황별 두시점표 / 측정 아닌 회고 / 환경·습관 자극과 가래의 의미.
- 소화 절: 경험·현재 호전 / 원인 미확인 / 실제 진료 기준.
- 환경 절: 저자 조건 / 독자의 권유 환경 조정 / 근거와 조정 어려울 때 상담.
- 폐기 절: 실제 폐기물 / 욕구 순간의 접근성 / 공식 안내와 치료 계획.
- 끝: 의존 양상 전달 / 국내 상담과 개인 15분 대처 / 금연 지속·응원.
패치후회는 두번째 절, 연구수치는 표, 시간표는 경과 절, 소화원인은 소화 절, 사회적 권유는 환경 절, 폐기이유는 폐기 절이 각각 담당한다. 도입과 마지막의 짧은 준비 권고·응원은 사용자 의도를 전달하기 위해 남겼다.

## 보호한 사실과 제한
연초10년·전자담배7~8년은 모두 약수이다. 현재는 '3개월차'이며 90일·100일로 바꾸지 않았다. NRT 효과 배수를 퍼센트포인트로 혼동하지 않는다. 연구별 비교 대상은 다르다. 수명 연구는 연초 흡연 집단 관찰이며 개인 예측이 아니다. 전자담배에 그대로 적용하지 않는다. 복부 증상의 원인 미확인·위험 신호를 편집 과정에서 보존했다. 의사·약사 상담과 약물 사용 범위를 보존한다.

### 캡션 삭제에 따른 명시적 예외
공통 검사기는 모든 이미지에 비어 있지 않은 caption을 요구한다. 저자는 이미지 설명을 삭제하라고 명시했고 현재 원고는 빈 캡션을 의도한다. 공유 스킬·검사기는 수정하지 않았다. bundle 내부 render_captionless_review.py는 해당 이미지의 빈 캡션 오류 한 건만 명시적으로 기록하고 나머지 오류는 모두 중단한다. 렌더에서 빈 figcaption을 제거한다. 이 예외는 로컬 저자 검토본에만 적용하며 게시 통과로 표시하지 않는다. hero는 독립 검토 pass를 확인한 뒤 validated로 갱신했다.

### 3차 독립 원고 검토 뒤 수정
