## 독자 이해

article.md를 먼저 읽고 첫 화면과 heading만 다시 읽은 후 brief/evidence/audit를 확인했다. 원고 질문은 “기존 Opus/Sol 업무를 더 저렴한 Terra로 옮겨도 되는가”다. 첫 화면의 정체→교체 고민→분야별 차이→가격 흐름은 자연스럽다. 시험별 결과, 종합 지수, 개인 후기, API 요금을 별도 표·절로 나눠 무엇을 비교하는지 이전보다 명확해졌다.

## 수정 요청

아래는 최초 검토 내역이다. 이후 부모가 전달한 최신 사용자 지정과 수정 확인은 마지막 절에 기록했다. 표 조건 위치의 최초 요청은 철회됐다.

1. **평가 조건을 표 전에 설명해야 한다.** 공식표 뒤의 max·높을수록 좋음·결측·fallback 설명, AA표 뒤의 날짜·지수 버전·max/fallback 조건, 가격표 뒤의 100만 토큰/달러·토큰 정의가 모두 결과를 본 다음에 나온다. 출처 링크는 표 뒤에 두어도 되지만 읽는 기준은 표 앞의 짧은 문단으로 옮긴다. max는 `추론에 쓰는 양을 최대로 설정한 조건`처럼 한 번 설명한다. fallback은 공식표에서는 과학 연구 코딩의 Opus에만 해당함을 유지하고 AA에서는 서비스 평가 구성에 포함된다는 구분을 보존한다. 별표를 표 전 설명과 연결하거나 셀에 짧게 표시한다.

2. **공식 차트 원자료 검증 기록을 확정해야 한다.** 현재 evidence의 `직접 HTML 수치확인 증거 전달 대기` 및 `대체 예정`은 미해결 상태다. 부모의 실제 확인 주체, 확인한 공식 HTML/Vega-Lite 항목, 각 모델/effort/평가/단위 매핑과 저장 증거 또는 구체적 검증 receipt를 기록한다. 이 검수자는 부모 전달값의 전사만 확인했음을 유지한다. 단순히 기존 미확보 문장을 지우거나 이 검수자를 직접 확인자로 쓰면 안 된다.

3. **마지막 권고 반복을 줄여야 한다.** 결론 첫 두 문단이 반복 업무의 Terra와 어려운 작업의 기존 모델을 각각 설명한 뒤, 마지막 문단 `결국 나눠 맡기는 쪽이 자연스럽습니다. 반복 입력에는 Terra를, 해결하기 어려운 문제에는 기존 상위 모델을 쓰는 식입니다`가 그대로 재진술한다. 두 문장을 삭제하고 비용 절감 여부를 가르는 수정·총비용 조건으로 끝내면 충분하다. 제목의 선택 질문은 앞 두 문단이 이미 답했다.

권고: 비용 예시의 `출력 1만 토큰`을 `청구 대상 출력 1만 토큰`으로 유지하면 숨은 추론 토큰까지 포함한 계산이라는 뜻이 정확하다. 결말의 비용이 수정 횟수에만 `달려 있습니다`는 표현은 `수정 횟수와 끝날 때까지 쓴 토큰에 따라 달라집니다`로 명확히 할 수 있다. 후기는 사용량을 API 비용으로 환산하지 않는 현재 범위를 유지한다.

## 사용자 지정 반영 후 최종 부분 판정

부모가 전달한 최신 사용자 지시는 “필요한 근거·조건은 표 아래 짧은 주석으로 모으세요”다. 따라서 조건을 표 앞으로 옮기라는 일반 지침에 따른 요청 1은 철회한다. 현재 주석에 max의 뜻, 모델마다 계산량이 다름, 점수 방향, 미표시 및 fallback이 설명돼 있고 사용자의 지정 위치를 따른다. 주석 위치만으로 source 실패를 판단하지 않는다.

원고를 다시 확인해 max 풀이 추가, 결론의 `결국 나눠 맡기는…` 두 문장 삭제, 미표시 기호를 em dash에서 하이픈으로 변경한 것을 확인했다. 결론의 앞 두 문단은 Terra와 기존 모델의 선택을 각각 종합하고 마지막은 수정 부담이라는 비용 조건을 남긴다. 문체·독자 이해·중복 검수 pass다. 출력 토큰과 결말의 총토큰 표현 보강은 선택적 권고이며 현재 계산 가정을 무효화하는 오류는 아니다.

전달된 공식 점수의 원고 전사는 전부 일치하므로 **전사 pass**. 기존 직접 검증한 AA 지수·단가·후기 및 산술도 **pass**다. 단, 원문 차트를 직접 읽어 각 숫자·모델·max·백분율을 확인하는 단계는 **pending**이다. 부모 검증 전달값을 본인의 직접 확인으로 기록하지 않는다. evidence의 원자료 확인 receipt가 확정되기 전에는 전체 source pass를 새로 발급하지 않는다.

이 검수자는 정책상 거부된 shell 경로 또는 브라우저를 재시도하지 않았다. 남은 blocker는 공식 HTML/Vega-Lite 원자료의 독립 확인 및 부모 검증 증거 확정이며 문체 수정이나 산술 문제가 아니다.

## 원자료 receipt 수신 후 최종 판정: pass
