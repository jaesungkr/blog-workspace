# GPT-6.1 Terra, 화면을 읽고 앱 작업을 돕는 AI

- 독자: ChatGPT로 원고와 이미지 작업을 하면서 Terra의 사용처를 찾는 비전문가.
- 상황: 이미지 설명을 넘어 앱에 정보를 옮기는 일을 맡기고 싶음.
- 기억할 메시지: Work/Codex의 Terra는 화면 기반 작업 후보이며, 실제 실행에는 도구와 접근 환경이 필요함.
- 가장 쉬운 시작: Work의 Advanced 모델 목록 확인.
- 지식 기준: 모델명, 서비스명, API 요금을 혼동할 수 있음. 이를 먼저 구분.
- 실용 추천과 효과: 원고/미리보기/편집기 입력을 나눠 결과와 전제조건을 확인하면 미완료 작업을 식별할 수 있음.
- 첫 화면: 무엇인지 → Work/Codex 제공 → 일반 Chat 제외.
- 독자 질문 소유권: 제공 위치(1절), 앱 작업의 의미(2절), 비용 단위(3절), 성능 해석과 미지원 입출력(4절).
- first-party value: dev.log 티스토리 작성 작업을 자료·권한·검증대상으로 분해한 명시적 판단표 및 재현 가능한 API 텍스트 비용 계산. 실사용 성능 테스트로 부르지 않음.
- 직접 시험 경계: Terra 호출, 한국어 품질 비교, 계정별 모델 목록, Tistory 게시 실행은 수행하지 않음. 공개 공식 문서 검증과 계산만 Codex 수행.
- 제외: 전체 벤치마크 순위, 한국어 우월성, 무제한 사용, 계정별 UI 캡처, 구독 추천, 실사용 후기.
- 시각 계획: 이미지 정보가 실행으로 이어지는 일을 종이 도면과 커서의 촉각적 은유로 표현한 생성 hero. 제품 UI 또는 성능 증거로 표현하지 않음. 도입 뒤 배치.
- 보조 그림 검토: max-txt2img의 과정 은유와 diagram-design의 조건 분기를 검토했으나 3행 판단표가 더 정확하고 짧음. 추가 infographic not_applicable.
- 화면 캡처: 절차 튜토리얼이 아니라 제공 범위 설명이므로 스크린샷 없음. 확인하지 않은 계정 UI를 재현하지 않음.
- 승인 범위: 새 묶음 로컬 초안/QA만. 기존 글 수정, 공개 게시, push 금지.
