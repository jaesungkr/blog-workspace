# 한 번 보여 주면 다음부터 맡길 수 있을까? 화면 녹화로 AI 스킬 만들기

독자: 화면 녹화로 반복 업무를 스킬로 만드는 기능을 처음 접하는 비개발자.
유지할 메시지: 업무를 보여 주면 절차 초안이 만들어지고, 판단 기준을 확인해 저장한 뒤 다른 입력으로 다시 쓸 수 있습니다.
범위: 경쟁사 리뷰 조사라는 익숙한 작업을 설명 예시로 사용. 영상에서 확인된 범위는 설명·챕터이며 시청 후기 아님. 제품 메뉴·지원·보관은 공식문서로 분리 검증.
제외: 시뮬레이션/Artifacts/Visualize, 코드 구조, 실제 계정 녹화·설치, 자동화 설정 실행, 완벽 재현 주장.
원본 가치: 기능의 단계별 결과물 구분, 리뷰 조사 기준의 독창적 예시, 저장과 예약 구별, 최신 공식 기능 범위 확인.
미디어: 공식 Claude 녹화기능·검토저장 안내2장, 자체 설명용 흐름도1장 계획. 영상 actual 캡처는 확보 실패하여 사용하지 않음. 공식 문서 캡처도 부모 전달 전 잠정 배치. 흐름도는 간단한 HTML 4단계 설명이며 제품 UI를 흉내 내지 않음. max-txt2img보다 순서가 정확한 설명 도식을 선택. 독립 픽셀검수 전 publishable 처리하지 않음.
상태: drafting, 사용자 검토용. 새 별도 Library로 전달. 기존 simulation 산출물은 보존하며 게시 금지.

## 사용자 수정 후 현재 중심 예시

경쟁사리뷰와 영상챕터 설명은 본문에서 제거. 날짜와 주제를 사용자가 명시하는 가상의 연습 파일 정리로 통일. 다음파일에도 같은규칙을 쓰는 이익을 보여줌. GPT/Claude 모두존재는 짧게, 지원환경은 하단, 출시일은 별도질문답변으로 처리하고 본문생략. 기존3이미지는 범용이므로 재사용. 추가전후도식은 선택사항이며 원고에는 짧은표만 사용.
