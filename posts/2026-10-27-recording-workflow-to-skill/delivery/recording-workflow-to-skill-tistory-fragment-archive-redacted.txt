<p>아래는 이해를 돕기 위해 만든 가상의 연습 예시입니다. <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">정리연습</code> 폴더에 <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">자료1.pdf</code>가 있고, 이 파일에 붙일 날짜는 <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">2026-10-01</code>, 주제는 <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">여행계획</code>이라고 미리 정했다고 해 보겠습니다.</p>
<p>내가 보여 줄 일은 간단합니다. 파일 이름을 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">2026-10-01_여행계획.pdf</code></strong>로 바꾸고, <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">정리연습</code> 안의 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">2026-10</code> 폴더</strong>로 옮깁니다. AI가 파일 내용을 보고 날짜나 주제를 추측하게 하는 것이 아니라, 내가 정한 이름 규칙을 보여 주는 예시입니다.</p>

<section class="devlog-rich__section is-alt" aria-labelledby="녹화를-켠-뒤-평소처럼-작업하기">

<p>Claude를 예로 들면, 최신 Mac 앱의 Cowork에서 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">+ → Record a skill</code></strong>을 선택합니다. Cowork는 여러 단계의 업무를 맡기는 작업 모드입니다. 처음에는 요청되는 macOS 접근성·화면 기록 권한을 허용해야 합니다. <a href="https://support.claude.com/en/articles/12512198-how-to-create-custom-skills" style="color:#1a73e8;text-decoration:none;" target="_blank">공식 녹화 안내</a>를 기준으로 합니다.</p>

<section class="devlog-rich__section" aria-labelledby="저장-전에-이번-파일에만-맞춰져-있지-않은지-확인하기">
<h2 id="저장-전에-이번-파일에만-맞춰져-있지-않은지-확인하기">저장 전에 이번 파일에만 맞춰져 있지 않은지 확인하기</h2>
<p>녹화가 끝나면 AI가 스킬을 제안합니다. Claude에서는 제안 카드의 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">Content</code></strong>를 열어 내용을 읽고, 새 스킬은 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">Save</code></strong>, 기존 스킬 수정은 <strong><code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">Update</code></strong>로 반영합니다.</p>

<h2 id="다음에는-다른-파일을-같은-방식으로">다음에는 다른 파일을 같은 방식으로</h2>
<p>저장한 스킬을 사용할 수 있게 켠 뒤, 새 대화에서 이름을 지정해 요청합니다. Claude의 저장된 스킬은 <strong>Customize → Skills</strong>에서 확인할 수 있습니다. <a href="https://support.claude.com/en/articles/12512180-use-skills-in-claude" style="color:#1a73e8;text-decoration:none;" target="_blank">공식 스킬 사용 안내</a>에 따른 흐름입니다.</p>
<pre style="background:#f6f6f6;border:1px solid #e5e5e5;border-radius:4px;padding:14px 16px;overflow-x:auto;font-size:0.9em;line-height:1.6;margin:1.4em 0;"><code style="font-family:Menlo,Consolas,monospace;white-space:pre;">저장한 ‘파일 정리’ 스킬을 사용해 줘.
이번에는 ‘정리연습/자료2.pdf’를 정리할 거야.
날짜는 2026-11-03, 주제는 모임안내로 해 줘.</code></pre>
<p>앞서 정한 규칙을 적용하면 기대하는 결과는 <code style="background:#f0f0f0;border-radius:3px;padding:2px 5px;font-family:Menlo,Consolas,monospace;font-size:0.92em;">정리연습/2026-11/2026-11-03_모임안내.pdf</code>입니다. 이번에는 파일 이름을 붙이는 방법과 월별 폴더를 고르는 규칙을 다시 설명하지 않아도 됩니다. 실제로 이 파일을 정리한 결과가 아니라, 스킬을 재사용하는 방법을 보여 주는 예시입니다.</p>
<p>처음 다시 사용할 때는 복사해 둔 연습 파일로 결과를 확인하세요. 지정한 파일만 바뀌었는지, 이름과 폴더가 맞는지 살펴본 뒤 필요한 기준을 보완하면 됩니다. 스킬에 방법을 저장해도 실제 파일에 접근할 도구와 권한은 별도로 필요합니다.</p>

<section class="devlog-rich__section" aria-labelledby="두-서비스-모두-있지만-지원-환경은-확인하기">
<h2 id="두-서비스-모두-있지만-지원-환경은-확인하기">두 서비스 모두 있지만, 지원 환경은 확인하기</h2>
<p>Claude의 <strong>Record a skill</strong> 녹화는 현재 <strong>Mac용 Cowork의 Pro·Max·Team</strong>에서 지원합니다. 일반 채팅·Windows·Free·Enterprise는 제외됩니다. 일반 스킬을 사용할 수 있는 범위와 녹화 기능의 범위는 다릅니다. <a href="https://support.claude.com/en/articles/12512198-how-to-create-custom-skills" style="color:#1a73e8;text-decoration:none;" target="_blank">Claude 녹화 지원 조건</a>.</p>
<p>ChatGPT에도 <strong>Record &amp; Replay</strong>라는 같은 종류의 기능이 있습니다. 공식 안내상 <strong>macOS에서 Computer Use가 제공되고 활성화돼 있어야</strong> 하며, 녹화로 만든 스킬을 새 대화에서 바뀐 입력값과 함께 재사용합니다. <a href="https://learn.chatgpt.com/docs/extend/record-and-replay" style="color:#1a73e8;text-decoration:none;" target="_blank">OpenAI 공식 안내</a>.</p>
<p>녹화 전에는 비밀번호나 사적인 대화가 보이는 창을 닫아 두세요. Claude는 검토 후 영상·음성을 보관하지 않지만 작업의 스크린샷은 남습니다. <a href="https://support.claude.com/en/articles/12512198-how-to-create-custom-skills#whats-kept-from-a-recording" style="color:#1a73e8;text-decoration:none;" target="_blank">녹화 자료 보관 안내</a>.</p>
<p>스킬을 저장했다고 매일 자동으로 정리가 시작되는 것은 아닙니다. 정해진 시간에 실행하려면 예약을 따로 설정해야 합니다. 먼저 작은 연습 작업 하나를 보여 주고, 다음 파일에서도 같은 규칙으로 처리되는지 확인하는 것부터 시작하면 됩니다.</p>
