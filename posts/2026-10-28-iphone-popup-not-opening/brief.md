# 보관 범위

게시된 159번 글의 승인 원고와 증거 보관. Safari에서 예매 새 창이 열리지 않는 독자를 위한 설정 안내. 서버·대기열 문제 해결이나 직접 예매 성공을 주장하지 않습니다.

저장소 분류 Log > 개발 · 디지털은 기존 taxonomy 호환 매핑입니다. 실제 Tistory 분류는 생활·기록 > 생활정보·비교 (847699)입니다.

사용자가 제공한 실제 Safari 설정의 회색 OFF 스위치를 보여 주는 한 장을 해당 설정 설명 직후 배치합니다. 다른 메뉴 화면과 별도 인포그래픽은 단순 경로를 반복하므로 생략합니다. 생성 hero, GIF, 추가 breakpoint는 해당하지 않습니다.
