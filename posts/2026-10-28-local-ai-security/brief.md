# Brief

- 제목: 내 서버의 AI, 정말 안전할까?
- 독자: 회사 문서를 외부 AI 서비스로 보내기 부담스러워 자체 호스팅을 검토하는 한국어 독자.
- 메시지: 서버 위치와 도구 권한은 서로 다른 운영 결정이며, 맡긴 작업에 필요한 파일·명령·네트워크 권한만 허용합니다.
- 분류: Trends > AI 뉴스 · 테크 · 산업; standard-rich 보도 해설.
- 승인 범위: 전달된 최종 원고 보존, 첫 그림 교체, 두 번째 그림 유지. 본문을 임의로 수정하지 않습니다.
- 구성: Cohere 관찰과 한계 → 모델·도구·권한 구분 → 가상 회의록 사례 → 권한 점검.
- 기여: 공개 보고와 OWASP 가이드를 회의록 처리의 권한 결정 예시에 연결한 설명 프레임. 독자 실험이나 재현 결과를 주장하지 않습니다.
- 범위 제외: 모델 성능 순위, Qwen 전체 안전성 단정, 악의적 의도 추정, 보편적 재현율.
- 첫 이미지: 샌드박스에서 외부 전송 시도가 차단된 흐름. 원 생성 프롬프트를 보존하고 실제 픽셀을 확인했습니다. 독립적인 전체 전문 이미지 게이트 기록은 별도입니다.
- 두 번째 이미지: 전체 권한과 제한 권한 비교. 변경 없이 유지하며 infographic 검증 대상.
- 제작 도구 선택: 기존 승인 미디어를 사용하므로 새 생성 없음. 원 제작 프롬프트는 artifacts/provenance/에 보존했고, 실제 최종 PNG도 수령했습니다.
