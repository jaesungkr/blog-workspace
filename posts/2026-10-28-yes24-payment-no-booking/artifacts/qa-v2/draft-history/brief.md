# 기획: 예스24 티켓, 결제됐는데 예매 내역이 없을 때

- 범위: 새 글의 로컬 초안. 티스토리 게시, 외부 에디터 저장, Git push 금지. 기존 글 변경 금지.
- 독자: 예스24 티켓 결제 알림을 받았지만 공연 예매 내역이 보이지 않아 좌석 확보와 취소 상태를 구분하려는 사람.
- 검색 의도: 결제 후 예매내역 없음, 자동 취소 시점, 문의 준비 정보.
- 핵심: 예매 내역과 예매번호로 예매 여부를 확인한 뒤, 내역 없이 결제만 된 경우의 공식 취소·문의 조건을 적용한다.
- 첫 화면: 인사 → 결제 알림과 빈 예매 내역의 불일치 → 예매 내역·번호 확인.
- 구조: 예매번호 확인 → 내역 없는 결제의 취소 안내 → 안내 기간 이후 문의.
- 용어: 예매번호는 예매 내역에서 확인하는 번호. 승인번호는 문의를 위한 결제 정보. 두 문장으로 한 번만 구분.
- 근거: 공식 FAQ 원문 직접 열람. 실제 오류·결제·자동 취소 재현은 수행하지 않음.
- 독자 가치: 공지의 조건을 독자의 판단 순서로 재구성. 실제 메뉴·FAQ·문의 위치 화면으로 탐색 지원 예정.
- 한계: 현재 화면의 메뉴명과 위치는 스크린샷 수신 후 대조. 카드사 환급 시점·모든 불일치 원인·타 티켓사 정책 일반화 금지.
- 제외: 팝업·아이폰 예매창, 티켓팅 성공 팁, 정상 예매 취소 절차, 수수료, 무통장입금 문제.
- 시각 구성: 메뉴(어디서 확인?) / FAQ(어떤 경우 취소?) / 문의(어디로 연락?) 3장. 각각 해당 행동 뒤 배치.
- 인포그래픽: max-txt2img와 diagram-design을 검토했으나 번호 구분은 두 문장으로 충분하고 실제 메뉴 식별이 중심이므로 사용하지 않음.
- 생성 대표 이미지: 사용하지 않음. 실제 메뉴 스크린샷을 리드 후보로 계획.
- 불필요한 화면: 전체 홈, 로그인 양식, 임의의 결제 성공/실패 화면은 탐색 설명을 늘리거나 미재현 상태를 오인시키므로 제외.
