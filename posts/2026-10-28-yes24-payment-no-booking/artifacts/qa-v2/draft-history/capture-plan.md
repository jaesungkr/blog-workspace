# 스크린샷 계획

상태: 부모가 수집 완료를 보고했고, 부모 환경에서 그림 포함 검토본을 만들 예정. 이 환경에는 이미지 바이트를 아직 수신하지 않음. 이미지를 가공해 예매 상태를 만들지 않는다.

- FAQ URL: https://www.yes24.com/Mall/Help/FAQ?faqGb=38&faqSubGb=YG2
- 실제 화면에 보이는 메뉴명만 확정한다. 메뉴가 FAQ와 다르면 현재 화면 표기와 FAQ 표현을 구분해 원고 수정.
- 개인정보 없는 공개 화면만 사용. 실제 완료 예매·개인 결제 화면을 대신 만들어 넣지 않음.
- 메뉴 랜드마크는 인접 맥락과 함께 보존. 과도하게 넓은 화면은 360px 가독성 확인 후 재캡처 또는 검증된 스크롤 처리 검토.
- 수신 후 로컬 바이트, 파일 서명, 크기, SHA-256, 전체 화면과 360px 검사를 각각 기록.
- 부모의 로컬 경로는 이 환경의 파일로 간주하지 않음. Library 자료는 현재 스킬의 materialization으로 다운로드.
- 페이지 전체와 로그인 입력란은 독자의 다음 선택에 도움을 주지 않아 제외.
