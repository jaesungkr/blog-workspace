# 게시 보관 자료

현재 게시물: https://dop3n.tistory.com/entry/예스24-티켓-결제됐는데-예매-내역이-없을-때

최종 보관 HTML은 실제 수정 payload에서 네이티브 이미지 토큰을 로컬 경로로 치환한 비식별 파생본이다. raw HTML과 바이트가 다르고 재게시용이 아니다. 정확한 raw editor/prepared payload SHA-256과 개행 차이는 수정 영수증에 별도 보존했다. 토큰·서명 URL이 포함된 원본 HTML은 보관하지 않는다.
승인 MD 원본은 artifacts/approved-source/article.md. 본문 이미지 3개는 assets의 02/03/04 PNG이며 대표 이미지만 yes24-faq-question-thumbnail.png로 교체됐다.
최초 발행 QA는 initial-publication-history, 사용자 요청에 따른 간격/대표 이미지 수정은 spacing-thumbnail-revision에 각각 보존한다. 수정 후 dark-theme 전체 재검사 결과는 없다.
