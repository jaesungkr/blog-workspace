# diagram-design 소개 글 — 게시 소스 v7

- 원고: `article-draft.md`
- 자체완결 미리보기: `diagram-design-article-review.html`
- 본문 이미지: `images/`의 GitHub 캡처, 이사 핵심 요약, 방 배치, 공통 시간
- 실제 제작 경위: `examples-provenance.json`, `process-evidence-v7.json`
- 현행 독립 검수: `source-review.json`, `qa/v7/structure-checks.json`
- 게시 기록: `artifacts/publication/` (최초 게시와 수정 기록을 구분)

이사 도식은 네 장면의 요약입니다. 원문 전체를 그림에 넣었다고 주장하지 않습니다. 방과 약속 시간 그림은 가상 예시입니다. 원본 스킬 지침을 직접 읽어 적용했으며, 설치 플러그인의 호출 화면이나 실행 로그를 만든 것이 아닙니다. 본문의 간단한 요청문은 따라 쓸 수 있는 예시입니다.

v7은 두 불필요한 주의문과 이미지의 같은 취지 문구를 제거하고, 방·약속 요청을 짧은 자연어로 바꾼 좁은 수정입니다. 도형의 좌표나 가구 치수·시간 집합은 바꾸지 않았습니다.

Library ID·전송 URL·로컬 private 경로·원본 native 첨부 블록·private editor backup은 포함하지 않습니다. 내부 브라우저 QA 캡처도 제외하고 텍스트 결과만 남깁니다. 요청된 GitHub 유형 미리보기 캡처는 출처와 MIT 고지를 함께 포함합니다.

`build_preview.py`는 이 디렉터리의 원고와 자산으로 미리보기 HTML을 만듭니다. 저장된 HTML은 빌드 없이 열 수 있습니다. 게시 플랫폼의 검수 결과와 standalone HTML 검수 범위는 따로 기록합니다.
