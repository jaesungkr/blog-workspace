# 편집 의도와 최종 변경 범위

독자: 개발자와 비개발자 모두. 목적: 회사 팀장 추천으로 자주 사용하는 AI 스킬을 사용자 경험과 간단한 사용 예시로 소개한다.

말투: 자연스럽고 짧은 한국어, 과장된 마케팅 문구와 불필요한 경고 없이 쓴다. 회사명·private project·수치화된 절약 효과는 만들지 않는다.

독자가 알아야 할 것: 지침을 준비한 AI에 메모나 필요한 내용을 툭 던지면 어울리는 그림으로 정리할 수 있다. 전문적인 도식 이름이나 디자인 지시를 먼저 외울 필요는 없다. 원하는 부분만 말로 수정하면 된다.

고정 내용: 팀장·동료 사용 경험, 실제 GitHub 유형 캡처, 원문 이사 메모→짧은 요청→4장면 요약→추가 수정, 방과 공통시간의 서로 다른 그림, 그림 유형과 파일 형식 구분, 짧은 결말.

가벼운 요청이 매번 정확히 같은 도형을 산출한다고 보장하지 않는다. 예시 요청을 과거 실제 생성 호출의 원문으로 꾸미지 않는다.
