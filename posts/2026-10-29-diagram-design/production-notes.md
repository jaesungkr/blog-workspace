# 제작 메모 v7 — 블로그 본문 아님

사용자가 불필요한 주의문 두 곳을 빼고, 방 배치와 약속 시간 예시를 전문용어 없이 툭 던지는 짧은 요청으로 바꾸길 요청했습니다. revision-v7-replacements.json의 일곱 군데만 바꿨습니다. 그림 종류나 레이아웃까지 지정할 필요가 없고, 필요한 내용을 알려준 뒤 마음에 안 드는 부분만 말로 바꾸면 된다는 흐름입니다. 짧은 요청은 교육용 예시이며 실제 과거 생성 호출의 원문이라고 주장하지 않습니다.

방 그림은 하단의 별도 확인 경고 한 줄, 벤 그림은 하단의 약속 길이 부연만 삭제했습니다. 접근성 설명과 독립 HTML의 같은 취지 문구도 제거했습니다. 도형, 좌표, 가구 치수, 시간 집합은 그대로입니다. 두 PNG를 로컬 Inkscape로 재렌더하고 346px 버전을 직접 확인했으며 독립 검수자가 같은 범위를 확인했습니다. 원본 SKILL 지침 직접 적용 제작이라는 경위도 변함없습니다.

이사 그림은 승인된 v6 네 장면 요약을 그대로 유지합니다. 실제 GitHub 캡처, 소개, 사용 준비법, 전체 이사 메모와 정확한 한 문장 요청, 유형 안내, 결말은 변경하지 않았습니다. 세부 작업 20개 전체를 보여준다는 주장은 없습니다.

이전 v6 소스·이미지·검수는 versions/v6에 보존했습니다. 게시 담당자가 최초 게시를 완료했고, 이번 좁은 수정도 같은 게시물 161에 저장했습니다. 저장된 편집기를 다시 열어 정규화한 전체 HTML이 승인 payload와 일치함을 확인했습니다. 게시 및 native 미리보기 검수의 확정 기록은 publication/에 별도로 있으며, 이 문서는 그 결과를 대신하지 않습니다. standalone HTML 전체 브라우저 렌더 검증과 실제 PNG 검수는 구분합니다.
