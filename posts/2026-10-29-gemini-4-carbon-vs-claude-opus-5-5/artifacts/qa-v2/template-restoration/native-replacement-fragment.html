1. Gemini 4 Carbon, 무엇이 달라졌나

Carbon은 구글의 새로운 상위 AI 모델입니다. 구글은 여러 단계를 거치는 개발 작업을 오래 이어가는 능력과 보안 문제를 찾고 수정하는 능력을 강조했습니다. 코드를 한 번 작성하는 데서 끝나는 것이 아니라, 문제가 생기면 원인을 찾고 다시 고치며 작업을 이어가는 쪽입니다.

다만 발표와 일반 사용 시작은 구분해야 합니다. 구글은 일부 사이버 보안 담당자에게 먼저 제공하고, 개발자와 일반 사용자에게는 순차적으로 확대하겠다고 밝혔습니다. 아직 누구나 Gemini 앱에서 선택해 쓸 수 있는 단계는 아닙니다. 구글 발표

먼저 눈에 들어온 건 Artificial Analysis의 Intelligence Index 59점입니다. 여러 모델을 평가하는 외부 업체의 종합 지표로, 업무·코딩·과학·일반 지식에 걸친 9개 시험을 묶습니다. Carbon은 이 지표에서 1위에 올랐습니다. Artificial Analysis 평가

이전 Argon과 비교하면 발전 폭이 더 뚜렷합니다. 종합 점수는 50점에서 59점, 터미널 작업은 57.1%에서 65.2%로 올랐습니다. Carbon·Argon 비교

3. Arena 비교: Text는 Carbon, 웹 제작은 Opus 5.5

시험 점수와 함께 보는 곳이 Arena입니다. 모델 이름을 가린 두 결과를 보여주고, 사용자가 더 마음에 드는 쪽을 고릅니다. 이런 선택을 모아 상대 점수를 계산하므로, 정답률보다는 사람들이 어떤 결과를 더 선호했는지에 가까운 평가입니다. Arena 소개

10월 29일 확인한 Text Arena 전체 순위에서 Carbon은 1위, 1,528점이었습니다. 수학·코딩·글쓰기 등 여러 텍스트 요청을 아우르는 부문입니다. 아직 초기 집계로 표시돼 있고, 불확실성을 반영한 순위 범위는 1~2위입니다. Text Arena

4. 가격과 사용 가능 여부

구글이 발표한 Carbon의 API 출시 초기 가격은 입력 100만 토큰당 2달러, 출력은 10달러입니다. 초기 기간이 끝나면 4달러·20달러로 바뀝니다. 토큰은 AI가 읽거나 만들어낸 글의 양을 세는 단위이고, 이 가격은 Gemini 앱의 월 구독료와는 별개입니다. 공식 가격 안내

초기 가격만 보면 눈길이 가지만, 아직 일반 공개 전인 만큼 지금 당장 구독을 옮길 근거로 삼기는 어렵습니다. 실제 사용할 수 있게 됐을 때 응답 속도와 사용 한도, 내 작업에서의 결과를 함께 봐야겠습니다.

6. Carbon과 Opus 5.5, 어떤 모델을 고를까

공개된 결과만 놓고 보면 종합 역량과 터미널 작업은 Carbon, 웹 제작 결과물의 선호도와 PC 화면 조작은 Opus 5.5 쪽에 무게가 실립니다. 여기에 개발 과제 성능을 중시한다면 GPT-6 Astra도 빼놓기 어렵습니다.

웹사이트 제작이 목적이라면 현재 Arena에서 앞선 Opus 5.5의 결과를, 터미널 작업이 많다면 Carbon의 강점을 눈여겨볼 만합니다. 지금 어떤 모델을 쓰는지보다 앞으로 어떤 일을 맡길지가 선택의 기준이 되겠습니다.

다만 Carbon은 아직 일반 공개 전입니다. 지금의 결론은 ‘Opus 5.5를 대체했다’보다는 ‘작업에 따라 맞붙을 강력한 비교 대상이 나왔다’에 가깝습니다. 공개 이후에는 이 점수 차이가 실제 작업 시간과 완성도에서도 이어지는지가 관건이겠습니다.
