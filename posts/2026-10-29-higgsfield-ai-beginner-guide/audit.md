# 편집 감사

- 원문 기능목록 8단계 대신 사진→템플릿→입력→결과의 한 경로를 먼저 설명.
- 제목은 무엇을 할 수 있는지 직접 답함. 다른 모델 평가/제작완료 경험을 약속하지 않음.
- 도입: 제품 사진만 가진 독자의 영상 제작 필요 → 웹서비스 정의 → 쉬운 Marketing 경로. 일반 로드맵·기업 성장 이야기는 삭제.
- 모델 이름 전체 학습 불필요를 설명하되 모든 경로에 모델 선택이 필수인 것처럼 쓰던 '선택 두 번' 표현 수정.
- 독립 검수자가 지적한 '영상 수정 불가' 범위를 Marketing 템플릿에 한정.
- 문단별 역할: 플랫폼 정의 / 도구 선택 / 4단계 / 출력종류 / 수정 / 자유장면 / 예시요청 / 생성설정과결과위치 / 연재작업 / 비용 / 예시산식 / 무제한정의 / 조건표 / 웹직접이용제약 / 작업별판단.
- 소유 섹션: 모델구분=1, 제품템플릿절차=2, 자유생성과연재=3, 차감·무제한=4, 결론=5. 중복된 기본절차나 전체요약은 넣지 않음.
- 핵심 보호: 영상 Unlimited 존재, 조건부적용·활성구독·토글·일반대기열·자동화금지. 마케팅영상 재생성 비용. 실제생성 경험 없음.
- 이미지: 실제 공개UI 캡처 수신 중. 템플릿은 예시라고 캡션 명시, 직접 생성결과로 소개 금지.
- 기존 완성글 비교 근거: 이 작업의 전체 공개 원문과 직전 Claude canonical 실물 파일만 접근. 3~5개 추가 완성글 조회는 하지 않았으며 전체표본검사 주장 안 함.
- canonical renderer 사용 예정, 사용자 정의 CSS/HTML renderer 없음. 전체 브라우저 시각 QA 미실행. 출처 독립검토는 source-review.json에 별도 기록.

## v2 재작성

- 사용자 지적: v1이 사진→영상 서비스로 지나치게 축소되어 보임.
- 수정: 사진으로 한정한 제목/서론 제거. 글·이미지·영상 입력과 생성·수정을 첫 화면에서 설명.
- 구조: 작업별 표 → 글로영상 → 이미지생성/편집 → 연출/영상편집 → 광고사례 → 비용 → 쓰임결론.
- 사진 예시는 기능 하나의 증거로 뒤쪽 배치. 새 Edit Text 전후는 공식 원본을 그대로 사용하고 MVP/GOAL 글자를 직접 확인.
- 주요 제한 보호: 모델별 입력지원, Cinema4.0의 30초 입력제한, 무제한 조건, 재생성/일관성 부담.
- 삭제/축소: 별도 플랫폼분류 섹션, 반복되던 마케팅 기본추천, 4단계의 과도한 클릭 설명.
- 생성품질이나 개인적 사용 경험을 추가하지 않음. 시각자료는 공식 사례.

- v2 표지: 본문 Edit Text 전후는 유효. 단독 인물사진은 스포츠글로 보일 수 있어 공개용 썸네일은 미확정. 사용자 게시 승인 이후 별도 선정 필요.
