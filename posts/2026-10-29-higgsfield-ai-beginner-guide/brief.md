# 힉스필드 AI 사용법, 사진 한 장으로 영상 만들기

- 독자: 힉스필드에 관심은 있지만 첫 화면의 도구·모델 이름이 낯선 비개발자.
- 익숙한 상황: 제품 사진은 있고 짧은 소개 영상이 필요함. AI 모델·템플릿·크레딧을 모른다고 가정.
- 하나의 추천: 제품 영상은 Marketing Studio의 UGC 템플릿에서 시작. 자기 사진을 넣고 비용을 확인한 뒤 생성하는 경로 이해.
- 유지할 메시지: 힉스필드는 여러 AI 모델과 제작 도구를 제공한다. 템플릿 영상과 직접 장면 생성은 경로가 다르고 비용은 시도 횟수까지 계산한다.
- 설명 순서: 사진→영상이라는 목적 → 플랫폼/모델 구분 → 제품사진 입력과 출력 → 캐릭터 등 자유 장면 → 비용/Unlimited → 적합 작업 결론.
- 검증 기여: 실제 기존 글을 읽어 잘못된 API 화면과 과도한 기능 목록을 제거하고, 공식 현재 UI에서 초보자 행동 지점을 캡처. 영상 생성 품질 실험은 하지 않았음.
- 제외: API/MCP 설치, 기업가치·투자·사용자 수, 모든 모델 비교, 무검증 요금제 달러 가격, 생성 결과인 척하는 템플릿.
- 실제 사용자 경험 주장 없음. 공개 공식 문서와 읽기 전용 화면에 근거. 생성/결제/계정 변경 안 함.
- 그림 결정: max-txt2img는 실제 UI를 설명하지 못하고 diagram-design 흐름도는 짧은 4단계와 중복. 공식 입력 사진과 결과 장면 2장으로 사진이 영상에 반영되는 모습을 보여준다. API 로그인과 홈페이지 전체는 제외.
- 화면별 질문: marketing-input=어떤 사진을 넣는가? marketing-result=사진의 제품이 어떻게 등장하는가? 실제 생성 UI는 브라우저 error9로 캡처 불가. 공개 공식 제작 예시로 좁혔으며 UI 체험 주장 없음.
- 출처/영상 범위: Marketing 영상 수정=해당 템플릿 작업의 재생성. Cinema 등 다른 도구의 편집 가능성을 부정하지 않음. Unlimited 영상도 있으며 모델/기간/모드/유효구독/직접 웹 사용 조건 유지.

## 사용자 범위 확장 반영 (v2)

- 사용자: 사진 하나를 영상으로 바꾸는 기능만 하는 것처럼 보인다. 내용 범위 확장 요청.
- 현재 제목: 힉스필드 AI 사용법, 무엇을 만들 수 있을까?
- 독자 유지: 힉스필드를 처음 알아보는 일반 사용자. 제품 판매자로 제한하지 않음.
- 추천 변경: 필요한 산출물(영상 장면·이미지·기존 결과 수정·광고)에 따라 시작 메뉴 선택.
- 글로 새 영상 → 이미지 생성/수정 → 촬영연출/기존영상 수정 → 제품 광고 순서. 템플릿 사례는 한 섹션에만.
- 공식 사진 글자 편집 전후 2장을 추가. 독자는 원본 글자와 바뀐 글자를 비교해 영상 외 기능을 이해함. 브러시 인페인팅과 Edit Text 예시를 동일 절차로 오인하지 않게 별도 설명.
- 기존 v1의 사진 중심 추천·도입은 역사 기록이며 현재 방향은 이 항목이 우선함.

## v3 요청

사용자가 서두에 시장 위치와 선두로 주목받는 이유를 설명해 달라고 요청. 본문 기능 소개는 그대로 두고 이용자 규모(날짜·회사발표 명시)와 다중모델+제작도구 통합의 실용성을 서론 2문단으로 보강. 모델 품질 1위나 시장 점유율 순위로 설명하지 않음.
