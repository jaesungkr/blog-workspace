# 게시본 아카이브 복구

- 2026-11-10 원격 master에 빠진 게시본을 복구했습니다.
- 원고는 원본과 바이트 단위로 같고, 본문 내용 해시는 기존 원고 검증 기록과 일치합니다.
- 본문 이미지 전부를 기존 manifest의 SHA-256과 대조했습니다.
- 게시 당시 확인한 URL·시각과 후속 수정 기록을 publication.json에 보관했습니다.
- 공개 보관본에서는 이미지 접근용 임시 서명 정보와 개인 파일 식별자를 제거했습니다. 원본 해시를 남겼으며 공개 TXT를 정확한 원본으로 표시하지 않았습니다.
- 새 발행·본문 수정·게시 후 시각 검수는 하지 않았습니다. 검수 기록을 새 승인으로 재사용하지 않습니다.
- 원본 작업 폴더, 미게시 초안, 다른 변경 파일은 수정하지 않았습니다.

## 2026-11-11 초대 방식 정정

- 사용자 요청에 따라 게시 담당이 post 174 서론과 초대/초기화 구분 문장만 수정하고 저장했다. 담당 보고상 실제 게시 화면에서 덧붙임과 교체 문구를 확인했다.
- 이 로컬 작업은 확정된 게시 문구를 원고와 기존 sanitized 보관본에 같은 범위로 반영했다. 보관 HTML은 원격 제출 원본이 아닌 재구성된 서명 제거 보관본이다. 기존 publication 원본 해시와 당시 검수 이력은 변경하지 않았다.
- 개인정보·추천코드·보상 홍보를 추가하지 않았고 제목·게시일·가격 관찰 날짜·이미지를 변경하지 않았다.
