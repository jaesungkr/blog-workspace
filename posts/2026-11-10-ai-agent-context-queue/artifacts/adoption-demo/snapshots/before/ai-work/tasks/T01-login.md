## 목표와 허용 범위
만료 링크에서 흰 화면 대신 안내를 표시합니다. 로그인 화면의 기존 만료 처리와 관련 로컬 테스트만 다룹니다. 로그인 방식·권한·서버 API 변경과 배포는 허용하지 않습니다. 이 카드의 작성자는 ‘로그인 수정’ 대화 하나입니다.

## 멈춘 지점과 검증
가상 시나리오에서 만료 안내 수정안을 준비한 상태입니다. 버튼 추가는 사용자가 결정하기 전입니다. 제품 테스트는 실행하지 않았습니다. 이 fixture에는 실제 제품 코드가 없으며 코드 경로나 통과 로그를 만들지 않았습니다. 버튼 유무 결정이 후속 화면 확인 범위를 막는다고 가정합니다.

## 판단 근거
설명용 화면 초안은 ‘링크가 만료되었습니다’ 안내 아래에 ‘링크 다시 받기’ 버튼을 두는 구성입니다.

- A: 안내만 표시합니다. 변경 범위는 작지만 사용자가 재발급 경로를 따로 찾아야 합니다.
- B: 안내 바로 아래에 버튼을 둡니다. 다음 행동은 분명하지만 버튼 동작 검증이 추가로 필요합니다.
- 추천: B입니다. 사용자가 만료 안내를 읽은 자리에서 다음 행동을 선택할 수 있기 때문입니다. 이것은 디자인 제안이지 사용자 테스트 결과가 아닙니다.

실제 도입 시에는 이 절 대신 실제 변경 파일·화면·로그의 존재하는 경로를 연결합니다.

## 완료 조건
