# 도구 전제와 근거 확인

확인일: 2026-11-10. 실제 사용자 프로젝트에 도입하지 않은 기술 검증입니다.

## 공식 문서로 확인한 범위

1. **Codex CLI**: 로컬 저장소의 파일을 살피고 편집하며 명령을 실행할 수 있습니다. 프로젝트 디렉터리에서 시작하고 세션의 권한과 쓰기 가능 범위를 확인해야 합니다. 공식 문서의 ‘Work against your local repository’, ‘Run Codex and sign in’, ‘Set the boundaries for each run’을 확인했습니다.
   - 읽은 진입 URL: https://developers.openai.com/codex/cli/
   - 확인된 현재 문서: https://learn.chatgpt.com/docs/codex/cli
2. **Codex 파일 접근 한계**: 읽기 전용과 작업 공간 쓰기 범위가 구분됩니다. 파일을 읽을 수 있다는 사실만으로 편집 가능하다고 판단하면 안 됩니다. 이 운영 예제가 보안 설정 변경을 요구하는 것은 아닙니다.
   - https://learn.chatgpt.com/docs/sandboxing
   - https://learn.chatgpt.com/docs/permissions
3. **Claude Code**: 파일 읽기·편집·생성 도구가 있으며, 기본 작업 디렉터리와 현재 권한 모드가 파일 접근과 편집 승인을 좌우합니다. ‘Tools’와 ‘Working directories’를 확인했습니다.
   - https://code.claude.com/docs/en/how-claude-code-works
   - https://code.claude.com/docs/en/permissions
4. **세션 맥락**: Claude Code 문서는 새 세션의 맥락 창과 지침 파일·메모 기능을 구분합니다. 이 예제는 그러한 자동 기억 기능을 설정하거나 의존하지 않습니다. 일반 README와 해당 카드를 매번 명시적으로 읽히는 공통 절차를 사용합니다.
   - https://code.claude.com/docs/en/memory

위 문서는 기능 존재와 경계의 근거입니다. 이 예제의 네 프롬프트가 실제 서비스에서 항상 정확하게 실행된다는 보증이나 검증은 아닙니다. 공식 문서는 2026-11-10 웹 도구로 직접 열어 확인했습니다. Codex의 예전 `/codex/security/` 경로는 현재 Codex Security 제품 페이지로 이동하므로 샌드박스 근거로 쓰지 않았습니다.

## 원문의 운영 방식과 이번 글의 제안 구분

Sergey Kuhne의 원문은 Git에 남기는 카드와 보드, 사람 판단을 모으는 대기함, 검토용 화면, 결정의 카드 반환을 포함한 개인 도구 구성을 소개합니다. 핵심은 한 항목의 맥락을 읽고 결정한 뒤 다시 큐로 돌려보내 다음 항목을 볼 수 있게 닫는 절차입니다.

- https://sergeykuhne.com/blog/fighting-ai-brain-fry
- 원문 표기일: 2026-11-08.
- 이번 확인에서는 웹 도구 접근은 실패했지만 로컬 Python의 공개 HTTP GET은 200으로 본문을 읽었습니다. 로그인·계정 조작·전송은 없었습니다.

`ai-work/README.md`와 카드·수동 갱신 대기함은 원문의 도구를 복제했다고 주장하는 것이 아니라, 그 절차를 좁은 범위로 시작하기 위한 dev.log 제안입니다. 자동 대시보드·에이전트 순환·Git 자동 커밋·배포 기능은 구현하지 않았습니다.

## 이 예제에서 실제로 실행한 것

- 컴퓨터: Jaesungui-MacBookAir.local, Darwin arm64.
- 도구: Python 3.9.6 표준 라이브러리와 로컬 파일 읽기·쓰기.
- 입력: 가상 로그인·검색·테스트 조사 카드 세 개와 가상 결정 JSON.
- 검사 대상: 상태별 포함/제외, 정렬, 결정 반환 조건, 반환 뒤 카드·대기함 변화, 원본 카드 비변경.
- 실행 명령·시각·원본 출력: `verification.log`.
- 결과 요약: `results.json`.

## 실행하지 않은 것과 남은 조건

- Codex CLI·Claude Code CLI 호출, 유료 모델/API 호출, 실서비스 대화 생성은 하지 않았습니다.
- 실제 로그인·검색 코드, 브라우저 화면, 회귀 테스트는 검증하지 않았습니다. 카드 안에서도 미실행을 명시했습니다.
- `decision-input.json`의 전달 여부는 가상 테스트 입력이며 실제 전달 증거가 아닙니다.
- 프로토콜의 단일 작성자 규칙을 테스트 코드가 실제 동시 세션에 강제하지 않습니다. 파일 잠금·트랜잭션·다른 worktree 간 동기화도 없습니다.
- 카드가 갱신되지 않았거나 검토 중 바뀌면 목록이 오래된 정보가 될 수 있습니다. 사람 판단 전에 해당 카드를 다시 읽어야 합니다.
- 사용자가 실제 시작하려면 각 대화에서 같은 물리 폴더가 열렸는지, 필요한 파일 읽기·쓰기 권한이 있는지 확인해야 합니다. 요청이 막히면 저장 실패와 필요한 범위를 보고하고, 권한을 우회하지 않습니다.
- 피로·주의·생산성·문맥 전환 비용은 측정하지 않았습니다. 본 결과는 AI 사용 성공률이나 인지 개선 효과가 아닙니다.
