# 라면 글 형식 개선 범위

사용자 요청은 기존 글의 본문 내용 유지, 최신 글과 같은 HTML 형식, 이미지 재제작 및 교체다. 새 글의 집필이나 사실관계 재검증은 이번 범위가 아니다.

- 대상: 티스토리 글 31, 「한국인은 나흘에 한 번 라면을 먹는다 - 라면의 역사 그리고 오해」
- 원 게시: 2026-07-03 23:00. 제목, 원 게시일, 태그, 공개 URL, 실제 카테고리 음식·장보기를 유지한다.
- 독자: 라면의 역사와 흔한 오해를 읽으려는 기존 독자.
- 적용: 원문 8개 주요 섹션과 7개 하위 제목, 6개 표, 15개 목록 항목을 Markdown으로 보존하고 정본 rich-post-v2 렌더러로 표현한다.
- 문체: 원글의 해라체, 소제목, 표현과 수치까지 변경하지 않는다. 최신 집필 문체 규칙을 이유로 승인된 원문을 고치지 않는다.
- 원자료: 공개 본문 HTML 및 수정 화면 HTML을 백업했다.
- 이미지: 원래 1장의 위치를 유지하고 새 라면 식탁 사진형 삽화로 교체한다. 역사적 실물 기록이나 실험 증거로 사용하지 않는다.
- 이미지 설명: 새 이미지에 「우리 식탁에 익숙한 라면 한 그릇.」 캡션을 붙인다. 기존 마지막 문장은 이동하지 않는다.
- 인포그래픽: 없음. 이미 있는 6개 표를 유지하며, 이번 요청은 본문 추가가 아닌 형식 개선이다.
- 제외: 수치와 의학적 설명의 보완·수정, 신규 출처 추가, 제목·서론·결론 재작성.

## 판단 사슬

기존 공개 HTML → 의미 구조와 문구 보존 변환 → 본문 문자 동일성 확인 → canonical v2 렌더 → 이미지 교체·레이아웃 검수 → 원글 갱신.
