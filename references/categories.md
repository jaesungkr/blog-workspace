# 카테고리 체계

티스토리에 실제로 설정된 구조다. 새 글은 반드시 아래 중 하나에 들어간다.

| 대분류 | 하위 분류 | 다루는 것 |
|---|---|---|
| **Log** | AI 개념·실전 | AI 원리 설명, 파인튜닝, 임베딩, 실습 코드 |
| | AI 모델·비교 | 모델 벤치마크·실사용 비교, 가격·플랜 |
| | 개발·디지털 | 개발 도구, Claude Code, 자동화, 생산성 |
| **Trends** | AI 뉴스·테크·산업 | 업계 발표, 신제품, 정책 |
| | 경제·금융 | 시장, 물가, 투자 환경 |
| | 사회·문화 | 소비 트렌드, 유행 |
| **Health** | 질환·의약품 | 증상 감별, 약 비교, 복용법 |
| | 영양·식단 | 영양제, 식단, 제철 식재료 |
| **Reflections** | 말씀 묵상 | 설교 요약 + 개인 묵상 |
| | 신앙 질문 | 스스로 던진 질문과 정리 |
| | 성경 읽기 | 통독 기록 |

---

## 카테고리 판별 기준

애매하면 **"독자가 무엇을 검색해서 들어오는가"**로 판단한다.

- 방법·원리를 검색 → **Log**
- 사건·시세·유행을 검색 → **Trends**
- 증상·성분·식품을 검색 → **Health**
- 성경 구절을 검색 → **Reflections**

시의성이 있으면 Trends, 시간이 지나도 유효하면 Log.
예: "Claude Opus 5 출시" = Trends / "Claude Code 비용 줄이기" = Log

## 카테고리별 필수 요소

### Log
- 도입 직후 **"한 문장 정리"** 섹션 (결론 선공개)
- 마지막에 **선택 기준표** 또는 정리표
- 코드가 있으면 실행 가능한 완성 형태로. 조각만 던지지 않는다
- 모델·도구는 **버전과 확인 날짜**를 명시 (예: "2026년 7월 기준")

### Trends
- 첫 문단에 **언제 일어난 일인지** 명시
- 사실과 해석을 문단으로 분리. 해석 문단은 "제 생각에는"으로 시작
- 출처 링크를 본문 안에 건다

### Health
- **면책 문구 필수.** 글 끝에 아래 문장을 그대로 넣는다:
  > 이 글은 일반적인 정보 정리이며 의학적 진단이나 처방을 대신하지 않습니다.
  > 증상이 지속되거나 복용 중인 약이 있다면 의사·약사와 상담하시기 바랍니다.
- 용량·복용법은 **출처(식약처, 제조사, 논문)를 명시**한다. 근거 없으면 쓰지 않는다
- "낫는다", "치료된다" 같은 효능 단정 표현 금지 → "도움이 될 수 있습니다"
- 특정 제품 추천보다 성분 기준으로 설명

### Reflections
- `references/voice.md` §7 규칙을 따른다
- 성경 인용은 **쉬운성경**
- 설교 요약은 전한 목사님 성함을 밝힌다
- 겸손 장치 1회 이상
- 마무리는 기도/바람

## 태그 규칙

- **3~6개.** 10개씩 붙이지 않는다
- 사람이 실제로 검색창에 칠 말로만 쓴다
- 대분류 태그 1개 + 구체 키워드 2~4개
- 띄어쓰기 없는 고유명사는 그대로 (예: `ClaudeCode`가 아니라 `Claude Code`)
- Reflections는 `묵상` 태그를 공통으로 붙인다

예시:
- Log: `Claude Code`, `AI 코딩`, `개발 생산성`, `비용 절감`
- Health: `마그네슘`, `영양제`, `마그네슘 부작용`, `건강기능식품`
- Reflections: `묵상`, `로마서`, `설교요약`
