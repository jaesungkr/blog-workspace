# 티스토리 발행 체크리스트

발행 직전에 훑는다. 자동화할 수 없는 항목이라 사람이 확인한다.

## 제목
- [ ] 검색 키워드가 앞쪽에 있는가
- [ ] 32자 이내인가
- [ ] 같은 블로그에 비슷한 제목의 기존 글이 없는가 (자기잠식 방지)

## 본문
- [ ] 첫 문단 안에 핵심 키워드가 들어갔는가
- [ ] 소제목(H2)이 4개 이상인가
- [ ] 표가 1개 이상 있는가 (Reflections 제외)
- [ ] 문단 길이가 균일하지 않은가 (AI 티 방지)
- [ ] 이모지가 없는가
- [ ] Health 글이면 면책 문구가 들어갔는가
- [ ] 인용한 수치·날짜에 출처가 있는가

## 이미지
- [ ] 대표 이미지(썸네일)를 지정했는가
- [ ] 모든 이미지에 alt 텍스트를 넣었는가
- [ ] 이미지가 저작권 문제 없는 것인가 (직접 생성/촬영, 또는 라이선스 확인)

## 티스토리 설정
- [ ] 카테고리를 올바르게 지정했는가
- [ ] 태그 3~6개인가
- [ ] 공개 설정이 '공개'인가
- [ ] 주소(slug)를 영문으로 바꿨는가 — 한글 URL은 공유 시 깨진다
- [ ] 요약(설명)을 채웠는가 — 검색 결과에 노출됨

## 발행 후
- [ ] 모바일에서 표가 넘치지 않는지 확인
- [ ] 코드블록이 가로 스크롤되는지 확인
- [ ] `drafts/`의 원본을 `published/`로 옮기고 프론트매터 `status: published`로 변경

---

## 티스토리 HTML 에디터 붙여넣기 방법

1. 글쓰기 화면 우측 상단 **기본모드 → HTML** 선택
2. `dist/*.html` 내용을 전체 복사해서 붙여넣기
3. 다시 **기본모드**로 전환 (여기서 레이아웃이 깨지면 표 구조를 단순화)
4. 이미지는 HTML로 넣지 말고 기본모드에서 직접 업로드

> 티스토리 Open API는 2024년 2월 완전 종료되어 프로그램 발행은 불가능하다.
> 이 붙여넣기 단계는 사람이 직접 한다.
