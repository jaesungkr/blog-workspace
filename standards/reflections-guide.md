# Reflections guide

## Scope and preparation

- Use only for sermon-based personal meditation.
- Before drafting, summarize the supplied scripture and each sermon, then
  present the intended direction for review when interpretation is
  consequential.
- Do not add an idea, illustration, verse, or inference that is absent from the
  supplied material.
- With one sermon, omit the comparison section.

## Structure

1. Title: default to the scripture reference, such as `마태복음 25:31-46`.
2. Opening: briefly set the Sunday context, include one roadmap sentence, then
   state the recurring fear/confession in fresh natural language.
3. Scripture: use the requested translation, include verse numbers, and add a
   short lead paragraph that names the passage's tension.
4. Sermon summaries: separate by preacher. Give 1-2 framing sentences, then
   about three numbered core claims with 2-4 sentences each.
5. Comparison: when there are multiple sermons, introduce a three-column
   Markdown table (`구분 / 설교자 A / 설교자 B`), keep cells short, and explain
   their meeting point below it.
6. `Thoughts`: personal observation -> initial interpretation -> honest
   self-correction -> unresolved tension if any -> concrete application to one
   nearby person or scene.

## Voice and integrity

- Use consistent 존대어 and allow `저/제` freely.
- Permit exploratory, vulnerable prose without becoming self-abasing.
- The recurring confession should convey that the preachers prepared deeply,
  the writer's knowledge is limited, and different readings are possible.
- Preserve the difference between what the passage says, what a preacher said,
  and what the writer thinks.
- Do not force a solution to a question the passage leaves open.
- Avoid sliding into effort-based moralism when the passage centers received
  love flowing outward.
- Avoid heroic ethics when the passage points to an ordinary nearby person.
- End with a concrete personal application, not an abstract lesson.

## Output compatibility

- Default new posts to rendered Tistory Markdown, consistent with the latest
  site-wide rule.
- If the user says the post must match an older Reflections article, use plain
  text for prose and Markdown only for the comparison table.
- Confirm preacher names, scripture range, and Bible translation before
  finalizing when the source material does not make them certain.

## Final checks

- Polite endings remain consistent throughout the post and no 한다체 paragraph
  appears accidentally.
- The opening starts with `안녕하세요. dev.log입니다.`, then contains context,
  roadmap, and humble confession without a long self-introduction.
- The scripture lead exposes the core tension.
- Each preacher's summary stays inside the transcript and uses the compact
  numbered form.
- The comparison table is concise and followed by a point of convergence.
- `Thoughts` shows self-correction and lands on a concrete personal application.
- Scripture context, preacher names, and translation are accurate.
